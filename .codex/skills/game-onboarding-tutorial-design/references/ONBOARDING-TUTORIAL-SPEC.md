## Acceptance Criteria

- [ ] First-session learning goals are limited to what the current gameplay requires.
- [ ] Each prompt has trigger, success, and exit conditions.
- [ ] The first failure has a recovery path.
- [ ] Veteran players can skip or pass through quickly.
- [ ] Critical teaching does not rely on text alone.
