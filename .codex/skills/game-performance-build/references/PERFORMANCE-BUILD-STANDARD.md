# Performance And Build Standard

## Evidence Level

Performance, build, and device conclusions must prioritize device records, Profiler data, build logs, package metadata, permissions, or SDK records. Do not claim performance improvement without measurement.

## Review Axes

- FPS, GC, memory, draw calls, and load time.
- Textures, audio, shaders, fonts, scenes, and asset loading.
- Scripting backend, stripping, permissions, signing, and package size.
- Target devices, platform differences, heat, and input devices.

For build failures, identify the root cause first. For performance tuning, establish a baseline first.
