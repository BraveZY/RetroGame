# Setup Self-Check Checklist

After completing setup, check each item.

## Project Identification

- [ ] The engine has been identified, or unknown has been explicitly recorded.
- [ ] For a Unity project, `ProjectSettings/ProjectVersion.txt` has been read.
- [ ] Key code, asset, and documentation directories have been recorded.
- [ ] For a Unity project, whether UnityCaptain / UnityMCP is installed and whether it is available in the current session has been recorded.

## Documentation

- [ ] `game-design/<game-slug>/agents/game-project.md` exists.
- [ ] `game-design/<game-slug>/agents/task-workflow.md` exists.
- [ ] `game-design/<game-slug>/agents/content-pipeline.md` exists.
- [ ] `game-design/<game-slug>/agents/build-targets.md` exists.
- [ ] `game-design/<game-slug>/agents/domain.md` exists.

## Tasks

- [ ] The task system has been recorded.
- [ ] The task directory or external link method has been recorded.
- [ ] The Agent's permissions for the task system have been recorded.

## Assets

- [ ] Asset directories have been recorded.
- [ ] Placeholder/prototype/production asset rules have been recorded.
- [ ] Whether Scene, Prefab, and asset modifications are allowed has been recorded.

## Verification

- [ ] Available verification methods have been recorded.
- [ ] UnityCaptain / UnityMCP has been distinguished as "installed in the project" versus "callable in the current session."
- [ ] Known test or build risks have been recorded.
- [ ] Problems found during setup have not been presented as already fixed.

## Output

- [ ] The final reply lists created/updated files.
- [ ] The final reply lists issues still requiring confirmation.
- [ ] The final reply recommends the next skill.
