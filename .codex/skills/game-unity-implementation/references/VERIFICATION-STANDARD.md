# Unity Implementation Acceptance Evidence Standard

| Level | Applies to |
|---|---|
| L1 Static evidence | Code, configuration, asset paths, import settings. |
| L2 Automated tests | EditMode, unit tests, rule logic, state machines, numeric calculations. |
| L3 Unity Editor evidence | Scene, Prefab, components, Console, compile, screenshots. |
| L4 PlayMode / Manual flow | Playtest, screen recording, screenshots, manual steps, in-game flow. |
| L5 Device / Build evidence | Real device, Profiler, build logs, package, permissions, SDK. |

Feature completion is not acceptance. When not run, unable to run, partially passed, or evidence is insufficient, keep acceptance items unchecked and mark them `⚠️ pending verification`.
