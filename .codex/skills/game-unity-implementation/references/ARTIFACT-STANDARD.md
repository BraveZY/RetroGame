# Unity Implementation Artifact Standard

The implementation summary must allow later QA, review, and handoff to re-check the work.

## Required Fields

```text
Implemented:
Task basis:
Modified files:
Scene/Prefab/asset impact:
Verification:
Regression verification:
Remaining risks:
```

Completed feature items must trace to code, scene, Prefab, asset, or configuration locations. Completed acceptance items must trace to evidence sources.

For existing projects, also state the change type, existing behaviors that do not change, regression verification results, and compatibility or migration impact for save data, configuration, asset references, and similar surfaces.
