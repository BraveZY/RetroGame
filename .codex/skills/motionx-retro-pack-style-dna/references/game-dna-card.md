# 游戏 DNA 卡片

创建或修改某个具体 MotionX Retro Pack 游戏概念时使用。

## 必填卡片

| 字段 | 要求 |
| --- | --- |
| 游戏名 | 中文名 + 可选英文名 |
| 所属主题馆 | `童年操场`, `客厅街机`, `家庭电视健身`, or another approved hall |
| 场景一句话 | 玩家在哪里 |
| 玩家身份 | 玩家在这个场景里是谁 |
| 动作理由 | 为什么要在场景里做这个动作 |
| 核心动作原语 | 必须落在稳定 2D 单目体感动作内 |
| 记忆触发音 | 一个最强音频锚点 |
| 关键视觉锚点 | 一个最强视觉锚点 |
| 反馈语言 | 成功、失败、连击或暂停如何表达 |
| 结算记忆 | 称号 + 回忆标签 |

## 动作边界

优先使用：

- 跑 / 停
- 冻结 / 静止
- 挥臂
- 伸手到屏幕区域
- 出拳
- 抬膝
- 下蹲 / 站起
- 左右倾斜 / 左右侧移
- 拍手节拍

不要作为核心玩法：

- 真实地面落点
- 前后纵深移动
- 精确投掷距离
- 精细手腕 / 手指动作
- 精确多人同步百分比
