# 文档地图

回答前用这份地图选择最小必要上下文。

## 风格权威文档

- `references/style-dna.md`
- `references/theme-visual-extension.md`
- `references/ai-image-prompt.md`

当用户询问这些内容时读取：

- 游戏 DNA
- 视觉风格
- UI 一致性
- 美术方向
- 音频方向
- 文案语气
- 动效反馈
- 结算 / 奖励风格
- 某个设计是否符合 MotionX Retro Pack

当任务涉及页面主题化、首页、登录 / 入口、主题详情、游戏选择卡、游戏中 HUD、结算页或奖励卡视觉拓展时，读取 `references/theme-visual-extension.md`。

当任务涉及通用游戏画风、2D / 3D 取舍、首页 / loading 风格方向、是否像经营游戏、是否有重 3D 玩具感时，先读取 `references/style-dna.md` 和 `references/theme-visual-extension.md`。`../../../Retro_Games_plans/docs/设计方案/MotionX-Retro-Pack-游戏风格概念定义.md` 只作为 docs 侧入口页，不承载完整上位规则。

当任务涉及 AI 生图、Prompt、概念图生成、主题馆主视觉、UI 背景、奖励卡或图标生成时，读取 `references/ai-image-prompt.md`。

当任务涉及“按当前确认风格生成图片”“统一输出图片风格”“游戏中效果图 / HUD 方向图”时，读取 `references/ai-image-prompt.md`，并把 `references/approved-visual-targets/playground-gameplay-hud-approved-20260630.png` 作为目标风格基准。

当任务涉及产品定位、风格红线、UI / 文案 / 音频 / 动效统一判断时，读取 `references/style-dna.md`。

## AI 生图 Prompt

- `references/ai-image-prompt.md`

当任务涉及这些内容时读取：

- 优化 Prompt
- 根据参考图调整 Prompt
- 生成首页 / 主题卡 / 奖励卡 / 图标 Prompt
- 生成游戏中效果图 / HUD 方向图，并贴近已确认的横版体感 HUD 基准
- 评审 AI 生图是否有情怀、有自然 80/90 元素冗余、是否太正规正矩
- 把“顶级大厂水准”落实到可复制 Prompt
