# 风格评审清单

评审页面、mockup、UI 概念、美术方向、文案、音频、动效、结算页或奖励卡片时使用。

## 通过 / 不通过清单

| 检查项 | 通过标准 |
| --- | --- |
| 5 秒内能读懂场景 | 用户能识别操场、街机、电视健身、游园会或其他具体童年场景 |
| 30 秒内能读懂规则 | 用户不用读长说明也知道要做什么动作 |
| 游戏中效果图是否贴近确认目标 | 横版 16:9、至少 55% 无阻挡中央 / 前景动作区、清晰关键 HUD、站位区、目标物和运动路径清楚；不把每个模块都做成大卡，不像竖版经营地图 |
| 父母有发起理由 | 父母能自然说“这像我小时候玩的” |
| 情怀是否触动回忆 | 有自然的 80/90 年代生活碎片，不只是一个复古标签 |
| 冗余是否受控 | 有贴纸、票根、磁带、奖状、掌机等小物件，但不影响标题、CTA 和动作目标 |
| 环境是否干净 | 墙面、地面、跑道、客厅和大面积背景明亮清爽；怀旧不是污渍、灰尘、破损或暗角 |
| 是否避免太正规正矩 | 不像极简企业 App、不像模板卡片、不完美死板对齐 |
| 孩子不懂怀旧也能玩 | 孩子仍能理解规则并觉得好玩 |
| 不低幼 | 画面是全龄家庭娱乐，不使用儿童绘本画风、幼态大头身、玩具化吉祥物或过度卖萌的 UI 语言 |
| 不做立体材质 | 画面以平面图形化 2D 表达；不用轻 3D、拟真体积、玻璃高光、软塑料质感或细腻表面渲染 |
| UI 远距离可读 | 分数、倒计时、站位区和动作提示清楚 |
| HUD 占屏受控 | 顶部 HUD 约不超过 15%、底部约不超过 12%；当前目标不在顶部、中央、底部重复；同一时刻只有一个主视觉反馈 |
| 怀旧是辅助 | 去掉复古装饰后，动作理由仍成立 |
| 文案像现场语言 | 文案像广播、机器、主持人、老师或摊主，而不是技术系统 |
| 音频原创安全 | 不使用真实老歌、真实节目音乐或可识别 IP 音频 |
| 结算留下记忆点 | 包含称号、标签或家庭可讨论点 |
| 不像换皮 | 目标、节奏、动作理由或反馈语言有真实差异 |

## 默认评审输出格式

```text
结论：
通过 / 部分通过 / 不通过

主要问题：
1. ...
2. ...

修改建议：
| 维度 | 当前问题 | 建议改法 |
| --- | --- | --- |

红线风险：
- ...
```

## 常见修正

| 问题 | 修正方式 |
| --- | --- |
| 旧照片 / VHS 风格过重 | 恢复明亮 UI，把复古纹理降级为二级装饰 |
| 墙面 / 地面太脏 | 改为 `clean-film childhood memory illustration`：干净墙面、干净地面、暖日光、轻微可爱使用感，不要污渍、灰尘、霉斑、破损墙皮和暗角 |
| 看起来像普通运动游戏 | 补充场景、身份、动作理由、主题反馈和结算记忆 |
| 文案暴露技术 | 用场景语言替换识别 / 校准文案 |
| 怀旧道具过多 | 保留一个强视觉锚点，把动作目标放到第一层 |
| 画面太正规正矩 | 加入 `curated nostalgic clutter`, `playful lived-in details`, `not too formal`, `not overly symmetrical` |
| 情怀不够 | 加入自然的 `Memory details`：贴纸、票根、磁带、搪瓷杯、奖状、粉笔线、掌机玩具、集章卡 |
| 孩子可能看不懂 | 简化动作目标，减少历史解释 |
| 画面低幼 | 保留明亮和亲和，改用更自然的角色比例、利落构图和克制材质；移除绘本笔触、玩具化角色和儿童节目式字体 |
| 画面过于立体或细腻 | 改为清晰色块、扁平图标、有限阴影和明确轮廓；删除 3D 道具、玻璃高光、体积光和材质纹理 |
| HUD 模块都太大 | 先保留至少 55% 无阻挡动作区；顶部收为分数、倒计时、目标摘要，底部只突出动作提示或玩家状态之一；连击 / 成功改为短暂弹出，删除重复目标面板 |
