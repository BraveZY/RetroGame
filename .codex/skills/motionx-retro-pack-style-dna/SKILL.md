## 核心规则

- 以权威 DNA 文档作为风格决策依据。
- 保持产品定位为 `家庭共同参与 + 童年场景记忆 + 1-3 分钟短局体感 + 明亮清晰现代 UI + 轻怀旧元素 + 原创安全表达`。
- 默认采用 `主题体验 70% / 怀旧元素 30%` 的风格比例。
- Prompt 和视觉概念必须有情怀触发点：让父母看到自然的 80/90 年代生活碎片后产生“我见过这个”的回忆感。
- 允许“有控制的情怀冗余”：贴纸、票根、磁带、搪瓷杯、奖状、广播、粉笔线、掌机玩具、集章卡等可以自然出现在边角、卡片缝隙、收集模块和奖励图里。
- 不要太正规正矩：避免极简企业 App、过度对齐、完美对称、模板化卡片和空泛精致。应有一点自然的小乱、收藏感、生活感和惊喜，但不能影响 UI 可读性。
- 不把项目做成纯怀旧滤镜、旧照片 UI、VHS 特效、像素皮肤或擦边复刻。
- 通用美术执行默认采用 `明亮 90 后生活记忆场景 + 平面图形化 2D + 全龄清晰 UI`；品质由构图、色彩、字体层级和动作反馈建立，不用轻 3D、立体空间感、玻璃高光或细腻材质表现。亲和不等于低幼，避免儿童绘本、幼态角色、玩具化吉祥物和儿童节目式包装。首页和主题入口走大舞台，不走经营地图主风格。
- 当前已确认的图片风格基准是 `横版 16:9 现代家庭体感 HUD + 明亮童年操场舞台 + 大动作空间 + 清晰可读的关键分数 / 倒计时 / 目标提示 + 边缘轻怀旧道具`。大号只用于当下唯一关键反馈，不等于每个 HUD 模块都要放大；默认保留至少 55% 的无阻挡动作区，不回到竖版经营地图、小游戏图标墙或纯插画封面。
- 优先保证明亮、可读、适合家庭的 UI，不使用暗、脏、噪点重、过度做旧的视觉。
- 怀旧不能靠污渍、灰尘、破损、霉斑、暗角、脏墙面或脏地面表达；墙面、地面、跑道、客厅和大面积背景必须干净、通透、暖日光，只允许轻微生活痕迹和可爱的使用感。
- 用户可见文案隐藏技术语言，优先使用 `准备上场`、`站到队伍里`、`投币成功`、`跟上节拍` 等场景语言。
- 每个设计都要绑定清晰的场景、玩家身份、动作理由、反馈语言和结算记忆。
- 尊重 2D 单目体感边界，不把真实地面落点、前后纵深、精细手指动作或精确物理距离作为核心玩法。
- 音乐、音效、角色、道具和文案都要原创安全，不使用真实老歌、真实影视、真实街机/游戏 IP、明星教练或可识别影视引用。

## 输出要求

输出设计建议时，要给出可执行的风格判断，不只写概念。

适合时优先使用这些格式：

- 视觉 / UI / 音频 / 文案规则表。
- 包含 `场景`、`身份`、`动作理由`、`视觉锚点`、`音频锚点`、`反馈语言`、`结算记忆` 的游戏 DNA 卡片。
- AI 生图任务输出可复制 Prompt 时，包含 `固定画风锚点`、`主题场景`、`动作焦点`、`Memory details`、`UI 构图`、`版权安全`、`负面 Prompt`。
- 用于评审 mockup、UI 页面或游戏概念的通过 / 不通过清单。

结论必须和项目文档保持一致；不确定项应标记为实现或资产制作决策，不要改写游戏 DNA 本身。若用户要求“顶级大厂水准”，优先检查：情绪是否打动人、细节是否自然丰富、UI 是否可读、风格是否统一、版权边界是否安全。
