# Micro-Innovation Creative Operators

Use this reference after the reality anchor and baseline loop are clear. Search across several design dimensions so the result is genuinely divergent, then keep only ideas that create playable consequences.

## Divergence Map

Generate 8-12 sparks across at least four rows. Do not use one operator repeatedly with different themes.

| Operator | Question |
|---|---|
| Decision upgrade | What new tradeoff can be inserted into the repeated action? |
| Goal mutation | What if success means preserving, connecting, escorting, balancing, hiding, or choosing what may fail? |
| Failure transformation | How can a mistake create a new problem or opportunity instead of only subtracting score? |
| Information shift | What can be hidden, delayed, shared, distorted, remembered, or intentionally revealed? |
| Space mutation | What if actions build, erase, rotate, divide, occupy, or reroute playable space? |
| Tempo mutation | What changes when safe and fast actions pull in different directions? |
| Role mutation | What if players alternate ownership, gain asymmetric duties, interfere, coach, or rescue? |
| Input mapping | What world state can a reliable input signal continuously affect? |
| Mechanic coupling | Can one mechanic change the target, state, risk, or next use of another? |
| Constraint mutation | Which one limitation creates a better decision rather than mere difficulty? |
| Spectator / social shift | What can observers predict, call out, sabotage, vote on, or celebrate? |
| Theme-to-rule translation | Which property of the theme can become a rule rather than decoration? |

### Decision Upgrade

Start with the choice a player already repeats. Change one tradeoff, then state the visible consequence.

- Dodging becomes choosing between protecting personal space and saving a shared objective.
- Catching becomes deciding whether to secure a point or redirect danger toward a better position.
- Queue management becomes choosing which customer to disappoint before a hidden patience threshold breaks.

Question: can a player explain the better choice after one round?

### Goal Mutation

Change one success condition without replacing the entire game:

- Finish with exactly the right amount rather than the maximum.
- Protect one route while deliberately sacrificing another.
- Create a pattern the opponent can see but cannot safely interrupt.

Question: does the new goal change moment-to-moment priorities?

### Failure Transformation

A useful failure creates state:

- A miss changes terrain, ownership, information, or future risk.
- A failed action gives another player a temporary role or opportunity.
- An error becomes recoverable debt rather than immediate loss.

Question: can a skilled player respond intelligently after the mistake?

### Information Shift

Change who knows what and when:

- Players see consequences but not causes.
- One player sees a target while another controls execution.
- Acting reveals intent to opponents.

Question: does information alter action, or only add explanation?

### Input-to-World Mapping

Start with a reliable signal, not a fashionable device. Map it to a game state that players and spectators can read.

| Available signal | Good world mapping | Weak mapping |
|---|---|---|
| Body position / silhouette | Blocking lanes, herding, balance zones, shielding allies | Selecting menu answers |
| Motion energy / tempo | Charging, stabilizing, escaping, disrupting | Generic score multiplier |
| Hand zone | Grabbing, passing, sorting, redirecting | Tiny invisible button presses |
| Voice volume / rhythm | Attracting, calming, coordinating, exposing | Binary voice command |

Question: if replaced by a button, what player decision or spectacle would be lost?

### Pressure Reframe

Keep the main verb but alter the situation that makes it difficult.

- Shared space: players interfere, cover, or save one another.
- Imperfect information: players decide before all consequences are visible.
- Recoverable failure: a mistake creates a new problem instead of immediate loss.
- Tempo shift: the safe action becomes too slow at the wrong moment.
- Role asymmetry: one player sees a risk another player must physically resolve.

Question: does the pressure create a repeatable choice, not merely noise?

### Mechanic Coupling

Use this when two mechanics can reinforce each other:

```text
mechanic A action/result -> mechanic B state, target, or risk -> next meaningful choice
```

Good coupling creates a decision that disappears if either mechanic is removed. Weak coupling merely places two scoring systems or activities beside each other.

Checks:

- Does A materially change B?
- Does B change how, when, or why the player performs A?
- Is there a new tradeoff rather than additional workload?
- Can the relationship be understood in one short round?

### Content Runway

For one candidate, name three variations that reuse its same core rule.

- Change spatial layout.
- Change the threat or information pattern.
- Change player roles, cooperation, or the success condition.

If three variations require three unrelated mechanics, the core is too thin.

### Theme Fit

Only after the loop works, use a meme, setting, or emotion to make cause and effect legible.

- A cafeteria queue can make patience, visibility, and unfairness instantly readable.
- A classroom can make shared attention, hiding, and turn-taking readable.

If the theme does not alter feedback, stakes, or content variation, classify it as `Presentation`.

## Optional Wildcards

Use these when the user explicitly requests unusual directions or the grounded routes converge too closely. Mark the result `unproven` until it creates a concrete player verb, choice, and feedback loop.

- **Random grafting**: pair two domains only after naming the shared player decision.
- **Role reversal**: move the player into an unusual role only if its moment-to-moment verbs are clear.
- **Genre reversal**: invert one genre expectation only if the new rule survives a 90-second round.
- **Emotional mismatch**: use an emotion only when a rule, not copy or cutscene, produces it.

## Meme Check

1. Name the visible meme moment.
2. Name the player's action that changes its outcome.
3. Name the recurring tradeoff and immediate feedback.
4. Name three variations of the same interaction.
5. If steps 2-4 are weak, classify it as `Level`, `Event`, `Presentation`, `Park`, or `Kill` instead of making it a core game.
