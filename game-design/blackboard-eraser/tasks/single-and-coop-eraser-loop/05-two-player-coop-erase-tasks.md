# 双人分工和共同擦除任务

## 父级总任务

| 项目 | 内容 |
|---|---|
| 总任务 | 体感擦黑板 1-2 人 60 秒玩法闭环 |
| 子任务编号 | 05 |
| 覆盖范围 | 双人分工任务、共同擦除任务、左右目标提示、协作擦除判定。 |

## 玩家可见结果

两名玩家能看到本轮是左右分工还是共同擦除任务，并按提示分别擦掉各自目标或一起擦掉同一个大目标。

## 需要实现的功能

- [ ] 双人任务系统能生成左右分工任务。
- [ ] 双人任务系统能生成共同擦除大目标任务。
- [ ] 分工任务用颜色、编号、左右标识或字幕明确提示每个玩家目标。
- [ ] 共同任务允许两个板擦共同累计同一目标擦除进度。
- [ ] 分工任务能分别记录左/右玩家贡献和擦错。
- [ ] 玩家擦到对方目标或干扰项时触发低收益或擦错反馈。

## 隐含玩法语义

```text
系统 -> 想制造双人协作 -> 判断分工或共同任务 -> 显示左右/共同目标提示 -> 两名玩家移动各自板擦 -> 目标按个人或共同进度响应 -> 系统计入协作完成、贡献或擦错
```

## 涉及系统

双人任务生成、目标提示 UI、擦除判定、共同进度、玩家贡献、擦错反馈、协作事件。

## 涉及资源

左右目标高亮、共同目标高亮、大涂鸦目标、双人任务字幕、双人擦除反馈。可使用 Prototype/Placeholder 资源。

## 验收标准与证据

- [ ] 双人分工任务能明确提示左玩家和右玩家各自目标。（证据：截图）
- [ ] 左/右玩家分别擦到自己的目标后，任务能完成并记录贡献。（证据：PlayMode 录屏）
- [ ] 共同擦除任务允许两个板擦共同累计同一目标进度。（证据：PlayMode 录屏）
- [ ] 玩家擦到对方目标或干扰项时有可见反馈，并影响本轮结果。（证据：PlayMode 录屏）
- [ ] 连续游玩中至少出现 3 个分工任务和 2 个共同擦除任务。（证据：人工流程记录或录屏）

## 依赖关系

依赖 04 双人校准和左右板擦、02 单人目标提示和擦除判定。

## 风险

双人任务提示如果过小或颜色不清，会导致误判。本切片需要同时关注 2-3 米大屏可读性，但真机验证放到 07。
