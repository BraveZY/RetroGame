# 双人校准和左右板擦

## 父级总任务

| 项目 | 内容 |
|---|---|
| 总任务 | 体感擦黑板 1-2 人 60 秒玩法闭环 |
| 子任务编号 | 04 |
| 覆盖范围 | 双人准备、左右玩家绑定、左板擦/右板擦、颜色/编号区分、双人模拟输入。 |

## 玩家可见结果

两名玩家进入双人模式后，可以看到左板擦和右板擦分别绑定到两个模拟输入，并通过颜色、编号或左右标识确认自己控制哪一个板擦。

## 需要实现的功能

- [ ] 双人模式准备界面显示左/右玩家站位或输入准备提示。
- [ ] 支持两个模拟体感输入源，分别驱动左板擦和右板擦。
- [ ] 左板擦/右板擦使用颜色、编号或左右标识区分。
- [ ] 两个板擦都被限制在黑板可擦区域内移动。
- [ ] 输入丢失时能提示对应玩家重新抬手或恢复输入。
- [ ] 身份混淆或输入未准备时保持校准状态，不直接进入正式任务。

## 隐含玩法语义

```text
两名值日生玩家 -> 想一起擦黑板 -> 左右站位/启用双输入 -> 系统绑定左板擦和右板擦 -> 两个板擦分别响应轨迹 -> 玩家确认自己身份和控制对象
```

## 涉及系统

双人输入、玩家身份绑定、板擦映射、校准状态、双人 HUD、输入丢失提示。

## 涉及资源

左板擦/右板擦颜色或编号变体、双人准备提示、左右玩家标识、双人 HUD 占位资源。

## 验收标准与证据

- [ ] 双人模式能显示两个不同颜色、编号或左右标识的板擦。（证据：截图）
- [ ] 两个模拟输入源能分别控制左板擦和右板擦。（证据：PlayMode 录屏）
- [ ] 任一输入未准备或丢失时，界面能指出对应玩家需要调整。（证据：截图/人工流程）
- [ ] 两个板擦都不能离开黑板可擦区域。（证据：PlayMode 录屏）
- [ ] 双人校准完成前不会开始正式任务刷新。（证据：人工流程）

## 依赖关系

依赖 01 单人准备、倒计时和板擦移动。

## 风险

真实摄像头双人身份识别不在本切片验收范围内；这里仅验证双人玩法对两个输入源和身份绑定的需求。
