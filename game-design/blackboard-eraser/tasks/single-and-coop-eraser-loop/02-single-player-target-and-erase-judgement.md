# 单人目标提示和擦除判定

## 父级总任务

| 项目 | 内容 |
|---|---|
| 总任务 | 体感擦黑板 1-2 人 60 秒玩法闭环 |
| 子任务编号 | 02 |
| 覆盖范围 | 单人目标生成、老师口令/字幕、高亮提示、目标擦除进度、干扰项擦错判定。 |

## 玩家可见结果

玩家能看到老师口令或字幕提示的目标内容，用单人板擦擦掉目标后获得完成反馈；擦到干扰项时看到擦错反馈。

## 需要实现的功能

- [ ] 提供至少三类单人任务数据：值日表/课程表、红圈错题错字、课间涂鸦。
- [ ] 每轮生成 1 个目标内容和若干干扰项。
- [ ] 显示老师口令/字幕、目标高亮框或箭头，明确告诉玩家要擦哪里。
- [ ] 板擦覆盖目标内容时累计擦除进度，并在达到阈值后完成任务。
- [ ] 板擦覆盖干扰项超过容错阈值时触发擦错反馈。
- [ ] 目标完成或失败后能刷新下一轮目标。

## 隐含玩法语义

```text
系统 -> 想让玩家快速找目标 -> 生成目标和干扰项 -> 用老师口令/字幕/高亮预警目标 -> 玩家移动板擦并覆盖目标 -> 目标内容响应擦除进度 -> 系统计入完成或擦错结果
```

## 涉及系统

任务系统、黑板内容系统、擦除判定、擦错判定、目标提示 UI、分数事件接口、配置数据。

## 涉及资源

Prototype/Placeholder 值日表或课程表、红圈错题错字、课间涂鸦、目标高亮、干扰项标记、擦除遮罩、基础粉笔灰反馈。

## 验收标准与证据

- [ ] 单人模式每轮只提示 1 个明确目标，玩家能从 UI 上看懂要擦哪里。（证据：截图/人工流程）
- [ ] 擦目标内容会增加进度并完成任务。（证据：PlayMode 录屏）
- [ ] 擦干扰项会触发擦错反馈，但不直接结束单局。（证据：PlayMode 录屏）
- [ ] 至少三类任务都能在连续游玩中出现。（证据：PlayMode 录屏或人工流程记录）
- [ ] 目标提示不依赖隐藏找错，所有目标都有口令/字幕/高亮之一。（证据：截图/人工流程）

## 依赖关系

依赖 01 单人准备、倒计时和板擦移动。

## 风险

擦除完成阈值、擦错容错和单题限时仍是待调参数。本切片可以使用原型默认值，但需要在后续调参记录中沉淀。

| 检查项 | 结果 |
