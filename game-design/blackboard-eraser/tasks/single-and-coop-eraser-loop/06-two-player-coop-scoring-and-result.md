# 双人协作连击、贡献和结算

## 父级总任务

| 项目 | 内容 |
|---|---|
| 总任务 | 体感擦黑板 1-2 人 60 秒玩法闭环 |
| 子任务编号 | 06 |
| 覆盖范围 | 双人 60 秒计时、协作连击、双人贡献、正确率、平均反应时间、团队评级和重开。 |

## 玩家可见结果

两名玩家能完整玩一局 60 秒双人协作模式，连续擦对会累积协作连击，结束后看到团队表现和双方贡献。

## 需要实现的功能

- [ ] 双人游戏状态运行 60 秒倒计时。
- [ ] 记录双人完成任务数、正确率、平均反应时间、最大协作连击和双人贡献。
- [ ] 连续完成分工或共同任务且未擦错时累积协作连击。
- [ ] 任一玩家擦错或任务超时时断协作连击或降低奖励。
- [ ] 60 秒结束后停止双人任务刷新和擦除判定。
- [ ] 双人结算界面展示完成任务数、正确率、平均反应时间、最大协作连击、双人贡献、评级和再来一局入口。

## 隐含玩法语义

```text
两名玩家 -> 想挑战团队成绩 -> 开始 60 秒协作单局 -> 完成分工/共同擦除任务 -> 系统统计团队结果和个人贡献 -> 时间结束停止场上流程 -> 结算展示团队表现并支持重开
```

## 涉及系统

双人玩法状态机、计时、团队计分、协作连击、贡献统计、双人结算 UI、重开流程。

## 涉及资源

双人 HUD、协作连击反馈、贡献条或贡献数字、团队结算面板、评级文本或图标。可使用占位 UI。

## 验收标准与证据

- [ ] 双人模式能运行完整 60 秒并自动进入结算。（证据：PlayMode 录屏）
- [ ] 连续完成至少 3 个双人任务会累积协作连击并在 HUD 或反馈中可见。（证据：PlayMode 录屏）
- [ ] 任一玩家擦错或任务超时会影响协作连击，且单局继续运行。（证据：PlayMode 录屏）
- [ ] 双人结算显示完成任务数、正确率、平均反应时间、最大协作连击、双人贡献和评级。（证据：截图）
- [ ] 再来一局会清理上一局双人统计、残留目标、贡献和计时状态。（证据：PlayMode 录屏或人工流程）

## 依赖关系

依赖 05 双人分工和共同擦除任务、03 单人 60 秒计分、连击和结算。

## 风险

双人贡献算法可能影响玩家感受，首版只要求贡献可见和一致，不把贡献权重定为最终数值。

## 切片完整性检查

| 检查项 | 结果 |
|---|---|
| 玩家可见闭环 | 合格：完整双人 60 秒协作单局可玩并结算。 |
| 动作链与粒度 | 合格：覆盖双人统计、连击和结算，不是横向 UI 任务。 |
| 追踪与验证 | 合格：引用父级总任务，可用录屏、截图和人工流程验证。 |
