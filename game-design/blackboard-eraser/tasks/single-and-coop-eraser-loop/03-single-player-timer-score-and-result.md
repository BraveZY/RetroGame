# 单人 60 秒计分、连击和结算

## 父级总任务

| 项目 | 内容 |
|---|---|
| 总任务 | 体感擦黑板 1-2 人 60 秒玩法闭环 |
| 子任务编号 | 03 |
| 覆盖范围 | 单人 60 秒计时、完成数、正确率、平均反应时间、个人连击、评级、重开。 |

## 玩家可见结果

玩家能完整玩一局 60 秒单人模式，擦对会累计分数和个人连击，擦错或超时会影响表现，结束后看到结算并能再来一局。

## 需要实现的功能

- [ ] 单人游戏状态运行 60 秒倒计时。
- [ ] 记录完成任务数、失败/擦错次数、正确率、平均反应时间和最大个人连击。
- [ ] 连续擦对时累积个人连击，并在 HUD 或反馈中体现。
- [ ] 擦错或单题超时时断连击或降低本轮奖励。
- [ ] 60 秒结束后停止任务刷新和擦除判定，进入结算界面。
- [ ] 结算界面展示完成任务数、正确率、平均反应时间、最大连击、评级和再来一局入口。

## 隐含玩法语义

```text
玩家 -> 想挑战 60 秒成绩 -> 开始单局计时 -> 连续接收目标并擦除 -> 系统统计完成/擦错/反应时间/连击 -> 时间结束停止场上流程 -> 结算展示表现并支持重开
```

## 涉及系统

玩法状态机、计时、计分、连击、结算 UI、任务刷新控制、重开流程、统计数据。

## 涉及资源

HUD 计时和分数文本、连击反馈、结算面板、评级文本或图标、按钮/输入提示。可使用占位 UI。

## 验收标准与证据

- [ ] 单人模式能运行完整 60 秒并自动进入结算。（证据：PlayMode 录屏）
- [ ] 连续完成至少 3 个目标会累积个人连击并在 HUD 或反馈中可见。（证据：PlayMode 录屏）
- [ ] 擦错或超时会断连击或降低奖励，且单局继续运行。（证据：PlayMode 录屏）
- [ ] 结算界面显示完成任务数、正确率、平均反应时间、最大连击和评级。（证据：截图）
- [ ] 再来一局会清理上一局统计、残留目标和计时状态。（证据：PlayMode 录屏或人工流程）

## 依赖关系

依赖 02 单人目标提示和擦除判定。

## 风险

评级和奖励数值未调优，首版只要求规则可见和数据正确，不把数值体验定为最终版。
