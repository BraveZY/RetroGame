# 单人准备、倒计时和板擦移动

## 父级总任务

| 项目 | 内容 |
|---|---|
| 总任务 | 体感擦黑板 1-2 人 60 秒玩法闭环 |
| 子任务编号 | 01 |
| 覆盖范围 | 单人准备界面、倒计时、单人板擦、模拟体感输入、黑板边界和基础 HUD。 |

## 玩家可见结果

玩家进入单人模式后，可以看到绿色黑板、单人板擦、准备/倒计时提示和基础 HUD，并用鼠标或调试输入控制板擦在黑板区域内移动。

## 需要实现的功能

- [ ] 创建或更新体感擦黑板原型场景，显示黑板游玩区域和基础 HUD。
- [ ] 支持单人准备状态，显示玩家识别/模拟输入准备提示。
- [ ] 支持 3 秒倒计时并进入 60 秒游戏状态。
- [ ] 使用模拟体感输入控制单人板擦移动。
- [ ] 将输入坐标映射到黑板区域，并限制板擦不能离开可擦边界。
- [ ] 在输入丢失或未开始时给出基础提示，不直接进入错误状态。

## 隐含玩法语义

```text
值日生玩家 -> 想开始擦黑板 -> 站入识别区/启用模拟输入 -> 系统显示准备与倒计时 -> 输入轨迹映射到黑板 -> 单人板擦移动并受边界限制 -> 玩家确认自己能控制板擦
```

## 涉及系统

玩法状态、模拟体感输入、板擦映射、黑板区域、HUD、场景、测试 seam。

## 涉及资源

Prototype/Placeholder 黑板背景、单人板擦 Sprite 或 Prefab、准备提示 UI、倒计时 UI、基础 HUD。无正式资源要求。

## 验收标准与证据

- [ ] 从准备界面可以进入倒计时，再进入游戏状态。（证据：PlayMode 录屏或人工流程）
- [ ] 单人板擦能随模拟输入在黑板区域内移动。（证据：PlayMode 录屏）
- [ ] 板擦移动到边缘时不会离开黑板可擦区域。（证据：PlayMode 录屏或人工流程）
- [ ] 输入未准备或丢失时屏幕有可读提示，且不会误开始正式擦除。（证据：截图/人工流程）
