# 游戏上下文

| 术语 | 含义 |
|---|---|
| 体感擦黑板 | 面向安卓大屏/电视盒子和电视摄像头的怀旧校园体感擦除玩法。 |
| 值日生玩家 | 现实中站在大屏前挥手控制板擦的玩家。 |
| 单人板擦 | 单人模式中跟随玩家手部或手臂轨迹移动的板擦。 |
| 左板擦/右板擦 | 双人协作时两名玩家分别控制的板擦，用颜色、编号或左右标识区分。 |
| 黑板内容 | 黑板上的粉笔字、表格、错题、涂鸦、口号和通知等可擦对象。 |
| 目标内容 | 本轮老师口令、字幕和高亮明确要求玩家擦掉的内容。 |
| 干扰项 | 同一块黑板上不应被擦除的非目标内容。 |
| 协作擦除任务 | 双人模式中的任务类型，两名玩家按左右分工擦不同目标，或共同擦除同一个大目标。 |
| 协作连击 | 双人连续完成擦除任务且没有擦错时累积的全队连击。 |
| 老师口令 | 当前任务提示来源，可由字幕、语音、铃声或黑板高亮共同表达。 |

| 范围 | 内容 |
|---|---|
| MVP | 1-2 人模式，玩家挥手控制板擦，根据老师口令、字幕和高亮提示擦指定黑板内容。 |
| 单人 | 1 名玩家控制 1 个板擦，快速反应找目标并擦除。 |
| 双人 | 2 名玩家协作，支持左右分工任务和共同擦除大目标。 |
| 不做 | 躲避玩法、沙包投掷/命中、隐藏找错、复杂文字识别、双人对抗、3 人及以上、剧情关卡。 |
