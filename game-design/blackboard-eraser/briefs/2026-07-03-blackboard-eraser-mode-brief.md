# 体感擦黑板模式 项目简报

| 项目 | 内容 |
|---|---|
| 一句话定位 | 面向安卓大屏/电视盒子和电视摄像头的怀旧校园体感擦黑板模式，1-2 名玩家通过挥手快速找到并擦掉老师指定的黑板内容。 |
| 游戏目标 | 在 60 秒内优先擦掉老师指定的高价值目标，争取更多小红花/值日星和更高“今日值日评分”；单局表现按完成目标数、目标价值、正确率、反应速度、连击和误擦次数判断。 |
| 目标玩家 | 家庭客厅、亲子娱乐、线下活动试玩用户，尤其对 90/00 年代小学教室有情怀记忆的玩家。 |
| 所属项目 | 放入同一 Unity 体感大屏产品中，但在 `game-design/blackboard-eraser/` 下作为独立小游戏维护。 |
| 首发平台 | Unity + 安卓大屏/电视盒子 + 电视摄像头。 |
| 输入方式 | 摄像头识别 1-2 名玩家的手部或手臂挥动，将体感轨迹映射为黑板上的 1-2 个板擦移动轨迹。 |
| 美术风格 | 中国 90/00 年代小学教室怀旧风：绿色黑板、粉笔字、红笔批改、课程表、值日表、下课铃、广播体操感；反馈可滑稽可爱，但不偏离怀旧主轴。 |
| MVP 目标 | 完成单局 60 秒单人/双人模式任务循环：明确提示目标内容和目标价值，玩家挥手擦除指定内容，系统按目标价值、正确率、反应速度、完成数和连击结算。 |

## 游戏目标

| 模式/场景 | 玩家目标 | 局内决策 | 结算或成功标准 |
|---|---|---|---|
| 单人模式 | 在 60 秒内尽量擦掉更多指定目标，优先拿高价值目标，刷新个人“值日评分”。 | 先擦近处普通目标求稳，还是冒险去擦远处/更小/限时更短的高分目标；是否为了连击放弃容易误擦的目标。 | 完成目标数、总分、小红花/值日星数量、正确率、平均反应时间、最大连击、误擦次数。 |
| 双人协作模式 | 两名玩家分工处理不同目标，尽量拿到更高团队值日评分。 | 一人稳擦普通目标、一人抢高价值目标；共同目标是否两人一起擦；出现左右分工时是否保持各自目标不抢擦。 | 团队总分、协作小红花、完成目标数、双人贡献、协作连击、误擦次数和共同目标完成率。 |
| 奖励目标 | 在普通任务之间出现短时奖励目标，例如“擦掉小红花旁边的错字”“擦到值日星”。 | 是否快速转向奖励目标，还是继续完成当前主目标保连击。 | 成功擦到奖励目标获得额外小红花、倍率或连击保护；误擦干扰项会损失奖励。 |

## 玩法说明

### 单人模式

1 名玩家站在大屏电视前，电视摄像头识别玩家挥手动作，屏幕上的一个板擦会跟随玩家手部/手臂轨迹在黑板上移动。每一轮系统会用老师口令、字幕和高亮框明确指定一个目标，例如“擦掉值日表里的名字”“擦掉红圈里的错别字”“擦掉右下角的涂鸦”。玩家需要快速找到目标并挥手擦除，擦对得分并累积连击，擦错非目标内容会断连击或扣少量分。

### 双人协作模式

2 名玩家站在大屏电视前，电视摄像头分别识别左右玩家的挥手动作。左侧玩家控制左板擦，右侧玩家控制右板擦，两个板擦用颜色、编号或左右标识区分。任务分为两种：一种是分工任务，例如“左边同学擦值日表，右边同学擦红圈错题”；另一种是共同任务，例如“两个人一起擦掉右下角的大涂鸦”。双人模式重点是协作分工，不做抢分对抗。

单局时长 60 秒，任务会连续刷新。玩法重点不是躲避，也不是把整块黑板全部擦干净，而是考验玩家能否在怀旧校园黑板场景中快速理解老师提示、判断目标价值、找到正确目标，并用体感挥手完成擦除。有些目标只是普通得分，有些目标会给小红花、值日星、倍率或连击保护。

| 步骤 | 玩家行为 | 系统反馈 |
|---|---|---|
| 1 | 单人：1 名玩家站到识别区域；双人：2 名玩家左右分开站位并抬手。 | 显示每名玩家对应的板擦映射位置，播放上课或下课铃式开局提示。 |
| 2 | 单人确认一个目标；双人确认左右分工或共同目标。 | 黑板上用框线、箭头、颜色、左右标识或字幕明确提示目标区域/内容，并显示普通/高分/奖励目标价值。 |
| 3 | 玩家快速挥手，把板擦移动到目标位置并擦除。 | 目标内容逐渐消失，擦对播放粉笔灰、板擦弹跳、分数、协作完成和可爱音效反馈。 |
| 4 | 玩家擦错非目标区域或反应太慢。 | 断连击、扣少量分或减少本轮奖励，并给出轻量滑稽提示。 |
| 5 | 60 秒结束。 | 按总分、小红花/值日星、正确率、平均反应速度、最大连击、完成任务数和误擦次数显示结算。 |

| 分类 | 内容 | 说明 |
|---|---|---|
| 关键系统 | 1-2 人摄像头手部/手臂轨迹输入、玩家区分、双板擦位置映射、黑板可擦区域、协作任务目标生成、擦除判定、连击和结算。 | 不继承丢沙包的躲避、投掷物和命中玩法，只复用同一体感大屏产品的技术与主题框架。 |
| 核心乐趣 | 快速反应找目标 + 目标价值取舍。 | 玩家听/看任务提示，马上找到目标并挥手擦掉；判断先擦稳妥目标还是抢高价值目标。 |
| MVP 任务类型 | 擦值日表/课程表、擦红圈错题错字、擦课间涂鸦、短时奖励目标；双人时加入左右分工任务和共同擦除大目标。 | 三类基础任务体现怀旧情怀，奖励目标提供游戏目标感和复玩动力。 |
| 情怀表达 | 值日生擦黑板、粉笔字、红笔批改、课程表、值日表、小学生涂鸦、老师口令、下课铃。 | 滑稽可爱元素只作为反馈调味，例如夸张口令、粉笔灰、板擦弹跳和擦错提示。 |
| 资源需求 | 黑板背景、粉笔字/错题/值日表/课程表/涂鸦素材、板擦、普通/高分/奖励目标标识、小红花/值日星、任务提示 UI、结算 UI、粉笔灰特效、老师口令和铃声音效。 | MVP 可用少量模板化内容组合生成任务，目标价值用图标和颜色区分。 |
| 技术约束 | 电视摄像头识别距离、客厅光照、双人手部追踪稳定性、玩家区分、输入延迟、安卓盒子性能、大屏远距离可读性。 | 首版应优先验证双板擦轨迹稳定、目标提示清晰、擦除反馈明显。 |
| 风险 | 双人识别互相干扰、左右玩家身份混淆、手部识别误差导致擦错、玩家挥手幅度过大难以精准定位、目标区域过小、目标价值提示不清、黑板内容远距离看不清。 | MVP 目标区域应偏大，提示要明显，普通/高分/奖励目标必须一眼能区分，擦除判定应有适度容错，并提供左右玩家校准。 |
| 不做范围 | 不做躲避玩法、不做沙包投掷/命中、不做隐藏找错、不做复杂文字识别、不做双人对抗、不做剧情关卡。 | 首版验证 1-2 人 60 秒体感擦黑板协作闭环。 |
| 验收方向 | 1-2 名玩家能在大屏前完成一局 60 秒游戏，理解老师提示、目标价值和双人分工，准确擦掉指定内容，并从结算中看懂自己为什么拿到高分或低分。 | 重点验证怀旧感、目标识别、目标价值取舍、体感操控、双人协作和反馈爽感。 |
