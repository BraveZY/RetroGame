# 游戏上下文

| 术语 | 含义 |
|---|---|
| 躲粉笔头 | 面向安卓大屏/电视盒子和电视摄像头的怀旧课堂体感闪躲玩法。 |
| 走神学生 | 玩家扮演的课堂角色，现实中站在大屏前通过左右闪和下蹲躲避。 |
| 老师视线检查 | 老师突然回头看课堂，玩家需要立刻站定装认真。 |
| 同学恶作剧 | 老师背对黑板写字时，同学从侧后方丢来粉笔头、纸团或橡皮。 |
| 粉笔头 | 同学恶作剧丢来的主要危险物，玩家需要躲开。 |
| 橡皮 | 偶尔飞来的奖励物，玩家接住后加分或恢复连击。 |
| 左右闪 | 玩家身体向左或向右移动，对应屏幕角色横向闪避。 |
| 下蹲 | 玩家下蹲或降低身体中心，对应屏幕角色躲过高位粉笔头。 |
| 装认真 | 老师回头检查时，玩家保持站定或做认真听课姿态，避免被判定为乱动。 |
| 反应连击 | 玩家连续躲开粉笔头或接住橡皮时累积的连击。 |

| 范围 | 内容 |
|---|---|
| MVP | 单人 60 秒课堂反应秀：老师背对时躲同学恶作剧丢来的粉笔头，接住橡皮加分；老师回头时立刻装认真。 |
| 不做 | 丢沙包规则、擦黑板规则、复杂课堂剧情、联网排行榜、3 人及以上、真实老师角色 AI。 |
