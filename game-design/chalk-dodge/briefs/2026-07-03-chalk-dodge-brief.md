# 躲粉笔头 项目简报

| 项目 | 内容 |
|---|---|
| 一句话定位 | 面向安卓大屏/电视盒子和电视摄像头的怀旧课堂体感反应游戏，玩家扮演上课走神的学生，在老师背对黑板时躲开同学恶作剧丢来的粉笔头，接住橡皮加分，并在老师回头时立刻装认真。 |
| 目标玩家 | 家庭客厅、亲子娱乐、线下活动试玩用户，尤其对 90/00 年代课堂、粉笔字、老师提醒和课桌教室氛围有记忆的玩家。 |
| 所属项目 | 放入同一 Unity 体感大屏产品中，但在 `game-design/chalk-dodge/` 下作为独立小游戏维护。 |
| 首发平台 | Unity + 安卓大屏/电视盒子 + 电视摄像头。 |
| 输入方式 | 摄像头识别玩家身体左右移动和下蹲动作，开发期可用键盘或调试输入模拟左闪、右闪、下蹲。 |
| 美术风格 | 中国 90/00 年代小学教室怀旧风：绿色黑板、讲台、粉笔盒、课桌、值日表、课堂纪律感；反馈可以滑稽可爱，但不做攻击性惩罚表达。 |
| MVP 目标 | 完成单人 60 秒循环：老师背对黑板写字时，同学恶作剧丢来粉笔头和橡皮；玩家左右闪/下蹲躲避粉笔头，接住橡皮加分；老师突然回头时玩家立刻站定装认真，结算展示躲避数、接住数、乱动次数、命中数和最大连击。 |

## 玩法说明

玩家站在大屏电视前，屏幕中是怀旧教室视角。系统用“上课走神但还要装认真”的情境开局：老师背对黑板写字时，后排或旁边同学开始恶作剧，丢来粉笔头、纸团或橡皮。玩家需要根据飞行物轨迹快速左右闪或下蹲躲开粉笔头；如果飞来的是橡皮，玩家可以主动接住获得额外分数。老师会突然回头检查课堂，这时所有恶作剧暂停，玩家必须立刻站定或做认真听课姿态；如果还在大幅闪躲，会被判定为上课乱动并扣分或断连击。单局时长 60 秒，节奏逐渐变快，重点考验反应速度、判断切换和动作识别稳定性。

| 步骤 | 玩家行为 | 系统反馈 |
|---|---|---|
| 1 | 玩家站入摄像头识别区，保持正对大屏。 | 显示走神学生、识别状态和老师背对黑板写字的开局提示。 |
| 2 | 老师背对时，同学恶作剧丢来粉笔头、纸团或橡皮。 | 屏幕给出轨迹预兆、破空音效和轻微夸张动画。 |
| 3 | 玩家向左/右闪或下蹲躲避。 | 躲开时加分、连击上升，角色做滑稽但可爱的闪避动作。 |
| 4 | 橡皮作为奖励物飞来，玩家移动到对应位置接住。 | 接住橡皮加分或恢复连击，播放轻快反馈。 |
| 5 | 老师突然回头时，玩家立刻站定装认真。 | 成功装认真保住连击；继续乱动会扣分或断连击。 |
| 6 | 玩家躲避失败、接错目标或老师回头时乱动。 | 命中/乱动反馈、断连击或扣少量分，不直接结束单局。 |
| 7 | 60 秒结束。 | 展示躲避数、接住橡皮数、乱动次数、命中数、最大连击和评级。 |

| 分类 | 内容 | 说明 |
|---|---|---|
| 关键系统 | 单人体感输入、左右闪/下蹲/站定识别、同学恶作剧事件、老师视线检查、粉笔头生成轨道、橡皮奖励物、躲避/接住/装认真判定、连击和结算。 | 与丢沙包、擦黑板共享体感大屏产品方向，但规则独立。 |
| 核心乐趣 | 快速反应切换。 | 玩家在“躲粉笔头、接橡皮、老师回头时别乱动”之间快速切换判断。 |
| MVP 内容 | 粉笔头危险物、橡皮奖励物、老师回头检查、4 种玩家状态：左闪、右闪、下蹲、站定装认真。 | 内容量可控，同时比纯躲避更有变化。 |
| 情怀表达 | 上课走神、同学恶作剧、老师突然回头、粉笔头、橡皮、绿色黑板、粉笔盒、讲台、课桌。 | 用轻喜剧表达课堂记忆，不强化真实惩罚或负面体验。 |
| 资源需求 | 教室背景、玩家学生角色、老师背对/回头提示、同学恶作剧提示、粉笔头、橡皮、轨迹预警、HUD、结算、课堂音效、命中/躲避/接住/装认真反馈。 | MVP 可先用 2D Sprite 和简单动效实现。 |
| 技术约束 | 摄像头识别距离、客厅光照、玩家左右移动幅度、下蹲识别稳定性、安卓盒子性能、大屏远距离轨迹可读性。 | 首版判定要有容错，粉笔头轨道和预警必须清楚。 |
| 风险 | 下蹲识别不稳定、站定装认真判定过严、玩家闪避幅度过大或过小、老师回头提示不明显、粉笔头速度过快导致挫败、橡皮和粉笔头视觉区分不清。 | 用明显颜色/形状区分奖励物和危险物，老师回头前给短预兆，前 20 秒降低速度。 |
| 不做范围 | 不做沙包投掷传接规则、不做擦黑板目标擦除、不做复杂课堂剧情、不做多人对抗、不做 3 人及以上、不做联网排行榜。 | 首版只验证单人 60 秒反应躲避闭环。 |
| 验收方向 | 玩家能理解“粉笔头要躲、橡皮要接、老师回头要装认真”，能用左右闪、下蹲和站定完成一局，并从结算看懂表现好坏。 | 重点验证怀旧感、输入识别、轨迹读性、状态切换、反馈爽感和难度节奏。 |
