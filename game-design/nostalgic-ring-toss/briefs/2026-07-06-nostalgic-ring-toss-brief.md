# 怀旧套圈 项目简报

| 项目 | 内容 |
|---|---|
| 一句话定位 | 面向安卓大屏/电视盒子和电视摄像头的体感套圈游戏，支持单人 60 秒高分挑战和双人 60 秒同时 PK，玩家用挥手动作投圈，套中 80-90 年代中国怀旧奖品。 |
| 游戏目标 | 在 60 秒内尽可能套中高价值奖品，获得更高分数和更多怀旧奖品收藏；单人追求刷新高分，双人追求分数超过对手。 |
| 目标玩家 | 家庭客厅、亲子娱乐、线下活动试玩用户，以及对 80-90 年代夜市/庙会套圈摊有怀旧记忆的玩家。 |
| 所属项目 | 放入同一 Unity 体感大屏产品中，在 `game-design/nostalgic-ring-toss/` 下作为独立小游戏维护。 |
| 首发平台 | Unity + 安卓大屏/电视盒子 + 电视摄像头。 |
| 输入方式 | 单人模式识别 1 名玩家；双人模式按站位绑定左右玩家。系统识别手部/手臂向前挥的方向、速度和幅度，并用半真实抛物线把手势映射为带平滑、容错和轻微修正的投圈轨迹。 |
| 视角与场景 | 斜俯视 2.5D 夜市/庙会路边套圈摊。单人使用全屏摊位，双人使用左右分屏摊位；每个摊位都有近/中/远三排奖品。 |
| 美术风格 | 中国 80-90 年代怀旧夜市/庙会风：彩灯、手写价格牌、摊布、塑料筐、旧报纸、红布垫底和远距离可读的怀旧奖品。 |
| MVP 目标 | 完成单人和双人共用的 60 秒套圈闭环：玩家就位倒计时、自动上圈、辅助轨迹预览、挥手投圈、宽松命中判定、奖品收走补货、比分和奖品收藏结算；双人模式额外支持左右分屏同时 PK。 |

## 游戏目标

| 模式 | 玩家目标 | 局内决策 | 结算结果 |
|---|---|---|---|
| 单人高分挑战 | 60 秒内尽量拿到更高总分，刷新个人最好成绩。 | 在容易命中的近排低分物和更难命中的中/远排高分物之间取舍；看到稀有奖品时决定是否冒险去套。 | 展示总分、最高价值奖品、本局奖品收藏清单和是否刷新高分。 |
| 双人同时 PK | 60 秒内分数超过对手。 | 在保证命中率和抢高分奖品之间取舍，同时观察自己与对手的实时分差。 | 展示左右玩家总分、胜负、本局奖品收藏清单和最高价值奖品。 |

玩家每 10 秒的核心追求是：看准当前最值得套的奖品，抬手预览落点，挥手投圈，确认命中或落空，然后立刻继续下一次投掷。

## 玩法说明

单人模式中，1 名玩家站在大屏电视前，控制全屏套圈摊，在 60 秒内尽量套中更多高价值奖品，结算时展示总分和本局奖品收藏清单。

双人模式中，2 名玩家站在大屏电视前，系统按摄像头画面左右站位绑定玩家。左侧玩家控制左屏套圈摊，右侧玩家控制右屏套圈摊。两边摊位结构、奖品池、分数和补货规则一致，只共享 60 秒倒计时和最终胜负结算。

每名玩家每次自动拿到一个圈。玩家抬手进入准备状态，屏幕显示大致落点或淡色辅助轨迹；玩家向前挥手后，圈按半真实抛物线飞出。挥手方向决定大致左右/远近，速度影响力度，系统通过轨迹平滑、命中容错和轻微修正保证体感爽感与公平性。

套中物品后，物品播放命中特效并飞入本局奖品收藏清单，原位置短暂空出后从同一排同档位奖池随机补货。没套中不扣分，只损失时间，玩家可以马上投下一个圈。60 秒结束后，单人模式展示总分和奖品收藏；双人模式左右分别展示总分、胜负和本局获得的怀旧奖品清单。

| 步骤 | 玩家行为 | 系统反馈 |
|---|---|---|
| 1 | 单人：1 名玩家站到摄像头识别区；双人：两名玩家按左/右站位进入识别区。 | 单人显示玩家已就位；双人显示左/右玩家已就位。满足当前模式人数后进入 3 秒倒计时。 |
| 2 | 玩家抬手准备投圈。 | 对应分屏显示当前圈、淡色抛物线或大致落点预览。 |
| 3 | 玩家向前挥手投圈。 | 圈按半真实抛物线飞出，轨迹根据方向、速度和幅度生成，并做适度平滑和容错。 |
| 4 | 圈落到奖品附近。 | 覆盖物品中心或主要碰撞区则算套中；擦边播放差一点反馈但不加分；落空后快速回到下一圈。 |
| 5 | 玩家套中奖品。 | 奖品弹跳/闪光，飞入奖品收藏栏，按距离基础分和稀有度加成计分，原位置同档位随机补货。 |
| 6 | 60 秒结束。 | 单人展示总分和奖品收藏；双人左右分别展示总分、胜负、本局获得的奖品缩略图和数量。 |

| 分类 | 内容 | 说明 |
|---|---|---|
| 关键系统 | 模式选择、玩家就位识别、双人站位绑定、单边识别状态、自动上圈、准备姿势、辅助轨迹预览、半真实抛物线、宽松命中判定、奖品收走与补货、分数和结算。 | 第一版支持单人高分挑战和双人同时投圈 PK；双人两边不互相干扰，只比较分数。 |
| 目标区结构 | 单人使用全屏近/中/远三排固定摊位；双人左右分屏各自使用同结构三排摊位。 | 近排更容易、基础分低；远排更难、基础分高。双人左右两边结构一致，保证公平。 |
| 奖品池 | 严格使用 80-90 年代中国常见怀旧物件，第一版每排 5-6 种，共 15-18 种。 | 采用混合怀旧摊：玩具、零食、文具和家用小物混摆。 |
| 奖品示例 | 近排可用弹珠、洋画片、跳跳糖、小贴纸；中排可用铁皮青蛙、文具盒、塑料水枪、磁带；远排可用随身听、收音机、小霸王手柄、搪瓷杯、变形玩具。 | 具体清单进入 GDD 时再定稿，需筛掉明显晚于 90 年代或远距离不易识别的物品。 |
| 计分规则 | 基础分 + 稀有度加成。 | 示例：近排基础 10，中排基础 30，远排基础 60；普通 +0，稀有 +10，经典大奖 +20。数值后续可调。 |
| 稀有出现 | 同排奖池低概率出现稀有和经典奖品。 | 补货不跨排，避免破坏三排难度和分数结构。 |
| 失败规则 | 没套中不扣分、不消耗有限圈数，只损失时间。 | 保持 60 秒限时高分的轻快节奏。 |
| 识别丢失 | 单人模式玩家丢失时暂停投掷并提示回到识别区；双人模式某一方短暂丢失时，只暂停该方投掷，另一方继续。 | 恢复识别后回到准备状态；60 秒倒计时默认继续。 |
| 美术需求 | 单人全屏摊位、双人左右分屏摊位、近/中/远三排奖品、投圈、辅助轨迹、落点预览、命中特效、奖品飞入收藏栏、结算收藏清单。 | 双人左右玩家需要明显颜色区分，例如蓝色/红色圈和轨迹；单人可使用默认玩家色。 |
| 音效需求 | 倒计时、投圈破空、命中弹跳、落空、补货、得分、胜负结算、夜市/庙会氛围。 | 可在后续 GDD 中细化摊主吆喝和怀旧环境音。 |
| 技术约束 | 普通电视摄像头的识别稳定性、单/双人模式切换、双人左右站位、手部/手臂速度估计、输入延迟、安卓盒子性能、分屏后电视远距离可读性。 | 不依赖精细手指识别；第一阶段可用模拟输入验证轨迹、命中和补货闭环。 |
| 主要风险 | 真实手势抛物线难调、摄像头噪声影响公平、单人全屏和双人分屏的 UI 适配、两人同时挥手互相遮挡、辅助轨迹过强导致像瞄准游戏、奖品过小导致电视上看不清。 | 用半真实抛物线、宽松判定、大目标核心区、左右分屏和同结构奖池降低风险。 |
| 不做范围 | 不做全真实物理抛投、不做共享摊位抢同一奖品、不做道具干扰、不做中央事件、不做复杂连击成长、不做联网排行榜、不做长期养成。 | 第一版只验证单人 60 秒高分挑战和双人分屏 60 秒套圈 PK 是否清楚、好玩、公平。 |
| 验收方向 | 单人玩家能完成一局 60 秒高分挑战；两名玩家能完成一局 60 秒同时 PK；玩家能理解抬手预览和挥手投圈，能明显看懂套中、落空、补货、分数变化和最终胜负。 | 重点验证体感投掷手感、奖品获得感、双人左右公平性和大屏可读性。 |
