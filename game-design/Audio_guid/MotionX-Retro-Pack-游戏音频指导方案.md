# MotionX Retro Pack / 游戏音频指导方案

> 本文是 `MotionX Retro Pack / 时光体感馆` 的全项目音频制作与接入指导。适用于主题馆、首页、准备页、单局 Gameplay、结算、奖励、语音口令、Unity 音频表和外包音频制作需求。

配套文档：

- [MotionX-Retro-Pack-AI音频生成提示词指南.md](./MotionX-Retro-Pack-AI音频生成提示词指南.md)：用于 AI 生成音乐、音效、环境声和短口令候选素材。

## 1. 音频 DNA

一句话定义：

> 今天客厅里的家庭体感节拍，带一点爸妈小时候听过的场景声音。

本项目音频不是“复古音乐包”，而是服务 `家庭共同参与 + 童年场景记忆 + 1-3 分钟短局体感 + 明亮现代 UI + 原创安全表达` 的游戏声音系统。

| 构成 | 占比 | 职责 | 判断标准 |
| --- | ---: | --- | --- |
| 体感节奏 | 45% | 帮助玩家知道何时动、停、命中、连击 | 不看画面也能跟上节拍 |
| 场景记忆 | 30% | 让家长听出操场、街机、电视节目等童年场景 | 3 秒内有明确场景联想 |
| 轻复古音色 | 15% | 提供 80/90 年代生活碎片，不做复刻 | 点到为止，不喧宾夺主 |
| 家庭温度 | 10% | 保持温暖、轻松、失败友好 | 孩子失败后愿意继续玩 |

音频最高原则：

> 声音先服务身体动作，再触发童年记忆；怀旧是调味，不是主菜。

## 2. 总体风格

| 维度 | 应该是 | 不应该是 |
| --- | --- | --- |
| 情绪 | 明亮、热闹、亲切、轻松、可分享 | 昏暗、压抑、成人怀旧展、严肃运动测试 |
| 音乐 | 稳定节拍、短循环、原创动机、轻复古音色 | 真实老歌、仿名曲旋律、长剧情配乐 |
| 音效 | 清楚、短促、可重复听、和动作同步 | 刺耳警报、重惩罚、复杂噪声 |
| 语音 | 像广播、老师、街机机器、电视节目主持人在招呼玩家 | 技术提示、产品说明、长旁白 |
| 怀旧 | 下课铃、口哨、广播、投币、电视雪花的原创变体 | 真实节目、真实街机、真实影视或品牌音源 |

## 3. 音频类型

项目音频分为 8 类。

| 类型 | 用途 | 资产形态 | 典型时长 | 是否循环 |
| --- | --- | --- | ---: | --- |
| 主题馆 BGM | 主题入口、选游戏页、主题主页氛围 | `bgm_theme_*` | 30-60s | 是 |
| 单局 Gameplay Loop | 游戏中持续节奏，驱动体感动作 | `bgm_game_*_loop` | 45-90s | 是 |
| 入戏开场提示音 | 进入单局前建立场景和身份 | `jingle_*` / `stinger_*` | 3-8s | 否 |
| 倒计时 / 节拍提示 | 开始前、节奏玩法、时间临近 | `sfx_countdown_*` / `sfx_beat_*` | 0.1-3s | 视情况 |
| 交互 UI 音效 | 选择、确认、返回、卡片翻页、奖励弹出 | `sfx_ui_*` | 0.08-0.8s | 否 |
| 游戏反馈音效 | 命中、失败、连击、道具、目标刷新、分数跳动 | `sfx_game_*` | 0.08-1.2s | 否 |
| 场景记忆音效 | 下课铃、口哨、广播、投币、电视开机等 | `sfx_memory_*` / 主题前缀 | 0.2-4s | 视情况 |
| 结算 / 奖励音乐 | 分数、称号、徽章、贴纸、收藏 | `stinger_result_*` / `sfx_reward_*` | 0.5-4s | 否 |

制作优先级：

| 优先级 | 类型 | 原因 |
| --- | --- | --- |
| P0 | Gameplay Loop | 决定体感节奏是否成立 |
| P0 | 游戏反馈音效 | 决定动作确认和爽感 |
| P0 | 倒计时 / 节拍提示 | 决定开始点和跟拍稳定性 |
| P0 | 入戏开场提示音 | 决定主题场景是否立住 |
| P1 | 场景记忆音效 | 强化父母的回忆触发 |
| P1 | 结算 / 奖励音乐 | 强化完成感和收藏感 |
| P1 | UI 音效 | 提升产品质感 |
| P2 | 主题馆 BGM 扩展版本 | 后续丰富主题大厅体验 |

## 4. 音频总线

| Bus | 内容 | 优先级 | 规则 |
| --- | --- | ---: | --- |
| `BGM` | 主题馆 BGM、Gameplay Loop、结算音乐 | 2 | 不能压过倒计时、口令和核心反馈 |
| `AMB` | 操场、河边、客厅、街机环境底噪 | 1 | 只做空间感，默认低音量 |
| `UI` | 菜单、按钮、卡片、奖励收集 | 4 | 高频触发也不能刺耳 |
| `SFX` | 命中、失败、连击、道具、目标变化 | 5 | 游戏动作反馈优先 |
| `VOICE` | 广播、老师、机器、节目主持口令 | 6 | 出现时压低 `BGM` / `AMB` |
| `COUNTDOWN` | 3、2、1、开始、最后 10 秒 | 7 | 最高优先级，必须清楚 |

混音规则：

| 场景 | 规则 |
| --- | --- |
| 语音出现 | `BGM` / `AMB` 降低 4-8 dB |
| 倒计时出现 | `COUNTDOWN` 不被任何音效遮挡 |
| 命中反馈 | 与视觉命中同帧或延迟不超过 80ms |
| 高频分数 tick | 限频，避免一秒内堆成噪声 |
| 连击音 | 最多 3 个强度层级，不能无限升高 |
| 失败音 | 比成功音短 20%-40%，音色更轻 |
| 暂停 | 停止 Gameplay Loop 或低通淡出，不继续紧张倒计时 |
| 恢复 | 播放短恢复提示，不重播完整入戏音 |

## 5. 音乐制作规范

### 5.1 BPM 范围

| 强度 | BPM | 适用玩法 | 听感 |
| --- | ---: | --- | --- |
| 轻松亲子 | 95-110 | 热身、低龄玩家、轻节奏跟做 | 舒服、可跟、不催促 |
| 标准短局 | 115-130 | 多数 1-3 分钟体感小游戏 | 清楚、热闹、稳定 |
| 高能挑战 | 135-150 | 街机挑战、连击、反应、冲刺 | 更兴奋，但不压迫 |

### 5.2 Loop 结构

Gameplay Loop 建议使用 4 层结构，便于动态混音：

| 层 | 内容 | 用途 |
| --- | --- | --- |
| `Base` | 主节拍、低频脉冲、基础律动 | 游戏常态循环 |
| `Action` | 拍手、木块、电子 blip、口风琴短音 | 强化动作节奏 |
| `Tension` | 最后 10 秒加速层、轻上扬音型 | 时间临近 |
| `Success` | 连击高光层、短亮片段 | 高分或连击阶段 |

要求：

- Loop 必须无缝循环。
- 旋律动机短，避免长旋律抢走动作注意力。
- 不模仿真实老歌、广播体操、影视、动画或街机旋律。
- 复古音色只做局部点缀，不能牺牲清晰度。
- BGM 在电视外放、手机扬声器和耳机下都要能听清节拍。

## 6. 主题馆音频方向

### 6.1 童年操场

音频关键词：下课铃、口哨、操场广播、粉笔线、脚步、同学欢呼。

| 类型 | 方向 |
| --- | --- |
| 主题 BGM | 口风琴 / 木琴 / 轻打击 + 操场广播质感，明亮课间感 |
| 入戏提示音 | 下课铃短响 + 广播启动 + 口哨预备 |
| Gameplay Loop | 鼓点清楚，适合跑停、跳跃、侧移、冻结 |
| 成功音 | 哨声短亮、粉笔星星、队旗亮起、同学轻欢呼 |
| 失败音 | 轻刹车、粉笔小滑、温和提醒，不像惩罚 |
| 结算音 | 广播表扬 + 贴纸落册 + 小范围欢呼 |

禁止：

- 真实学校广播录音。
- 真实广播体操音乐或可识别旋律。
- 刺耳体育哨长鸣。

### 6.2 客厅街机

音频关键词：投币、机器启动、灯牌、计分跳动、高分榜、按钮。

| 类型 | 方向 |
| --- | --- |
| 主题 BGM | 明亮电子节拍 + 轻 chiptune 点缀 + 家庭客厅温度 |
| 入戏提示音 | 投币成功 + 灯牌亮起 + 机器启动 |
| Gameplay Loop | 节拍更紧，适合挥臂、反应、投篮、出拳 |
| 成功音 | 计分跳动、灯牌亮、短上扬 blip |
| 失败音 | 轻回弹、机器小提示，不做负面 buzzer |
| 结算音 | 高分上榜、分数滚动、灯牌收束 |

禁止：

- 使用真实街机、游戏机、掌机或品牌音源。
- 过度 synthwave 导致风格偏成人霓虹。
- 像赌博机、抽卡或付费老虎机的音效。

### 6.3 家庭电视健身

音频关键词：电视开机、轻雪花、频道切换、节目片头、原创节拍、主持口令。

| 类型 | 方向 |
| --- | --- |
| 主题 BGM | 电视节目暖场 + 明确节拍 + 轻家庭综艺感 |
| 入戏提示音 | 电视开机 + 频道切换 + 节目标题短音 |
| Gameplay Loop | 稳定拍点，支持抬膝、挥臂、深蹲、拍手 |
| 成功音 | 同步达标、节拍亮起、节目提示音 |
| 失败音 | 轻偏拍提示，不像错误警报 |
| 结算音 | 节目收尾 + 家庭掌声 + 徽章亮起 |

禁止：

- 模仿真实电视台、真实主持人或经典节目口号。
- 过重雪花噪声。
- 把口令做成健身教练训话。

## 7. 页面与状态触发

| 页面 / 状态 | 主要音频 | 目标 |
| --- | --- | --- |
| 启动 / 健康提示 | 极轻品牌提示，可无 | 不制造等待负担 |
| 登录页 | 贴纸册、纸张、轻品牌音 | 不像普通账号表单 |
| 首页 | 主题切换 UI 音 + 轻环境 | 像翻到一段回忆 |
| 进入主题馆 | 主题入场提示音 + 环境声 | 先听出场景 |
| 主题主页 | 主题 BGM + 卡片切换音 | 保持浏览氛围 |
| 游戏选择 | 卡片聚焦、确认、返回 | 操作清楚但不吵 |
| 入戏开场 | 场景提示音 + 短口令 | 回答“我在哪里、我是谁” |
| 站位准备 | 就绪音、集合音、轻口令 | 隐藏技术检测感 |
| 倒计时 | 3、2、1、开始 | 给明确动作起点 |
| 游戏中常态 | Gameplay Loop + 核心反馈 | 服务体感动作 |
| 连击 / 高光 | 连击层、短欢呼、分数亮音 | 强化爽感 |
| 时间临近 | 加速层或短倒计时提示 | 有紧张感但不刺耳 |
| 暂停 | BGM 淡出或低通 | 立即降低紧张 |
| 结算 | 分数确认、称号、奖励音 | 先清楚结果，再给记忆 |
| 奖励 / 收藏 | 贴纸、徽章、卡片入册 | 有“收下了”的满足感 |

## 8. 游戏事件音效规则

| 事件 | 音效方向 | 时长 | 变体 | 限制 |
| --- | --- | ---: | ---: | --- |
| 选择 | 木块 / 纸片 / 小电子点 | 0.08-0.18s | 4 | 最多 10 次/秒 |
| 确认 | 明亮短促，有进入感 | 0.15-0.35s | 3 | 页面切换播放一次 |
| 返回 | 轻弹回、纸张收起 | 0.12-0.25s | 2 | 立即响应 |
| 玩家就绪 | 温和确认，像轮到你 | 0.3-0.6s | 3 | 每个玩家独立 |
| 全员就绪 | 集合完成，进入倒计时 | 0.6-1.2s | 2 | 只播一次 |
| 倒计时 tick | 清楚拍点 | 0.2-0.4s | 2 | 最高优先级 |
| 开始 | 明亮启动音 | 0.4-0.8s | 2 | 对齐游戏开始帧 |
| 命中 | 短、亮、上扬 | 0.15-0.5s | 4 | 不能盖住下一次动作 |
| 连击 | 逐级增强 | 0.4-0.8s | 3 | 最多 3 层 |
| 失误 | 轻、短、可继续 | 0.2-0.6s | 3 | 同玩家 1 秒内最多一次 |
| 道具出现 | 有发现感，不像抽卡 | 0.4-1s | 3 | 不能像付费奖励 |
| 分数 tick | 轻快跳分 | 0.08-0.18s | 5 | 最多 12 次/秒 |
| 新纪录 | 更亮、更完整 | 0.8-1.5s | 2 | 可短暂 duck BGM |
| 结算分数 | 成绩落牌 / 盖章 | 0.5-1s | 3 | 先于奖励音 |
| 奖励获得 | 贴纸、徽章、收藏 | 0.6-1.4s | 3 | 不叠抽卡感音效 |

## 9. 语音与口令

语音不是长旁白，只做短口令和场景人格。

| 主题 | 口令人格 | 示例方向 |
| --- | --- | --- |
| 童年操场 | 广播 / 老师 / 同学招呼 | `下课了，站到队伍里`、`老师看过来了，别动` |
| 客厅街机 | 机器提示 / 围观喊声 | `投币成功`、`挑战启动`、`看看谁能上榜` |
| 家庭电视健身 | 节目主持 / 家庭口令 | `站到电视前`、`跟上节拍`、`全家一起` |
| 河边 / 游园扩展 | 同伴招呼 / 摊主 | `轮到你了`、`这颗真会飞`、`再来一下` |

口令规范：

- 单句优先 2-6 个字，最长不超过 10 个字。
- 首次教学可以稍长，但不能超过 2.5 秒。
- 不说 `校准`、`骨骼识别`、`算法检测`、`识别失败`。
- 不模仿真实主持人、影视台词、经典节目口号。
- 失败口令不能嘲笑儿童或家长。
- 高频反馈不依赖语音，语音只做关键状态和偶发高光。

## 10. 动态播放策略

| 机制 | 要求 |
| --- | --- |
| 随机变体 | 高频音效至少 3 个变体，核心命中建议 4-6 个 |
| Pitch 微调 | UI、脚步、分数 tick 可做 ±3%；口令和倒计时不随机变调 |
| 音量微调 | 高频同类 SFX 可做 ±1.5 dB 随机 |
| 同类限频 | 失败、选择、分数 tick、脚步必须限频 |
| 优先级抢占 | `COUNTDOWN` > `VOICE` > 核心 `SFX` > `UI` > `BGM` > `AMB` |
| Ducking | `VOICE` / `COUNTDOWN` 出现时自动压低背景 |
| Fade | 环境声进入 / 退出 0.3-0.8 秒淡入淡出 |
| Layer | BGM 可按游戏状态打开 `Tension` / `Success` 层 |
| Stop | 游戏结束时 Gameplay Loop 先淡出，再播放结算 |
| Resume | 暂停恢复只播短提示，不重播完整提示音 |

## 11. Unity 接入建议

### 11.1 Audio Mixer Group

建议建立以下 Mixer Group：

```text
Master
  BGM
  AMB
  UI
  SFX
  VOICE
  COUNTDOWN
```

建议暴露参数：

| 参数 | 用途 |
| --- | --- |
| `MasterVolume` | 总音量 |
| `BgmVolume` | 背景音乐 |
| `SfxVolume` | 游戏反馈和 UI |
| `VoiceVolume` | 语音口令 |
| `AmbVolume` | 环境声 |
| `BgmDuckAmount` | 语音 / 倒计时压低 BGM |

### 11.2 事件命名

建议所有音频通过事件 ID 触发，不直接在玩法代码里引用文件名。

| 事件 ID | 示例文件 | 说明 |
| --- | --- | --- |
| `ui.select` | `sfx_ui_select_v01.wav` | 通用选择 |
| `ui.confirm` | `sfx_ui_confirm_v01.wav` | 通用确认 |
| `game.countdown.tick` | `sfx_countdown_tick_v01.wav` | 倒计时 |
| `game.start` | `sfx_start_go_v01.wav` | 开始 |
| `game.hit` | 玩法专属命中音 | 命中 |
| `game.miss.soft` | 玩法专属轻失败 | 失败 |
| `game.combo.tier1` | 玩法专属连击 1 | 连击 |
| `result.score.show` | `sfx_result_stamp_v01.wav` | 分数出现 |
| `reward.card.collect` | `sfx_reward_card_v01.wav` | 奖励收下 |

### 11.3 音频表字段

建议每条资产进入 Unity 前记录以下字段：

| 字段 | 说明 |
| --- | --- |
| `AudioId` | 唯一 ID |
| `FilePath` | 文件路径 |
| `Bus` | `BGM` / `AMB` / `UI` / `SFX` / `VOICE` / `COUNTDOWN` |
| `Category` | 主题或玩法分类 |
| `Priority` | 播放优先级 |
| `Loop` | 是否循环 |
| `Volume` | 默认音量 |
| `PitchRandom` | 是否允许随机音高 |
| `Variants` | 同事件变体列表 |
| `Cooldown` | 同类触发冷却 |
| `DuckBgm` | 是否压低 BGM |
| `FadeIn` | 淡入时间 |
| `FadeOut` | 淡出时间 |
| `PlatformNote` | 平台压缩或音量备注 |

## 12. 文件命名与目录

### 12.1 命名格式

```text
<type>_<scope>_<event>_v<version>.<ext>
```

| 类型 | 前缀 | 示例 |
| --- | --- | --- |
| BGM | `bgm` | `bgm_pg_game_loop_v01.wav` |
| 环境声 | `amb` | `amb_pg_playground_loop_v01.wav` |
| UI 音效 | `sfx_ui` | `sfx_ui_confirm_v01.wav` |
| 游戏 SFX | `sfx` | `sfx_pg_whistle_soft_v01.wav` |
| 语音 | `vo` | `vo_pg_ready_line_v01.wav` |
| 提示音 / 强调音 | `jingle` / `stinger` | `jingle_arcade_coin_start_v01.wav` |

### 12.2 Scope 建议

| Scope | 含义 |
| --- | --- |
| `global` | 全局通用 |
| `ui` | UI 通用 |
| `pg` | Playground / 童年操场 |
| `arcade` | 客厅街机 |

## 16. 版权与安全红线

| 禁止项 | 原因 | 替代方向 |
| --- | --- | --- |
| 真实老歌 / 儿歌 / 广播体操音乐 | 版权风险 | 原创短动机、口风琴、木质打击 |
| 模仿名曲旋律 | 版权和识别风险 | 只保留情绪，不保留旋律轮廓 |
| 真实影视 / 综艺 / 动画音效 | IP 风险 | 抽象化节目感、广播感 |
| 真实街机 / 游戏机采样 | IP 和品牌风险 | 原创 chiptune / 投币 / 计分音 |
| 真实学校广播录音 | 版权 / 隐私风险 | 自制广播质感短口令 |
| 明星教练 / 主持人口吻 | 肖像和识别风险 | 原创亲切主持人格 |
| 刺耳警报 / 嘲笑失败 | 不适合亲子 | 温和提醒、轻回弹、短失败音 |
| 过重 VHS / 磁带噪声 | 影响清晰度 | 干净轻怀旧 |
| 赌博 / 抽卡 / 付费感音效 | 产品气质不符 | 贴纸、徽章、奖状、上榜音 |

## 17. 验收清单

| 检查项 | 通过标准 |
| --- | --- |
| 场景识别 | 不看画面也能听出操场、街机、电视健身或具体玩法场景 |
| 动作帮助 | 玩家能通过节拍、倒计时和反馈知道什么时候动 |
| 反馈清楚 | 命中、失败、连击、时间临近互不混淆 |
| 失败友好 | 失败音不刺耳、不羞辱、不像严重错误 |
| 家庭适配 | 电视外放不吵，儿童和家长都能接受 |
| 短局适配 | 1-3 分钟反复播放不疲劳 |
| UI 适配 | UI 音短、清楚、频繁触发不烦 |
| 混音优先级 | 倒计时和语音不会被 BGM / 环境声盖住 |
| 变体充足 | 高频音效有足够变体，避免机械重复 |
| 版权安全 | 没有真实老歌、影视、品牌、街机或可识别采样 |
| 风格统一 | 明亮、家庭、童年场景、轻怀旧、原创安全 |
| 技术可接入 | 命名、Bus、循环、变体、触发点和规格完整 |

## 18. 一句话制作 Brief

给音频制作方的短 Brief：

> 为 MotionX Retro Pack 制作一套明亮、亲切、适合家庭体感的原创游戏音频。音乐要有清楚节拍，帮助玩家在 1-3 分钟短局里跟着动；音效要短促、爽快、失败友好；场景记忆来自下课铃、口哨、广播、投币、电视开机、节目节拍等原创变体。不要使用真实老歌、影视、街机、品牌、明星或可识别 IP 声音。整体听感像今天客厅里的家庭游戏，把爸妈小时候的课间、街机和电视节目重新做成一套干净、明亮、现代的声音。
