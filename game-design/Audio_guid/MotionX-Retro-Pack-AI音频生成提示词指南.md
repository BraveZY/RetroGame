# MotionX Retro Pack / AI 音频生成提示词指南

> 本文用于指导使用 AI 生成 `MotionX Retro Pack / 时光体感馆` 的背景音乐、游戏音效、环境声和短口令候选素材。它是 [MotionX-Retro-Pack-游戏音频指导方案.md](./MotionX-Retro-Pack-游戏音频指导方案.md) 的配套 Prompt 文档。

## 1. 使用原则

AI 音频生成只负责产出候选素材，最终仍需人工筛选、剪辑、混音、命名和 Unity 接入。

| 原则 | 要求 |
| --- | --- |
| 以中文 Prompt 为主 | 项目主打中国 90 年代童年记忆，中文更容易保留语境 |
| 保留少量音频术语 | `BPM`、`loop`、`one-shot`、`SFX`、`UI`、`BGM` 可保留 |
| 一次生成一个明确资产 | 不要用一个 Prompt 生成整套音效库 |
| Prompt 必须写场景和动作 | 不能只写“复古音效”或“童年音乐” |
| 优先生成 P0 资产 | 倒计时、命中、失败、确认、Gameplay Loop 优先 |
| 保持原创安全 | 不提真实歌曲、影视、动画、街机、品牌、明星、节目名称 |
| 声音干净明亮 | 不做重 VHS、脏噪、恐怖、刺耳警报 |
| 失败反馈友好 | 不做嘲笑、惩罚、危险警告 |

项目音频核心句：

> 明亮、温暖、适合家庭体感的原创游戏音频；用中国 90 年代童年场景声音做轻记忆触发，但不复刻任何真实歌曲、节目、街机、品牌或 IP。

## 5. One-shot SFX 提示词

### 5.1 通用命中成功音

```text
生成一个家庭体感游戏的短命中成功音效。场景是<主题场景>，触发是玩家成功命中目标。声音要短、亮、上扬，有“做到了”的感觉；加入来自场景的轻材质提示，例如粉笔、木牌、投币灯牌、电视节目提示音。时长0.2-0.5秒，one-shot，混音清晰，适合频繁重复。不要刺耳警报、赌博机音效、抽卡音、真实街机采样、知名游戏音效。
```

### 5.2 通用轻失败音

```text
生成一个家庭体感游戏的轻失败音效。场景是<主题场景>，触发是玩家差一点成功但没有命中。声音要轻、短、友好，像温和提醒，不要羞辱、不危险、不沉重。可以用轻弹回、木块小落下、粉笔小滑、柔和下行音。时长0.2-0.6秒，one-shot，音量低于成功音。不要失败号角、刺耳 buzzer、嘲笑声、恐怖音、重低频撞击。
```

### 5.3 倒计时 Tick

```text
生成一个家庭体感游戏倒计时 tick 音效，用于3、2、1开始前。声音要短促、清楚、有准备感，能在背景音乐上方听清，但不刺耳。可用木块轻敲、铃鼓短点、清脆小铃或口哨前的预备感。时长0.2-0.35秒，one-shot。不要闹钟刺耳声、军训倒计时、赌博机 beep、真实电视节目音效、真实采样。
```

### 5.4 UI 确认音

```text
生成一个明亮童年感家庭游戏的 UI 确认音。触发是进入主题或开始挑战。声音设计：贴纸轻拍、纸张小响、短促清亮 chime，温暖、有触感、干净。时长0.15-0.35秒，one-shot，适合菜单频繁使用。不要手机抽卡音、赌博奖励音、品牌通知音、知名 App UI 音。
```

## 10. 生成后筛选标准

| 检查项 | 通过标准 |
| --- | --- |
| 场景是否清楚 | 不看画面也能听出大致场景 |
| 动作是否清楚 | 玩家能理解成功、失败、倒计时或开始 |
| 是否足够短 | 高频 SFX 不拖尾、不遮挡下一次动作 |
| 是否家庭友好 | 不刺耳、不恐怖、不嘲笑 |
| 是否原创安全 | 没有可识别歌曲、节目、街机、品牌或名人特征 |
| 是否可循环 | Loop 没有明显接缝 |
| 是否可混音 | 不自带过重混响、压缩、噪声或大动态 |
| 是否可重复听 | 高频资产连续播放不烦 |
| 是否符合 MotionX | 明亮、亲子、童年场景、轻怀旧、录音干净、混音清晰 |

## 12. AI 生成工作流

| 步骤 | 输出 |
| --- | --- |
| 1. 从音频指导方案选资产 | 明确 ID、Bus、触发点、时长、变体 |
| 2. 填写单资产生成卡片 | 得到可复制中文 Prompt |
| 3. 每个资产生成 4-8 个候选 | 保留原始候选 |
| 4. 初筛版权和风格风险 | 删掉像真实歌、真实节目、街机采样的版本 |
| 5. 剪辑和响度统一 | 去静音、裁尾、统一同类响度 |
| 6. 做变体组 | 命名为 `v01`、`v02`、`v03` |
| 7. Unity 接入测试 | 检查触发、限频、ducking、loop |
| 8. 大屏外放验收 | 用电视或外放检查刺耳和清晰度 |
