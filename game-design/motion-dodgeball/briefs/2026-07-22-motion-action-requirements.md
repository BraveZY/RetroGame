# 体感丢沙包动作需求

| 项目 | 内容 |
|---|---|
| 游戏名称 | 体感丢沙包（Motion Dodgeball） |
| 文档用途 | 游戏动作与识别需求清单 |

> 状态：动作语义已整理；当前可运行输入为共享键盘。摄像头 SDK、动作数值阈值与目标设备验证均待确认，不得视为已实现。

## 输入范围与角色

| 玩家 / 角色 | 单人 | 双人 | 三人 | 当前键盘替代 | 后续体感输入 |
|---|---:|---:|---:|---|---|
| 1P / 躲避者 C | 人类 | 人类 | 人类 | `A/D` | 身体横向位置，控制躲避区 X 轴左右移动 |
| 2P / 上侧投手 A | AI | 人类 | 人类 | `J/L` 瞄准，`I` 出手 | 身体横向位置瞄准；明显挥臂请求出手 |
| 3P / 下侧投手 B | AI | AI | 人类 | `←/→` 瞄准，`↑` 出手 | 身体横向位置瞄准；明显挥臂请求出手 |

## 角色动作与动作需求

命名格式：`MotionDodgeball_<角色>_<动作>[_方向]`。原型资源加 `Prototype_` 前缀，例如 `Prototype_MotionDodgeball_DodgerC_Move_Left`。

| ID | 角色 | 动作 | 动作资产命名 | 触发 / 识别需求 | 反馈与保护 | 状态 |
|---|---|---|---|---|---|---|
| ACT-01 | 躲避者 C / 1P | 待机 | `MotionDodgeball_DodgerC_Idle` | 准备、无横向输入或移动停止时播放 | 保持面向场地；不产生额外输入 | 键盘已实现 |
| ACT-02 | 躲避者 C / 1P | 横向躲避 | `MotionDodgeball_DodgerC_Move_Left` / `MotionDodgeball_DodgerC_Move_Right` | 单/双/三人中，锁定玩家横向位置映射为中间躲避区 X 轴；键盘替代为 `A/D` | 角色同步横移，到边界反馈；不使用前后移动、下蹲、侧身或精细手势；丢失识别时保持当前位置 | 键盘已实现；体感待接入 |
| ACT-03 | 躲避者 C / 1P | 受击 | `MotionDodgeball_DodgerC_Hit` | 沙包与 C 的碰撞区重叠 | 扣 1 条生命、受击闪烁和短反馈；第三次命中提前结算 | 键盘路径可验；体感无关 |
| ACT-04 | 上侧投手 A / 2P | 待机 | `MotionDodgeball_ThrowerA_Idle` | 无瞄准、投掷或接球状态时播放 | 维持上侧投手位，不改变持球状态 | 键盘已实现 |
| ACT-05 | 上侧投手 A / 2P | 横向瞄准 | `MotionDodgeball_ThrowerA_Aim_Left` / `MotionDodgeball_ThrowerA_Aim_Right` | 双/三人中，2P 的横向位置映射到 A 的所属 lane；键盘替代为 `J/L` | 更新投手位置/瞄准；不得跨 lane；识别丢失后禁止继续瞄准 | 键盘已实现；体感待接入 |
| ACT-06 | 上侧投手 A / 2P | 挥臂投掷 | `MotionDodgeball_ThrowerA_Throw` | 明显挥臂产生一次性出手请求；键盘替代为 `I`；仅 A 持球、2P 已参与且识别有效时生效 | 投掷预警、出手和沙包轨迹；未持球、未参与或识别丢失时不得出手 | 需设备验证 |
| ACT-07 | 上侧投手 A / 2P | 接球 | `MotionDodgeball_ThrowerA_Catch` | 沙包未命中 C 后，A 成为接球投手 | 接住或回收沙包，进入下一次持球循环 | 键盘路径可验 |
| ACT-08 | 下侧投手 B / 3P | 待机 | `MotionDodgeball_ThrowerB_Idle` | 无瞄准、投掷或接球状态时播放 | 维持下侧投手位，不改变持球状态 | 键盘已实现 |
| ACT-09 | 下侧投手 B / 3P | 横向瞄准 | `MotionDodgeball_ThrowerB_Aim_Left` / `MotionDodgeball_ThrowerB_Aim_Right` | 三人中，3P 的横向位置映射到 B 的所属 lane；键盘替代为 `←/→` | 更新投手位置/瞄准；不得跨 lane；识别丢失后禁止继续瞄准 | 键盘已实现；体感待接入 |
| ACT-10 | 下侧投手 B / 3P | 挥臂投掷 | `MotionDodgeball_ThrowerB_Throw` | 明显挥臂产生一次性出手请求；键盘替代为 `↑`；仅 B 持球、3P 已参与且识别有效时生效 | 投掷预警、出手和沙包轨迹；未持球、未参与或识别丢失时不得出手 | 需设备验证 |
| ACT-11 | 下侧投手 B / 3P | 接球 | `MotionDodgeball_ThrowerB_Catch` | 沙包未命中 C 后，B 成为接球投手 | 接住或回收沙包，进入下一次持球循环 | 键盘路径可验 |
| ACT-12 | 沙包 | 飞行 | `MotionDodgeball_Sandbag_Fly` | 持球投手出手后进入飞行状态 | 显示清晰飞行轨迹；供躲避与命中判定使用 | 键盘路径可验 |
| ACT-13 | 沙包 | 命中 | `MotionDodgeball_Sandbag_Hit` | 沙包与 C 的碰撞区重叠 | 驱动 C 受击反馈与生命扣除 | 键盘路径可验 |
| ACT-14 | 1P / 2P / 3P | 站位与身份锁定 | `N/A`（HUD/校准表现另行命名） | 广角摄像头按左/中/右横向分区锁定身份 | 显示分区、校准状态与角色归属；不要求现实前后站位；未识别保持等待 | 体感待接入 |
| ACT-15 | 已锁定的 C / A / B | 识别丢失与恢复 | `N/A`（HUD 状态表现另行命名） | 识别状态由有效变丢失或恢复 | 对局不暂停、AI 不替换；C 保持位置，投手禁用瞄准/出手；回到原分区后恢复输入 | 需设备验证 |
| ACT-16 | 全部人类玩家 | 非目标动作过滤 | `N/A` | 前后移动、下蹲、侧身、精细手势不读取为有效输入 | 不产生移动、瞄准或出手；教学不应要求这些动作 | 体感待接入 |

## 识别 Adapter 最小数据契约

| 数据 | 提供对象 | 用途 | 当前边界 |
|---|---|---|---|
| 横向位置 | 按 owner 提供给 C/A/B | C 左右躲避；A/B lane 内瞄准 | 坐标归一化、死区、平滑和延迟预算待确认 |
| 一次性挥臂请求 | 按 owner 提供给 A/B | 接入既有“持球才能出手”的门控 | 动作特征、阈值、冷却、防连发待确认 |
| 识别状态 | 按 owner 提供给 C/A/B | 处理输入失效与恢复 | 丢失时长、恢复去抖、置信度门槛待确认 |
| 左/中/右分区 | 1P/2P/3P | 准备阶段锁定玩家身份 | 分区边界、锁定持续时间、遮挡策略待确认 |

## 明确不做与待确认

| 分类 | 内容 |
|---|---|
| 不做 | C 接沙包/反杀、复杂骨骼识别、联网、多关卡剧情。 |
| 不作为输入 | 前后移动、下蹲、侧身、精细手势；不应进入教学或判定。 |
| 待确认 | 摄像头 SDK、设备权限、光照/背景/距离、横向映射曲线、动作阈值、丢失与恢复时长、性能预算。 |
| 回归保护 | 必须保留无摄像头的 Editor 键盘路径；设备验证不能替代键盘回归。 |
