# 体感丢沙包 项目简报

| 项目 | 内容 |
|---|---|
| 一句话定位 | `童年操场`主题馆中的 1-3 人复古 2D 体感丢沙包子游戏：1P 在 100 秒内横向躲避上下两侧投来的沙包。 |
| 游戏目标 | 以 3 条生命坚持 100 秒；第三次受击即淘汰，时间结束时仍有生命即胜利，并按剩余生命给出纯生存评级。 |
| 目标玩家 | 家庭客厅、亲子娱乐、线下活动试玩的 1-3 人用户。 |
| 当前验证平台 | Unity Editor + 共享键盘；安卓大屏/电视盒子与摄像头体感后续验证。 |
| 输入方式 | 同一键盘：1P-C 为 `A/D`，2P-A 为 `J/L + I`，3P-B 为 `←/→ + ↑`；未参与当前模式的按键无效。 |
| 视角与场地 | 俯视 45 度角场地，投手位于上、下两侧，躲避者位于中间区域。 |
| 完整子游戏范围 | 支持单人、双人、三人 100 秒对局：模式选择、键盘输入、倒计时、投手投掷、躲避、命中扣生命、结算与重开；体感后续接入。 |

## 游戏目标

| 模式/场景 | 玩家目标 | 局内决策 | 结算或成功标准 |
|---|---|---|---|
| 单人 100 秒生存 | 扮演躲避者 C，在 100 秒内躲开上下投手 A/B 投来的沙包，并以 3 条生命坚持到时间结束。 | 根据持球投手位置、投掷预警和沙包轨迹，只向左或向右移动以避开命中区。 | 第三次命中立即淘汰；存活到时间结束即胜利，并按剩余生命显示 A/B/C 纯生存评级。 |
| 双人 100 秒对局 | 1P 是躲避者 C，2P 是上侧投手 A，下侧投手 B 由 AI 控制。 | 1P 用 `A/D` 横向躲避；2P 用 `J/L + I` 瞄准并出手。 | C 存活到时间结束则躲避者胜；C 第三次受击则投手阵营胜。 |
| 三人 100 秒对局 | 1P 是躲避者 C，2P 和 3P 分别是上侧投手 A、下侧投手 B。 | 1P 用 `A/D` 横向躲避；2P 用 `J/L + I`，3P 用 `←/→ + ↑` 瞄准并出手。 | C 存活到时间结束则躲避者胜；C 第三次受击则投手阵营胜。 |

玩家每 10 秒的核心追求是：观察当前持球投手，看清投掷预警和沙包轨迹，快速移动身体躲开命中区，然后立刻准备下一次上下夹击。

| 步骤 | 玩家行为 | 系统反馈 |
|---|---|---|
| 1 | 玩家选择人数模式并查看角色与按键说明。 | 显示当前模式、角色归属和准备提示。 |
| 2 | 当前持球投手 A 或 B 向中间躲避者 C 投出沙包。 | 沙包沿清晰轨迹飞过中间区域，并有投掷预警。 |
| 3 | 玩家通过身体左右移动躲避。 | 躲避成功增加统计，近距离擦过可给出强化反馈。 |
| 4 | 沙包命中玩家轮廓区域。 | 扣除生命，播放命中特效、音效和短暂受击反馈。 |
| 5 | 沙包未命中时，对侧投手接住或回收沙包，准备下一次投掷。 | 显示接球/回收反馈，持球状态切换到下一名投手。 |
| 6 | 100 秒结束或第三次受击。 | 根据是否存活和剩余生命显示 A/B/C 评级与课间称号。 |

| 分类 | 内容 | 说明 |
|---|---|---|
| 关键系统 | `GameSessionManager` 协调模式、阵容与单局流程；共享键盘输入、C 躲避输入、投手瞄准/出手、AI 投手、A/B 持球与接球循环、沙包轨迹、命中判定、生命和结算各自拥有具体规则。 | 支持 1-3 人，不引入游戏包级全局 Manager。 |
| 美术风格 | 明亮干净的童年操场，俯视 45 度角，原创小学生三人组和清晰沙包轨迹。 | 大屏远距离观看时，投手、玩家、沙包轨迹必须容易识别。 |
| 资源需求 | 3 个角色位、沙包、童年操场场地、入场/HUD/结算 UI、下课铃、短口哨和基础反馈音效。 | 下课铃与短口哨均为原创素材；原型阶段可使用占位资源。 |
| 技术约束 | 首轮用共享键盘验证；后续安卓盒子性能、普通摄像头稳定性、识别延迟、房间光照和站位距离。 | 不依赖精细骨骼，后续优先保证低延迟和少误判。 |
| 风险 | 共享键盘不能证明体感体验；沙包速度与公平性、后续摄像头误判和围观环境识别干扰仍需设备验证。 | 当前先完成键盘闭环，体感接入后单独验证。 |
| 不做范围 | 不做 C 接沙包/反杀、不做前后移动/下蹲/侧身输入、不做复杂骨骼识别、不做联网、不做多关卡剧情。 | A/B 接球属于投手循环；多人模式仅扩展玩家角色归属。 |
| 验收方向 | 三种人数模式都可完整入场、校准、开始、游玩、受击、躲避、接球/回收、结算和重开；已锁定玩家识别丢失时不暂停、不替换 AI。 | 重点验证低门槛、好看懂、动作反馈明显。 |
