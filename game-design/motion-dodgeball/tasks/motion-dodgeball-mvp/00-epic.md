| 项目 | 内容 |
|---|---|
| 玩家可见结果 | 玩家能站到识别区域，在 60 秒内躲避上下两侧 AI 投手传接并投来的沙包，并看到命中、生命、躲避次数、结算和重开。 |
| MVP 范围 | 准备流程、单人输入映射、AI 投手传接、单颗沙包轨迹、命中扣生命、躲避统计、60 秒结算、重开。 |

| 验收口径 | 一局可完整开始、游玩、命中、躲避、结算和重开；每个子任务都能独立验证玩家可见结果。 |

## 总体验收标准

- [ ] 玩家可以从准备状态进入 3 秒倒计时，再进入 60 秒游玩状态。（证据：UnityCaptain/录屏/人工流程）
- [ ] 玩家能通过模拟输入控制躲避者 C 在中间区域移动。（证据：PlayMode/录屏/人工流程）
- [ ] 上下两侧投手能围绕同一颗沙包完成投掷、未命中后的接球和下一次投掷，沙包轨迹清晰可见。（证据：UnityCaptain/录屏/人工流程）
- [ ] 沙包命中会扣生命并有明确反馈，未命中会统计躲避成功。（证据：PlayMode/录屏/人工流程）
- [ ] 60 秒结束或生命耗尽后显示结算。（证据：PlayMode/录屏/人工流程）
- [ ] 结算后可以重开，时间、生命、统计和场上沙包被正确重置。（证据：PlayMode/录屏/人工流程）

## 风险与约束

| 风险/约束 | 影响 | 应对 |
|---|---|---|
| 摄像头方案未确认 | 真实体感输入可能延迟或不稳定。 | MVP 先使用模拟输入，保留可替换输入层。 |
| 安卓盒子性能有限 | 特效、识别和场景复杂度需要控制。 | 先在 Editor 验证闭环，再做真机优化。 |
| 大屏远距离可读性 | 玩家和围观者可能看不清沙包轨迹。 | 投掷预警、拖尾、角色剪影和 HUD 需要优先清晰。 |
| 命中判定公平性 | 体感延迟会放大命中争议。 | 命中区域和沙包速度保留调参空间。 |
