## 玩家可见结果

沙包命中躲避者 C 时会扣生命并出现明确反馈；沙包穿过中间区域但未命中时，会统计为躲避成功。

## 需要实现的功能

- [ ] 躲避者 C 的命中区域。
- [ ] 沙包与躲避者的命中判定。
- [ ] 命中扣生命逻辑。
- [ ] 躲避成功统计。
- [ ] 命中次数统计。
- [ ] 受击、擦身或躲避成功的基础反馈。
- [ ] 生命耗尽时提前进入结算状态的触发点。

## 验收标准

- [ ] 沙包与躲避者 C 命中区域重叠时判定命中。（证据：PlayMode/录屏/人工流程）
- [ ] 命中后生命减少，HUD 立即更新。（证据：PlayMode/录屏/人工流程）
- [ ] 命中后有清楚的视觉或音频反馈。（证据：截图/录屏/人工流程）
- [ ] 沙包离开中间区域且未命中时，躲避次数增加。（证据：PlayMode/录屏/人工流程）
- [ ] 命中次数能正确统计。（证据：PlayMode/录屏/人工流程）
- [ ] 生命归零时触发提前结算。（证据：PlayMode/录屏/人工流程）

## 风险

- 命中区域过大会显得不公平，过小会削弱玩法压力。
- 体感输入延迟会放大命中判定争议，需要保留调参空间。
