# 60 秒单局结算与重开

## 父级总任务

| 项目 | 内容 |
|---|---|
| 总任务 | [体感丢沙包单人 60 秒 MVP](00-epic.md) |
| 子任务编号 | 05 |
| 覆盖范围 | 60 秒结算、生命耗尽提前结算、结算 UI、评级、重开和状态重置。 |

## 玩家可见结果

玩家完成 60 秒生存或生命耗尽后，看到结算界面，包含剩余生命、躲避次数、命中次数和评级，并可以快速再来一局。

## 需要实现的功能

- [ ] 60 秒计时结束后的结算流程。
- [ ] 生命耗尽后的提前结算流程。
- [ ] 结算界面信息展示。
- [ ] 简单评级规则。
- [ ] 再来一局流程，重置时间、生命、统计和场上沙包。
- [ ] 一局完整开始、游玩、结算、重开的闭环。

## 涉及系统

- 游戏状态流程
- 计时器
- 生命与计分
- 结算 UI
- 重开流程

## 涉及资源

- 结算界面占位 UI
- 评级表现占位
- 重开按钮或重开输入提示
- 结算音效占位

## 验收标准

- [ ] 60 秒结束后自动进入结算界面。（证据：PlayMode/录屏/人工流程）
- [ ] 生命耗尽时可以提前进入结算界面。（证据：PlayMode/录屏/人工流程）
- [ ] 结算界面显示剩余生命、躲避次数、命中次数和评级。（证据：截图/录屏/人工流程）
- [ ] 再来一局会重置时间、生命、躲避次数、命中次数和场上沙包。（证据：PlayMode/录屏/人工流程）
- [ ] 连续游玩 3 局不会出现状态残留。（证据：录屏/人工流程）
- [ ] 完整闭环满足 GDD 的单人 MVP 验收方向。（证据：人工流程/GDD 对照）

## 风险

- 状态重置遗漏会导致后续局残留沙包、计数或生命。
- 评级规则如果过早复杂化，会拖慢 MVP 闭环完成。
