## 玩家可见结果

玩家打开玩法场景后，能看到俯视 45 度角的丢沙包场地：投手 A/B 位于上下两侧，躲避者 C 位于中间区域。玩家可以从准备状态进入 3 秒倒计时，再进入 60 秒单局。

## 需要实现的功能

- [ ] 俯视 45 度角 MVP 场地布局。
- [ ] 上侧投手 A、下侧投手 B、中间躲避者 C 的占位表现。
- [ ] 中间躲避区和上下投手站位。
- [ ] 准备界面、3 秒倒计时、进入游玩状态的基础流程。
- [ ] 基础 HUD 占位：剩余时间、生命、躲避次数、命中次数。

## 验收标准

- [ ] 场景中能清楚看到上下两侧投手和中间躲避者。（证据：UnityCaptain 截图/场景状态）
- [ ] 中间躲避区边界可见或可理解。（证据：UnityCaptain 截图/人工流程）
- [ ] 玩家可以从准备状态进入 3 秒倒计时。（证据：PlayMode/录屏/人工流程）
- [ ] 倒计时结束后进入 60 秒游玩状态。（证据：PlayMode/录屏/人工流程）
- [ ] HUD 显示剩余时间、生命、躲避次数、命中次数的占位信息。（证据：UnityCaptain 截图/人工流程）
- [ ] 当前切片不需要真实投掷、命中或体感输入。（证据：代码/场景检查）

## 依赖关系

无。父级总任务：`00-epic.md`。

## 风险

- 45 度俯视角可能导致上下投手和中间区域的空间关系不够清楚。
- HUD 如果过早占用中间区域，会影响后续沙包轨迹可读性。
