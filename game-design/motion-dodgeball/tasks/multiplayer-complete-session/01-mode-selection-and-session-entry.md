## 玩家可见结果

玩家在童年操场场景中选择 1/2/3 人后，能直接看懂 C、A、B 的 owner 与键位，并进入对应阵容的 3 秒倒计时和 100 秒对局；不设置独立准备页面。

## 需要实现的功能

- [x] 模式选择展示单人、双人、三人及其固定角色归属。
- [x] 将选择结果创建为可读取的阵容配置：1P-C 固定，A/B 按模式分配人类或 AI。
- [x] 以 100 秒和初始 3 命初始化单局规则，并保留 3 秒倒计时。
- [x] 在模式选择/HUD 中显示当前模式与角色 owner 的占位反馈。

## 本轮实现记录

- `DodgeballSession` 保存模式、A/B 投手 owner、100 秒、3 命和倒计时；内部 `Ready` 状态承载 `1/2/3` 选择与 `Space/Enter` 开始，但不对应独立 UI 页面。
- 已确认不设置 `ReadyPanel`；`Enter/Space` 从模式选择直接进入倒计时。
- 模式选择 Canvas 实现已撤下，等待新的效果图后再按 `UI-HUD-FLOW-SPEC.md` 和效果图重新制作。

## 隐含玩法语义

`玩家 -> 选择人数并查看固定角色/键位 -> Enter/Space -> 3 秒倒计时 -> 以正确阵容开始 100 秒对局`。
