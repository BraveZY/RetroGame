## 玩家可见结果

所有模式中，C 撑过 100 秒时显示躲避者胜和课间称号；C 第三次受击时显示投手阵营胜。结算能读出 C 的 A/B/C 评级、剩余生命与投手阵营命中数，并可重开同一模式。

## 需要实现的功能

- [x] 以 100 秒、初始 3 命驱动单局规则；第三次命中立即结束。
- [x] 结算依据结果原因判定躲避者或投手阵营胜，并计算 C 的 A/B/C 评级。
- [x] 记录投手阵营命中数；AI 与人类命中都归入同一阵营统计。
- [x] HUD 显示时间、生命、躲避、命中、当前模式；结算显示胜负、评级、课间称号和重开提示。
- [x] 重开恢复阵容、时间、生命、统计、持球权和沙包，不遗留上一局对象。

## 本轮实现记录

- C 撑到时间结束为 `Dodger` 胜；3 次命中为 `Throwers` 胜。满 3 命存活为 A，带伤存活为 B，投手获胜为 C。
- `R` 已改为保留当前模式、重置运行时对象并直接进入 3 秒倒计时；`Esc` 返回模式选择。EditMode 测试覆盖模式保留、倒计时和统计重置，实际按键流程仍待 PlayMode 录屏。

## 隐含玩法语义

`100 秒计时或第三次命中 -> 停止投掷/飞行 -> 汇总生命与命中 -> 判定阵营胜负 -> 展示评级/称号 -> R 以同一阵容进入 3 秒倒计时 / Esc 返回模式选择`。

## 涉及系统

回合规则、命中/躲避统计、阵营统计、HUD、结算 UI、沙包清理、模式配置、EditMode/PlayMode 测试。

## 现有行为影响与保护

影响 `SinglePlayerReadyFlow` 的 60 秒默认值、`Rating` 和 ResultReason；必须保持 3 秒倒计时、命中扣 1 命、单人生命/躲避/命中统计和 R 重开调试路径。

## 涉及资源

现有 HUD TextMesh；新增 `Placeholder_` 模式、阵营胜负、课间称号和投手命中数文本。
