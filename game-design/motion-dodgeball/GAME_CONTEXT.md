# 游戏上下文

| 术语 | 含义 |
|---|---|
| 体感丢沙包 | `童年操场`主题馆中的支持 1-3 人的复古体感子游戏：保留传统三人丢沙包的上下对峙关系，躲避者在中间横向躲避。 |
| 躲避者 C | 1P 控制的中间角色，目标是在 100 秒内躲避沙包；正式体验只允许左右移动。 |
| 投手 A | 位于场地上侧的投手；单人时由 AI 控制，双人和三人时由 2P 控制。 |
| 投手 B | 位于场地下侧的投手；单人和双人时由 AI 控制，三人时由 3P 控制。 |
| 持球投手 | 当前持有沙包并准备向躲避者 C 投掷的投手，可能是 A 或 B。 |
| 接球投手 | 沙包未击中 C 后，主动移动到沙包飞出方向接球的对侧投手。 |
| 沙包 | A/B 之间传接并投向躲避者 C 的主要危险物；完整单局按单颗沙包循环处理。 |
| 躲避区 | 45 度俯视 2D 场地中央的横向活动区；C 只能沿 X 轴移动，不使用前后纵深作为核心输入。 |
| 当前键盘输入 | 当前实现阶段使用同一键盘：1P-C 为 `A/D`，2P-A 为 `J/L` 瞄准与 `I` 出手，3P-B 为 `←/→` 瞄准与 `↑` 出手；未参与当前模式的按键无效。 |
| 未来 2D 体感输入 | 后续摄像头识别玩家身体的横向位置，并映射为 C 的左右移动、投手的横向瞄准与挥臂；不依赖前后移动、精细手势或复杂骨骼。 |
| 横向分区 | 后续一台广角摄像头按左/中/右站位锁定 1P、2P、3P 身份；视觉中的上下投手位不要求玩家在现实空间前后站位。 |
| 单人 100 秒生存 | 单局目标：在 100 秒内躲避沙包；初始 3 命，第三次受击即淘汰，时间结束仍有生命即胜利。 |
| 纯生存评级 | 结算只依据是否存活至时间结束与剩余生命给出 A/B/C，不使用连击、掉落道具或长期养成。 |
| 阵营胜负 | C 存活至 100 秒则躲避者胜；C 第三次受击则投手阵营胜。结算同时展示 C 的生存评级和投手阵营命中数。 |
| 识别丢失 | 后续体感模式中，已锁定玩家丢失识别时游戏不暂停也不由 AI 替换；躲避者保持当前位置，投手不能继续瞄准或挥臂出手。 |
| 课间称号 | 纯生存评级的玩家可见称号：A 级为“课间小冠军”，B 级为“躲闪小能手”，C 级为“再来一局”。 |
| GameSessionManager | 子游戏的单局流程 owner，协调人数模式、键盘输入入口、倒计时、对局、结算与重开；不拥有投掷、沙包飞行或 HUD 的具体规则。 |

| 范围 | 内容 |
|---|---|
| 单局完整范围 | 单人、双人、三人模式；当前以键盘模式选择、倒计时、100 秒对局、结算和重开为实现范围。单人是 1P + 2 AI，双人是 1P + 2P + 1 AI，三人是 1P + 2P + 3P；体感校准后续接入。 |
| 不做 | C 接沙包/反杀、复杂骨骼识别、联网、多关卡剧情。 |
| 场景与角色 | 明亮、干净的童年操场；原创小学生三人组，C 在中间、A/B 在上下两端。 |
| 记忆锚点 | 原创下课铃用于入场，原创短口哨用于倒计时和投掷预警；不得使用真实校园铃声、现成音乐或可识别 IP 音效。 |
