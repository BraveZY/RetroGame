# 时光体感馆移动端字符原型草图

> 本文单独定义 `MotionX Retro Pack / 时光体感馆` 移动端手机原型。移动端不是大屏端的遥控器，也不是奖励册；它是独立的随身复古体感产品。移动端与大屏端共用同一套游戏内容、规则、奖励和单局流程，但 UI 按竖屏浏览、横屏识别 / 游戏、近距离阅读、摄像头权限和保存分享重新组织。

> 当前手机 / 平板 MVP 的页面流程、触控交互、权限 / 横屏取景、移动端结算奖励和保存分享，以本文为原型 authority。大屏端远距离信息层级参考见 [大屏端字符游戏界面草图](./MotionX-Retro-Pack-ASCII游戏界面草图.md)。

## 1. 使用边界

- 设备：首页、主题、结算、奖励、收藏、设置以竖屏为主；入戏式识别和正式游戏画面使用手机横屏。
- 操作：触控选择，游戏中以摄像头体感为主，少量按钮用于暂停、继续、退出。
- 内容：沿用大屏端首版内容池，包括 `童年操场`、`客厅街机`、`电视健美操`。
- 流程：进入首页 -> 选择主题 -> 选择 / 确认当前玩法 -> 入戏式识别 -> 游戏中 -> 结算 -> 奖励卡片。
- 不做：把电视端 UI 直接缩小、不把手机做成电视遥控器、不在首页展示密集运营位。

## 2. 页面层级与主流程

```
移动端首页
  -> 主题详情页
      -> 玩法确认
          -> 权限 / 横屏取景 / 入戏式识别
              -> 游戏中
                  -> 暂停页
                  -> 结算界面
                      -> 奖励卡片
                          -> 分享 / 保存 / 再来一局
```

移动端关键调整：

- 首页从大屏三门洞改成竖屏主题卡，不做电视大厅透视构图。
- 主题页保留当前主玩法，但增加“今日推荐”和“换个玩法”的触控入口。
- 准备页先处理摄像头权限，再提示用户横过手机、放稳设备并进入横屏识别。
- 游戏中使用横屏摄像头画面，HUD 分布在左右和上下边缘，避免遮挡动作主体。
- 结算和奖励页强化保存、分享、继续挑战。

## 17. 首版页面清单

| 页面 | 首版职责 | 验证点 |
| --- | --- | --- |
| 移动端首页 | 展示三大主题入口和今日活力 | 用户能一眼知道点哪里开始 |
| 童年操场主题页 | 展示操场主题、主玩法和玩法切换 | 用户能直接开始 `操场木头人` |
| 客厅街机主题页 | 展示街机主题和投篮机样板 | 用户理解这是刷分型短局 |
| 电视健美操主题页 | 展示健美操主题和节拍玩法 | 用户理解跟做动作和节拍 |
| 权限 / 横屏取景提示页 | 处理摄像头权限，并提示横过手机 | 用户知道为什么授权、怎么横放手机 |
| 入戏式识别页 | 横屏取景，用场景话术包装识别准备 | 用户不觉得是在处理技术校准 |
| 操场木头人游戏页 | 横屏支撑跑停短局 | 红绿灯、分数、进度和摄像头画面清楚 |
| 投篮机游戏页 | 横屏支撑举手投篮短局 | 分数、连中、出手区清楚 |
| 健美操游戏页 | 横屏支撑跟做节拍短局 | 当前动作、节拍和教练示意清楚 |
| 暂停页 | 游戏内横屏继续、重开、返回 | 重新横放和固定手机提示明确 |
| 结算界面 | 展示分数、称号、标签和下一步 | 本局结果清楚，按钮不混乱 |
| 奖励卡片 | 解锁、收藏、保存、分享 | 奖励价值清楚，适合移动端分享 |
| 我的成就 / 收藏页 | 查看活力、挑战和奖励收藏 | 不喧宾夺主，不变成第二首页 |
| 设置 / 设备页 | 管理权限、识别质量和帮助 | 用户能找到摄像头和摆放说明 |

## 18. 与大屏端的差异总结

| 项目 | 大屏端 | 移动端 |
| --- | --- | --- |
| 首页结构 | 三门洞游戏大厅，远距离可读 | 竖屏主题卡，触控进入 |
| 主题页 | 大画面 + 右侧主玩法面板 | 单列内容 + 主玩法卡 |
