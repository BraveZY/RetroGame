# MotionX Retro Pack / 复古体感包 产品定义

> 本文定义 `MotionX Retro Pack / 复古体感包` 是什么、给谁用、解决什么体验问题、由哪些产品模块组成，以及首版产品边界。不承担立项评审、资源排期和风险审批职责；这些内容见 [项目立项说明书](./MotionX-Retro-Pack-项目立项说明书.md)。




## 1. 产品一句话

> 让孩子玩到父母小时候的快乐，让父母重新参与孩子的游戏时间。

`MotionX Retro Pack / 复古体感包` 卖的不是单纯怀旧，而是亲子共同游戏场景：用 AI 摄像头，把 80/90 年代的电视健身、街机厅和童年操场，变成今天客厅里的全家体感游戏。

## 2. 核心定义

> 这不是单纯复古风游戏包，而是“父母带孩子体验自己那个年代游戏”的故事性体感内容。

复古只是视觉风格，真正的产品价值是：童年、青春、朋友、家人、操场、电玩城、老电视、放学后。用户不是来玩一个旧游戏，而是进入一段回忆。

产品成立的关键不是让孩子理解 80/90 年代，而是让父母有理由发起、孩子能快速觉得好玩、家庭能在一局结束后产生共同话题。情怀负责让父母点开，短局胜负、即时反馈、亲子协作、结算反馈和奖励卡片负责让孩子愿意继续玩。

产品本质：

- 不是新增一批重游戏。
- 不是把现有游戏简单换皮。
- 是给现有 40+ 游戏增加一层更容易理解、更容易销售、更适合 Lite 和 Game Pass 运营的主题组织方式。

## 3. 产品问题

### 3.1 用户侧问题

当前体感内容数量多，但家庭用户进入后容易遇到三个问题：

1. 不知道先玩哪个。
2. 很难在几秒内理解这个内容和家庭娱乐有什么关系。
3. 对“40+ 游戏”的数量感没有直接情绪认知。

### 3.2 产品侧问题

现有内容需要一个更清晰的包装层，让它从“游戏列表”变成“家庭场景”：

- 把玩法按用户记忆组织，而不是按运动项目平铺。
- 把识别、开场、反馈、结算做成有情绪的体验。
- 当前先把国内童年记忆、家庭电视和客厅娱乐场景做清楚；海外区域差异先进入资料池，不进入当前制作范围。

## 4. 目标用户

| 用户 | 需求 | 产品回应 |
| --- | --- | --- |
| 30-45 岁家长 | 想让孩子动起来，也想找回自己的童年记忆 | 童年操场、家庭电视健身、西游童年神话、结算反馈 |
| 5-12 岁儿童 | 规则要简单、反馈要快、失败也好玩 | 5 秒看懂、1-3 分钟短局、轻松反馈 |
| 轻健身用户 | 不想严肃训练，希望低压力日常运动 | 家庭电视健身、复古健美操、低冲击课程 |
| 派对/聚会用户 | 需要旁观者看得懂、多人能轮流上场 | 客厅街机、排行榜、轮流/分队 |
| 渠道/OEM | 当前优先需要国内可理解、可演示、可销售的主题包装 | 国内复古元素、主题馆、节日包；海外本地化后续再做 |

父母是主要发起者和情绪买单者，孩子是持续游玩的关键判断者。首版体验必须同时满足两件事：父母愿意说“这是我小时候玩的”，孩子愿意说“再来一局”。

## 5. 产品原则

1. 回忆是底色，轻松反馈是调味，不能做成恶搞童年。
2. 优先复用现有 40+ 游戏，不从零新增大项目。
3. 首页用主题馆收口，不直接平铺大量图标。
4. 每个对外独立入口必须有真实不同的玩法目标、节奏或动作组合。
5. 2D 单目不判物理落点，不做精确同步率。
6. 先做可验证的轻量闭环，再扩展合影、活动和重运营系统。
7. 所有复古音乐、角色、美术和文案必须原创，不碰真实 IP。
8. 当前阶段优先服务国内用户和国内渠道；国外市场、海外皮肤和海外营销话术暂不制作，只保留为后续资料与扩展方向。
9. 游戏风格采用“主题体验为主、轻怀旧元素为辅”：怀旧元素只做情绪锚点，不能替代玩法目标、动作理由、反馈语言和结算记忆。

## 8. 核心用户流程

### 8.1 首页进入

```text
首页
→ 时光体感馆 / Time Play
→ 选择主题馆
→ 选择游戏/课程
→ 入戏式识别
→ 1-3 分钟短局
→ 结算界面
→ 可选奖励卡片
```

### 8.2 单个游戏体验骨架

| 步骤 | 产品目的 | 首版要求 |
| --- | --- | --- |
| 回忆开场 | 把用户带入童年/街机/电视健身场景 | 10-20 秒，音效 + UI + 文案 |
| 入戏式识别 | 把校准包装成场景行为 | 不说“正在校准”，说“准备上场”“投币成功”等 |
| 亲子/多人角色 | 让家庭成员有参与位置 | 轮流、分队或同屏竞速 |
| 核心玩法 | 复用稳定体感动作 | 只用 2D 稳定动作原语 |
| 轻松反馈 | 降低失败挫败感 | 通用安全文案池 |
| 结算界面 | 清楚呈现本局结果，并用童年视觉元素包装 | 分数 + 称号 + 回忆标签 + 同步感三档 |
| 奖励卡片 | 承接解锁、收藏和可分享奖励 | 首版可做静态奖励卡片；实时合影后置 |

详细流程见 [单个复古体感游戏标准流程_参考](../单个复古体感游戏标准流程_参考.md)。

| 音乐 | 原创复古音乐 demo，不使用真实老歌 |
| 多人 | 轮流、分队、粗粒度同步感 |

### 9.2 首版不包含

| 不做项 | 原因 |
| --- | --- |
| 实时合影/换装 | 独立图像合成管线，成本高 |
| 精确家庭同步率 | 2D 多人遮挡和站位会影响稳定性 |
| 真实地面落点判定 | 单目 2D 无深度，不稳定 |
| 完整西游剧情大冒险 | 过重，偏离短局主题包定位 |
| 海量吐槽分支 | 内容维护和本地化成本高 |
| 真实老歌和真实 IP | 版权风险高 |

## 10. 首批样板定义

| 样板 | 所属主题馆 | 核心玩法 | 动作原语 | 产品验证点 |
| --- | --- | --- | --- | --- |
| 操场木头人 / Freeze Playground | 童年操场 | 跑、停、冻结，多人同屏 | `RunStop` + `FreezeStill` + `SimultaneousRace` | 多人动/静判定是否稳定 |
| 电玩城投篮机 / Arcade Shootout | 客厅街机 | 限时投准，高分榜 | `ReachZone` + `ArmSwing` | 现有运动资产街机化是否成立 |
| 家庭电视健美操 / Family Fitness TV | 家庭电视健身 | 跟做动作，家庭同步感 | `KneeRaise` + `ArmSwing` + `SquatStand` + `ClapBeat` | 故事开场、入戏识别和同步感是否成立 |

样板体验标准：

- 5 秒知道要做什么。
- 30 秒内理解玩法。
- 单局 1-3 分钟。
- 失败反馈轻松，不羞辱用户。
- 旁观者能看懂。
- 手机 / 平板上权限、横屏取景、识别、性能和发热无明显阻断。

## 11. 内容复用规则

复古包不是简单堆新游戏。现有游戏进入复古包时，按三层归类：

| 归类 | 条件 | 首页处理 |
| --- | --- | --- |
| 皮肤/主题 | 动作、节奏、评分、目标基本一致 | 放在同一入口下 |
| 模式 | 底层动作相似，但体验目标明显变化 | 作为同一游戏下的模式 |
| 独立入口 | 用户会认为这是新的玩法目标 | 可单列 |

判断标准：

> 用户会不会认为这是一个新的玩法目标？

一个内容想成为独立入口，至少要满足一项：

- 目标不同。
- 节奏不同。
- 动作组合不同。
- 场景记忆足够强，且不只是换背景。

## 12. 技术产品边界

本产品按 2D 单目摄像头设计。

### 12.1 可稳定使用的动作

- 举手、挥手、张臂、合臂。
- 出拳、摆臂、拍手。
- 抬膝、原地踏步、原地跑。
- 左右侧移、左右倾闪。
- 下蹲、站起、跳跃。
- 身体静止。
- 手伸到屏幕指定区域。

### 12.2 禁止作为核心体验的动作

- 真实地面落点判定。
- 前后纵深移动。
- 精细手腕或手指动作。
- 需要绝对空间坐标的投掷距离。
- 精确多人同步百分比。

核心铁律：

> 2D 下不要判断“身体在物理空间的哪个点”，而要判断“身体相对自己做了什么动作”。

## 13. 市场本地化定义

当前阶段先做国内市场，不做国外市场版本。底层动作和判定仍按可复用方式设计，但首版和首发只验证中国内地用户能理解、能共鸣、能购买的主题包装。

国内优先项：

- 主题馆排序优先：童年操场、家庭电视健身、客厅街机、节日游园、西游童年神话。
- 视觉皮肤优先：操场、课间、老电视、庙会、国产家庭客厅。
- 音乐风格优先：原创复古电视感、校园广播感、游园会热闹感，不使用真实老歌。
- 玩法命名优先：使用国内用户能直接理解的课间、操场、投篮机、庙会、电视健身等表达。
- 营销话术优先：围绕“爸妈带孩子玩自己小时候的游戏”“老电视变家庭运动会”。
- 节日活动包装优先：春节、暑假、开学季、亲子周末。

| 市场 | 首选主题 | 元素方向 |
| --- | --- | --- |
| 中国内地 | 童年操场、家庭电视健身、西游童年神话、节日游园、客厅街机 | 操场、课间、老电视、庙会、西游神话、投篮机 |
| 海外市场 | 暂不制作 | 仅保留资料池，不进入 MVP、首发内容、宣传素材和运营活动 |

国内详细元素优先见 [复古元素清单_按市场划分](../../参考/复古元素清单_按市场划分.md) 的中国大陆部分；海外部分仅作为后续版本预研资料。

## 14. 版权和品牌边界

必须遵守：

- 不使用真实 80/90 年代老歌。
- 不采样真实老歌。
- 不模仿名曲旋律。
- 不使用明星教练形象。
- 不使用真实街机、动画、游戏 IP 名称和角色。
- 西游主题不得直接使用 86 版电视剧音乐、演员形象、服装造型、台词口吻和镜头设计。
- 不照搬知名课程的完整编排、口令和镜头风格。

品牌口径：

> 要复古感，不要真实老歌；要童年神话感，不要复刻电视剧。

## 15. 产品验收口径

| 维度 | 产品验收标准 |
| --- | --- |
| 定位清晰 | 用户能理解这是“家庭复古体感主题”，不是普通游戏列表 |
| 入口清晰 | 首页能看到 `时光体感馆 / Time Play`，进入后按主题馆组织 |
| 上手清晰 | 单个样板 30 秒内理解玩法 |
| 动作稳定 | 首批样板动作落在 2D 稳定原语内 |
| 情绪成立 | 用户能感知童年、街机或电视健身记忆 |
| 亲子成立 | 父母有发起和讲述理由，孩子不依赖怀旧背景也愿意继续玩 |
| 不像换皮 | 独立入口在目标、节奏或动作组合上有真实差异 |
| 版权可控 | 不使用真实老歌、真实 IP 和 86 版西游电视剧元素 |
