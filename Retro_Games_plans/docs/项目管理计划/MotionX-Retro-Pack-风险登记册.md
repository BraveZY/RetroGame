# MotionX Retro Pack / 复古体感包 风险登记册

> 本文是 `MotionX Retro Pack / 复古体感包` 的独立风险登记册，用于记录、评估、跟踪和复盘项目风险。风险管理方法、评分标准、角色职责和升级流程见 [MotionX-Retro-Pack-风险管理计划.md](./MotionX-Retro-Pack-风险管理计划.md)。

## 1. 使用说明

风险评分沿用风险管理计划中的标准：

- 概率：1-5 分。
- 影响：1-5 分。
- 风险评分 = 概率 × 影响。
- 1-5 分为低优先级，6-12 分为中优先级，15-25 分为高优先级。

风险状态：

| 状态 | 含义 |
| --- | --- |
| 新增 | 刚识别，尚未完成验证 |
| 评估中 | 正在确认概率、影响、负责人或证据 |
| 应对中 | 已制定动作并正在执行 |
| 监控中 | 风险已降低，但仍需持续观察 |
| 已关闭 | 风险已消除或不再影响当前阶段 |
| 已接受 | 团队明确接受该风险并记录原因 |
| 已升级 | 超出当前团队权限，已提交专项评审或决策会 |

## 11. 下一次复评建议

下一次风险复评建议重点检查：

1. 三个 MVP 样板是否都能完成最小闭环。
2. 手机 / 平板上动作识别、帧率、发热、横屏取景和首局完成率是否达标。
3. 首批宣传素材是否全部基于真实可运行版本。
4. 是否存在真实 IP、真实音乐、影视化西游表达或素材来源不明问题。
5. 数据埋点是否能区分入口点击、游戏点击、首局完成、复玩、识别失败和主动退出。
6. 国内联网版本是否已验证登录态、实名状态、防沉迷状态、未成年人时段 / 时长、付费限制、隐私提示和拦截原因码。
