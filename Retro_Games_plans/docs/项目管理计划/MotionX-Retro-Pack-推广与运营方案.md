# MotionX Retro Pack / 复古体感包 推广与运营方案

> 本文用于规划 `MotionX Retro Pack / 复古体感包` 的市场推广、渠道打法、上线运营、活动节奏和数据指标。产品定义见 [MotionX-Retro-Pack-产品定义.md](./MotionX-Retro-Pack-产品定义.md)，立项目标与首版范围见 [MotionX-Retro-Pack-项目立项说明书.md](./MotionX-Retro-Pack-项目立项说明书.md)。当前执行以手机 / 平板 MVP 为优先版本；推广可以保留长期客厅家庭想象，但 MVP 物料必须基于移动端真实可演示能力，不提前承诺完整大屏端、电视盒子渠道或 OEM 能力。

## 1. 运营目标

`MotionX Retro Pack / 复古体感包` 的运营目标不是单纯提高某一个小游戏的曝光，而是把现有体感内容包装成一个更容易理解、更容易传播、更适合家庭场景消费的主题入口。

核心目标：

1. 把“40+ 游戏”从数量卖点转成“全家一起玩的童年运动会”。
2. 让家长愿意带孩子体验自己小时候的游戏。
3. 让儿童能在 5 秒内看懂动作，在 30 秒内进入玩法。
4. 让 Lite、Game Pass、Games APK 和 OEM 渠道都有可复用的主题更新框架。
5. 通过短局、排行榜、家庭挑战和节日活动提高复玩。

一句话运营定位：

> 把老电视变成全家一起动起来的时光体感馆。

## 2. 推广定位

### 2.1 核心卖点

| 卖点 | 用户理解方式 | 推广表达 |
| --- | --- | --- |
| 复古体感 | 不是看旧画面，而是亲身进入童年场景 | 电视里的童年游戏，现在可以全家一起玩 |
| 家庭亲子 | 父母和孩子有共同话题 | 陪孩子玩一次自己小时候的课间游戏 |
| 短局轻松 | 不需要学习复杂规则 | 1-3 分钟一局，站到电视前马上开始 |
| 客厅运动 | 游戏和轻运动结合 | 在家也能玩出运动会的热闹感 |
| 派对可看懂 | 旁观者也能理解输赢 | 聚会时轮流挑战，分数一出来就想再来一把 |
| 国内优先 | 当前先服务国内家庭和渠道 | 童年操场、老电视、课间、庙会、西游童年神话 |

### 2.2 目标人群

| 人群 | 需求 | 推广重点 |
| --- | --- | --- |
| 30-45 岁家长 | 想让孩子运动，也想找回童年记忆 | 亲子、童年、老电视、课间游戏 |
| 5-12 岁儿童 | 规则简单、反馈快、失败不挫败 | 马上能玩、动作夸张、结算有称号 |
| 轻健身用户 | 不想严肃训练，希望低压力活动身体 | 复古健美操、短时出汗、低冲击 |
| 派对/聚会用户 | 需要多人轮流、旁观者看得懂 | 街机挑战、排行榜、家庭对抗 |
| OEM / 渠道 | 需要国内差异化卖点和渠道包装 | 主题包、国内节日活动、销售演示素材 |

当前 MVP 宣传口径：

1. 手机 / 平板是当前主验证版本，宣传素材优先展示竖屏入口、横屏取景、触控选择、移动端结算和保存 / 分享。
2. “电视前”“老电视”“客厅共玩”可以作为长期家庭场景表达，但不能让用户或渠道误以为大屏端完整 UI 已进入当前 MVP。
3. 大屏端、Lite、电视盒子和 OEM 只作为后续同源复用方向，不作为当前首版物料的默认承诺。

## 3. 推广内容策略

### 3.1 主视觉方向

主视觉不要只做像素风或霓虹滤镜，应突出“家人在客厅一起动起来”的真实场景。

推荐画面：

- 客厅电视前，父母和孩子一起做动作。
- 电视画面里是操场、街机厅或复古健美操频道。
- 结算页显示家庭称号、分数、回忆标签。
- 远距离可读的大字标题和大按钮。

不推荐画面：

- 只有复古 UI，没有玩家身体。
- 只有游戏截图，没有家庭关系。
- 过度怀旧到儿童无法理解。
- 使用真实老歌、真实影视 IP、明星形象或可识别版权角色。

### 3.2 宣传话术

国内市场：

- “把老电视变成全家的童年运动会。”
- “爸妈小时候玩的课间游戏，现在孩子也能一起玩。”
- “站到电视前，1 分钟重回操场。”
- “不用手柄，身体就是游戏控制器。”

渠道 / OEM：

- “面向国内家庭娱乐场景的复古体感主题包。”
- “复用成熟体感玩法，用国内童年记忆、节日活动和家庭场景重新包装。”

海外英文话术暂不制作，后续确认海外市场优先级后再单独补充。

### 3.3 宣传素材清单

| 素材 | 用途 | 首版要求 |
| --- | --- | --- |
| 15 秒短视频 | 社媒、商店首屏、渠道演示 | 展示家庭上场、动作识别、结算反馈 |
| 30 秒功能视频 | 渠道和官网 | 展示三个样板：木头人、投篮机、电视健美操 |
| 商店主图 | 移动端商店 / APK / 后续 Game Pass | 一眼看出“家庭 + 体感 + 复古”，但画面能力不超过手机 / 平板 MVP |
| 游戏截图 | 商店详情页 | 每个样板至少 2 张，包含玩法中和结算页 |
| 渠道一页纸 | OEM 销售 | 产品定位、目标用户、区域可定制项、首版内容，并明确大屏端和 OEM 属于后续同源扩展 |
| 节日活动图 | 后续运营 | 春节、暑假、家庭日、周末挑战 |

## 4. 首发运营方案

### 4.1 首发内容

首发不宜一次性放出大量内容，应集中推三个最能说明产品方向的样板。

| 样板 | 推广角色 | 核心看点 |
| --- | --- | --- |
| 操场木头人 / Freeze Playground | 亲子破冰 | 跑、停、冻结，全家一眼看懂 |
| 电玩城投篮机 / Arcade Shootout | 街机刷分 | 限时挑战、分数刺激、适合排行榜 |
| 家庭电视健美操 / Family Fitness TV | 轻健身入口 | 老电视频道感、跟做动作、低压力出汗 |

### 4.2 首发节奏

| 阶段 | 时间 | 运营动作 | 目标 |
| --- | --- | --- | --- |
| 预热 | 上线前 7 天 | 发布家庭客厅短视频和复古主题海报 | 建立“这不是普通小游戏合集”的认知 |
| 首发 | 上线当天 | 首页推荐位、首发挑战、渠道主图更新 | 拉高入口点击率和首局完成率 |
| 强化 | 上线后 1 周 | 推出排行榜挑战和家庭称号 | 提高复玩和分享动机 |
| 复盘 | 上线后 2 周 | 分析点击、完成、复玩、退出和识别失败 | 判断是否扩到第二批内容 |

### 4.3 首发活动

活动名称建议：

- `全家木头人挑战`
- `客厅投篮王`
- `复古健美操 7 日轻运动`
- `周末时光体感馆`

活动规则保持轻量：

1. 每个活动只绑定 1-2 个样板游戏。
2. 单局 1-3 分钟。
3. 奖励以称号、徽章、结算标签为主。
4. 不引入复杂等级、装备、体力或货币。
5. 失败反馈保持轻松，不羞辱用户。

## 5. 长线运营方案

### 5.1 内容更新节奏

| 周期 | 内容形式 | 示例 |
| --- | --- | --- |
| 每周 | 家庭挑战 | 本周木头人、亲子投篮赛、家庭同步操 |
| 每月 | 主题包 | 放学后街机周、童年操场月、复古电视健身月 |
| 节假日 | 节日活动 | 春节游园会、暑假运动会、万圣节街机夜 |
| 季度 | 国内主题皮肤包 | 中国童年操场、春节游园、暑假运动会、西游童年神话 |

### 5.2 主题馆运营

| 主题馆 | 运营方向 | 活动例子 |
| --- | --- | --- |
| 童年操场 | 亲子、多人、童年记忆 | 全家木头人、课间挑战、暑假操场 |
| 客厅街机 | 刷分、排行榜、聚会 | 客厅投篮王、街机高分夜、周末挑战 |
| 家庭电视健身 | 轻运动、跟做、日常坚持 | 7 日健美操、饭后轻运动、亲子拉伸 |
| 校园运动会 | 分队、团队、竞赛 | 红蓝队接力、家庭运动会 |
| 节日游园会 | 节庆、渠道更新、活动入口 | 春节套圈、嘉年华挑战 |
| 西游童年神话 | 国内节假日、亲子幻想 | 火焰山挑战、蟠桃园摘桃 |

### 5.3 Game Pass 运营

Game Pass 适合用复古包做持续内容更新。

建议结构：

- 每月新增 1 个主题活动或 1 个轻量玩法模式。
- 每周刷新 1 个家庭挑战。
- 每个节日推出 1 套限定皮肤、音乐或结算标签。
- 每季度复盘一次主题馆点击和复玩，决定下季度扩展方向。

Game Pass 宣传重点：

> 每个月都有新的家庭体感挑战，不只是买断式小游戏列表。

### 5.4 OEM / Games APK 运营

OEM 和 Games APK 当前应强调国内可理解、可换皮、可快速形成渠道差异化。海外本地化暂不作为当前运营承诺。

可定制项：

- 首页入口名称。
- 主题馆排序。
- 国内主题皮肤。
- 原创音乐风格。
- 活动标题。
- 商店主图和宣传话术。
- 节日活动包。

不可承诺项：

- 不承诺真实 IP 或真实老歌授权。
- 不承诺精确地面落点判定。
- 不承诺精确多人同步百分比。
- 不承诺重剧情大冒险。

## 6. 数据指标

### 6.1 MVP 验证指标

| 指标 | 说明 | 目标判断 |
| --- | --- | --- |
| 入口点击率 | 用户是否愿意进入 `时光体感馆` | 判断主题包装是否有吸引力 |
| 游戏点击率 | 进入主题馆后选择哪个样板 | 判断首发样板排序和封面是否有效 |
| 首局完成率 | 用户是否能完成第一局 | 判断规则、识别和节奏是否过关 |
| 再来一把比例 | 单局结束后是否继续 | 判断核心乐趣和结算反馈是否成立 |
| 平均游玩时长 | 单次进入停留多久 | 判断短局串玩是否自然 |
| 多人参与率 | 是否选择轮流、分队或同屏玩法 | 判断家庭场景是否成立 |
| 结算页停留 | 是否看完称号、分数和回忆标签 | 判断结算界面是否清楚、有情绪 |
| 识别失败率 | 校准失败、动作无响应、异常退出 | 判断是否需要先修体验稳定性 |

### 6.2 上线后运营指标

| 指标 | 用途 |
| --- | --- |
| 日活 / 周活 | 观察主题入口整体活跃 |
| 次日 / 7 日留存 | 判断复古包是否有持续吸引力 |
| 活动参与率 | 判断每周挑战是否有效 |
| 排行榜查看率 | 判断街机刷分动机是否成立 |
| 主题馆分布 | 决定后续内容优先扩展方向 |
| 国内主题皮肤点击率 | 判断国内包装是否有效 |
| 渠道转化率 | 判断 OEM / APK 宣传素材是否有效 |

## 7. 版本节奏

### 7.1 MVP 版本

目标：证明方向成立。

包含内容：

- `时光体感馆 / Time Play` 入口。
- 三个首批样板。
- 回忆开场。
- 入戏式识别。
- 轻松反馈。
- 带童年元素的结算界面。
- 独立静态奖励卡片。
- 基础数据埋点。
- 国内联网版本的账号、实名、防沉迷、未成年人限制、隐私提示和付费拦截最小闭环。

验收重点：

- 用户是否看得懂。
- 家庭是否愿意一起玩。
- 单局结束是否愿意再来一把。
- 手机 / 平板上权限、横屏取景、识别、性能和发热是否稳定。
- 国内联网版本中，合规拦截是否正确、提示是否清楚。

### 7.2 首发版本

目标：形成可销售主题包。

建议扩展：

- 6-10 个复古主题内容。
- 三个主题馆稳定开放。
- 首页推荐位和活动入口。
- 排行榜或家庭挑战。
- 第一套国内渠道宣传素材。

### 7.3 成长期版本

目标：支撑订阅和国内长期运营。

建议扩展：

- 每月主题活动。
- 节日游园会。
- 国内主题皮肤包。
- 轻量徽章和称号。
- 内容达到 10+ 后，逐步引入《童年的一天》时间线结构。

## 8. 运营风险

| 风险 | 表现 | 应对 |
| --- | --- | --- |
| 只像换皮 | 用户觉得玩法没有变化 | 独立入口必须有不同目标、节奏或动作组合 |
| 儿童看不懂复古梗 | 家长有感觉，孩子不愿玩 | 规则和反馈优先儿童秒懂，复古只做情绪包装 |
| 识别体验不稳 | 用户首局失败或退出 | 先修动作原语和校准流程，再推活动 |
| 宣传过度承诺 | 用户期待精确动作或真实投掷 | 明确 2D 单目边界，不宣传不可稳定实现的能力 |
| 平台口径超前 | MVP 物料让用户或渠道误以为完整大屏端已经交付 | 当前物料优先展示手机 / 平板真实画面，大屏端只写后续同源扩展 |
| 合规门禁后置 | 国内联网版本上线前才补实名、防沉迷或未成年人限制 | MVP 阶段先验证账号状态、拦截原因码和隐私提示链路 |
| 版权风险 | 使用真实老歌、影视角色或明星形象 | 音乐、美术、角色和文案全部原创 |
| 运营过重 | 引入等级、装备、复杂任务 | 保持短局、轻量称号、徽章和家庭挑战 |

## 9. 推广与运营红线

1. 不把复古包宣传成真实 IP 合集。
2. 不使用真实老歌、影视音乐、明星形象或可识别版权角色。
3. 不承诺精确多人同步率、真实地面落点或前后纵深判定。
4. 不把首版做成重剧情、重养成或重存档系统。
5. 不让运营活动依赖复杂解释，用户必须能在手机 / 平板 MVP 中快速理解。
6. 不用大量游戏数量掩盖单个样板体验不稳。
7. 不用大屏端、电视盒子、OEM 或 Game Pass 远期能力包装当前手机 / 平板 MVP。

## 10. 一句话总结

`MotionX Retro Pack / 复古体感包` 的推广要卖“全家一起重回童年”，运营要持续制造“本周为什么要一起打开时光体感馆”的理由。首版先用手机 / 平板验证亲子、街机和轻健身三个场景，后续再通过每周挑战、每月主题包、节日活动、国内主题皮肤和大屏端同源复用，把它从一次性内容包运营成长期家庭娱乐场景。
