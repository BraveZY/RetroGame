# MotionX Retro Pack / 项目立项决策记录

> 本文是 `MotionX Retro Pack / 复古体感包` 的立项归档和决策记录，只保留立项评审需要确认的方向、范围和通过条件。产品定义、详细范围、里程碑、风险和运营策略分别以对应 authority 文档为准。

## 1. 立项结论

| 项目项 | 决策 |
| --- | --- |
| 项目名称 | MotionX Retro Pack / 复古体感包 |
| 首页入口 | 时光体感馆 / Time Play |
| 项目类型 | 现有体感内容二次组织 + 主题包装 + 轻量样板验证 |
| 立项阶段 | 概念验证 / MVP 验证 |
| 当前主版本 | 手机 / 平板 MVP 优先 |
| 首批样板 | 操场木头人、电玩城投篮机、家庭电视健美操 |
| 核心定位 | 父母带孩子体验自己小时候的游戏，把童年操场、客厅街机和家庭电视健身变成 1-3 分钟短局体感 |

立项结论：

> 建议立项，但采用“小步验证、严格控重”的方式推进。先用 3 个样板验证理解成本、复玩意愿和识别稳定性，再决定是否扩到首发内容包和 Game Pass 运营。

## 2. 评审需要确认

1. 是否确认项目主题名为 `MotionX Retro Pack / 复古体感包`，首页入口名为 `时光体感馆 / Time Play`。
2. 是否确认当前只做手机 / 平板 MVP 验证，不直接进入完整上线制作。
3. 是否确认首批样板为操场木头人、电玩城投篮机、家庭电视健美操。
4. 是否确认 2D 技术铁律：不判真实物理落点，不做前后纵深移动，不做精确同步率。
5. 是否确认西游童年神话、节日游园、完整《童年的一天》、Game Pass 和 OEM 定制都不进入 MVP。
6. 是否确认所有复古音乐、影视感、美术和角色均走原创，不碰真实老歌、真实 IP、明星形象和可识别影视引用。

## 3. 立项通过条件

| 条件 | 通过标准 |
| --- | --- |
| 方向清楚 | 用户能理解这是家庭复古体感主题，不是普通游戏列表 |
| 样板可做 | 三个样板都落在稳定 2D 单目动作原语内 |
| 范围可控 | MVP 不包含复杂任务、完整时间线、付费系统、重社交、换装、实时合影 |
| 家庭价值成立 | 父母有发起理由，孩子 5 秒知道动作、30 秒理解玩法 |
| 风险可控 | 版权、合规、识别稳定、渠道承诺和范围蔓延都有对应 owner 和控制策略 |
