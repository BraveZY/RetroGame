# 复古童年场景：学校教学楼引用

> 本文是 `MotionX Retro Pack / 复古体感包` 的学校教学楼场景引用文档。用于美术、关卡、UI 背景、宣传图和场景氛围统一口径。区域整体依据见 [区域怀旧设计依据_美术音乐玩法.md](../参考/区域怀旧设计依据_美术音乐玩法.md)，复古元素总表见 [复古元素清单_按市场划分.md](../参考/复古元素清单_按市场划分.md)。

## 0. 核心结论

中国大陆复古童年场景中，教学楼主体建议优先选择 **乡镇小学 / 乡镇初中教学楼**，而不是现代城市教学楼。

推荐口径：

> 主体用 90 年代末到 2000 年代初的乡镇学校教学楼，局部吸收城市学校的规整感。

这样既有童年辨识度，也不会显得过度破旧或过于地方化。

## 1. 为什么优先选乡镇教学楼

### 1.1 情绪辨识度更强

乡镇教学楼更容易承载“放学后、课间十分钟、操场游戏、小卖部、广播喇叭、集体活动”的童年记忆。

它的视觉不是现代校园的干净规整，而是带一点旧、带一点土、但仍然温暖热闹。

### 1.2 更适合复古体感包

复古体感包的核心不是还原真实学校建筑，而是给玩家一个能快速读懂的童年舞台。

乡镇学校天然适合承载：

- 跳房子、丢沙包、踢毽子、跳皮筋。
- 课间跑动、操场集合、广播体操。
- 放学路、小卖部、校门口、夕阳。
- 亲子玩家对“自己小时候”的代入。

### 1.3 与中国大陆市场怀旧底色一致

中国大陆怀旧主打 1990s 为主、80 年代末为辅。这个阶段的学校记忆通常不是高楼、电子屏和标准化新校园，而是老楼、操场、国旗台、围墙、铁门、树荫和广播。

## 2. 乡镇教学楼设计要点

### 2.1 建筑体量

- 2-4 层为主，不建议做成很高的大楼。
- 横向展开比纵向高耸更合适。
- 建筑轮廓简单，方便远景识别。
- 走廊、栏杆、窗框要清楚，能一眼看出是学校。

### 2.2 外墙与结构

可选方向：

| 类型 | 视觉特征 | 使用建议 |
| --- | --- | --- |
| 红砖教学楼 | 红砖墙、白色窗框、浅色走廊栏杆 | 怀旧最强，适合主视觉 |
| 白墙蓝窗楼 | 白墙、蓝色窗框、浅灰水泥楼梯 | 更干净，适合轻度复古 |
| 米黄老楼 | 米黄外墙、绿色或蓝色门窗 | 温暖，适合夕阳场景 |
| 水泥灰教学楼 | 灰墙、铁栏杆、旧楼梯 | 谨慎使用，容易显脏或压抑 |

建议避免把建筑做得过破、过脏、过荒废。目标是“旧但有人气”，不是废弃学校。

### 2.3 校园配套元素

推荐加入：

- 国旗台。
- 操场广播喇叭。
- 黑板报或公告栏。
- 水泥操场、粉笔格子、跑道线。
- 乒乓球台、单双杠、篮球架。
- 校门、铁门、围墙。
- 小卖部、树、花坛、自行车棚。
- 远处民房、低矮街道或田地轮廓。

不建议大量使用：

- 电子大屏。
- 现代塑胶跑道大面积主导画面。
- 玻璃幕墙。
- 大型现代体育馆。
- 过于豪华的校门和景观绿化。

## 3. 城市教学楼适用条件

城市教学楼不是不能用，但它更适合以下方向：

- 游戏明确发生在大城市。
- 主题偏现代校园、补习班、规范化学校生活。
- 需要塑胶跑道、高楼、电子屏、整齐校门。
- 目标情绪是“干净、规整、城市童年”，不是“土味、课间、街边小卖部”。

如果使用城市教学楼，应避免做成完全现代校园。可以保留一些复古元素，例如老式黑板、广播喇叭、旧窗框、操场器材和放学小卖部。

## 4. 推荐折中方案

最终方案建议采用“乡镇主体 + 轻度规整”的混合设计：

| 部分 | 推荐处理 |
| --- | --- |
| 教学楼主体 | 乡镇老楼，2-4 层，红砖 / 白墙蓝窗 / 米黄外墙 |
| 操场 | 水泥地或旧塑胶局部，不做全现代标准运动场 |
| 校门 | 简单铁门或砖柱校门，不做豪华景观门 |
| 周边 | 树、小卖部、围墙、远处民房 |
| 氛围 | 夕阳、课间铃、广播、孩子跑动、温暖滤镜 |
| 清洁度 | 旧但干净，不脏乱，不废弃 |

一句话给美术：

> 做一所 90 年代末到 2000 年代初的乡镇小学 / 初中：低矮老楼、水泥操场、国旗台、广播喇叭、小卖部和树荫；画面温暖、有人气，不要做成废弃学校。

### 5.1 应该出现

- 红砖墙。
- 白墙蓝窗。
- 走廊栏杆。
- 水泥操场。
- 粉笔线。
- 国旗台。
- 黑板报。
- 广播喇叭。
- 乒乓球台。
- 单双杠。
- 老篮球架。
- 铁门和围墙。
- 小卖部。
- 自行车棚。
- 树荫。
- 夕阳放学。

### 5.2 谨慎使用

- 大面积塑胶跑道。
- 玻璃幕墙。
- 电子屏。
- 现代教学楼连廊。
- 高层综合楼。
- 豪华校门。
- 过脏墙面。
- 废弃感破损。

## 6. 风格边界

### 6.1 不做真实学校复刻

教学楼只作为原创怀旧场景，不直接复刻某个真实学校的校门、校徽、标语、建筑布局或名称。

### 6.2 不强化贫穷或破败

乡镇教学楼的重点是亲切、温暖、熟悉，不是苦难叙事。墙面可以旧，设施可以简单，但整体要有人气。

### 6.3 不做单一年代考古

场景可以混合 90 年代末和 2000 年代初元素，只要整体情绪统一，不必追求每个物件都严格属于同一年。
