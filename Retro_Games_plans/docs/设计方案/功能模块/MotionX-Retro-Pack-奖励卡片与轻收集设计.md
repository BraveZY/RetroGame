# MotionX Retro Pack / 奖励卡片与轻收集设计

> 本文定义 `MotionX Retro Pack / 复古体感包` 的奖励卡片、贴纸、徽章、称号和轻量收藏方向。结算界面只负责本局结果展示；奖励卡片负责解锁、收藏和可分享表达。

## 1. 设计边界

奖励系统服务亲子共同游戏场景，不做重养成、不做货币、不做装备数值。

首版原则：

- 轻收集：奖励以贴纸、徽章、称号、静态卡片为主。
- 低成本：优先复用 UI 模板和主题视觉，不做复杂动画。
- 可看懂：孩子能理解奖励是什么，父母能看出童年元素。
- 不混结算：本局分数、评价和操作留在结算界面；解锁内容进入奖励卡片。

## 2. 奖励类型

| 类型 | 主要用途 | 首版优先级 |
| --- | --- | --- |
| 童年贴纸 | 高频轻奖励，适合孩子收集 | P0 |
| 徽章 | 阶段性成就，适合活动和挑战 | P0 |
| 称号 | 本局表现反馈，也可进入收藏 | P0 |
| 纪念照片 / 明信片 | 情绪收藏和分享 | P1/P2 |
| 收藏物件 | 长期图鉴和主题扩展 | P1 |
| 家庭奖励 | 强化亲子共同参与 | P0 |

## 3. 奖励产生条件

奖励不能只靠“打一局就给”，否则很快变成无意义弹窗；也不能全部绑定高分，否则孩子、低龄用户和父母示范局容易受挫。首版应以参与型和亲子型奖励为主，表现型奖励为辅。

| 条件类型 | 触发例子 | 适合奖励 | 首版建议 |
| --- | --- | --- | --- |
| 参与型 | 完成一局、首次进入主题馆、首次完成某个游戏 | 贴纸、基础称号 | P0，保证孩子和父母都能拿到 |
| 表现型 | 达到 A 级、刷新分数、动作稳定、同步感好 | 徽章、称号 | P0，但不要占比过高 |
| 行为型 | 再玩一次、换一个主题、连续玩 3 局 | 贴纸、家庭奖励 | P0，用来推动复玩 |
| 亲子型 | 父母示范、孩子挑战、全家参与、孩子超过父母参考分 | 家庭徽章、家庭称号 | P0，优先级最高 |
| 活动型 | 周末挑战、节日活动、每日任务 | 限定贴纸、限定徽章 | P1，首版可先预留 |

首版奖励方向：

- 优先奖励“家庭一起玩”，再奖励“孩子高分”。
- 参与型奖励保证每个家庭能快速获得正反馈。
- 表现型奖励只做少量明确目标，不做高压竞技。
- 亲子型奖励应比单人高分奖励更醒目。

## 4. 收集获得规则

收集系统只做展示和情绪价值，不影响玩法能力，不提供数值加成。

| 规则项 | 首版口径 |
| --- | --- |
| 每局是否必给奖励 | 新手前几局可以高频给；后续按条件触发 |
| 每局奖励数量 | 结算后最多弹出 1 张奖励卡片 |
| 是否可重复获得 | 可以重复触发，但收藏只点亮一次 |
| 重复获得处理 | 显示“已拥有”或增加点亮次数，不转货币 |
| 是否做稀有度 | 首版不做复杂稀有度 |
| 是否能付费购买 | 不能，只能通过游玩获得 |
| 是否影响能力 | 不影响动作判定、分数、难度和胜负 |
| 是否做每日任务 | 可做轻量“每日 / 周末家庭挑战”，不做复杂任务链 |
| 是否做成套收集 | 可以按主题做小套装，每套 6-12 个 |

收藏页建议按主题分组：

| 分组 | 收集内容 |
| --- | --- |
| 童年操场 | 操场贴纸、木头人徽章、课间称号、操场明信片 |
| 客厅街机 | 投币贴纸、街机徽章、投篮称号、电玩城冠军照 |
| 家庭电视健身 | 电视贴纸、同步徽章、健身称号、节目单卡片 |
| 家庭回忆 | 亲子徽章、家庭称号、周末家庭赛奖励 |

## 5. 奖励类型的获得逻辑

| 奖励类型 | 获得方式 | 频率 | 作用 |
| --- | --- | --- | --- |
| 贴纸 | 完成、参与、主题体验、再玩一次 | 高频 | 让孩子有即时收集感 |
| 称号 | 本局表现或家庭行为 | 中频 | 结算时有反馈，收藏里可展示 |
| 徽章 | 达成明确条件、首通、A 级、多人参与 | 低频 | 形成成就感 |
| 家庭奖励 | 父母和孩子共同完成、家庭复玩、周末挑战 | 中低频 | 强化“我们一起玩过” |
| 纪念照片 / 明信片 | 特殊场景、主题首通、活动完成 | 低频 | 情绪收藏和分享 |
| 收藏物件 | 主题长期图鉴、活动扩展 | 后续 | 做长期收集线 |

## 13. 首版建议

首版只保留三类高性价比奖励：

1. 童年贴纸。
2. 徽章。
3. 称号。

家庭奖励可以作为贴纸或徽章的命名方向优先进入首版。纪念照片、收藏物件图鉴和家庭相册放到后续版本，避免奖励系统过重。

首版最小闭环：

```text
完成一局
→ 结算界面显示本局结果
→ 如满足条件，弹出 1 张奖励卡片
→ 奖励进入对应主题收藏页
→ 用户可选择继续玩 / 查看收藏
```

## 14. 与结算界面的关系

结算界面：

- 显示本局分数、评级、称号、回忆标签、同步感和下一步操作。
- 可以使用童年元素做视觉包装。
- 不展示完整收藏图鉴，不承载复杂解锁说明。

奖励卡片：

- 在结算后独立出现，或进入单独奖励页。
- 展示本次解锁的贴纸、徽章、称号或收藏项。
- 可提供“收下”“查看收藏”“继续玩”等操作。
