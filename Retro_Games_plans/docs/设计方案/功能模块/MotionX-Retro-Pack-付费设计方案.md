## 1. 核心结论

首发优先卖一个清晰的买断基础包；Game Pass 只在内容更新节奏、家庭活动和留存数据成立后上线。

| 决策 | 口径 |
| --- | --- |
| 首发付费 | 优先 `时光体感馆基础包` 买断 |
| 订阅定位 | 成长期持续活动和内容更新服务 |
| 已买断用户 | 已买断内容永久保留，不进入订阅墙 |
| 儿童奖励 | 只能通过游玩解锁，不收费 |
| 零散付费 | 不做贴纸、徽章、称号、奖励卡片、复活、体力、高分、抽卡 |

一句话口径：

> MVP 免费验证，首发卖一个清晰的买断基础包；当内容更新节奏和家庭复玩数据成立后，再上线 Game Pass 订阅承接长期活动。游戏内奖励全部靠游玩解锁，不做儿童付费点。

## 2. 阶段策略

| 阶段 | 主策略 | 说明 |
| --- | --- | --- |
| MVP 验证期 | 免费验证 | 不开放付费，先验证首局完成率、再来一局比例、家庭参与度和奖励理解度 |
| 首发期 | 买断基础包 | 作为首发核心商业模型，父母容易理解，决策成本低 |
| 成长期 | Game Pass 订阅 | 只在内容更新、家庭活动和留存数据成立后推出 |
| 奖励卡片 / 徽章 / 贴纸 | 不收费 | 必须通过游玩解锁，服务亲子体验和复玩 |

## 3. 不做零散付费点

这些内容不作为付费点：

| 不收费项 | 原因 |
| --- | --- |
| 贴纸、徽章、称号、奖励卡片 | 它们是游玩反馈和家庭回忆，不是商品 |
| 复活、体力、加分、高分 | 会制造压力，破坏轻松短局体验 |
| 儿童专属奖励 | 容易变成“孩子想要、父母付款”的拉扯 |
| 抽卡、盲盒、随机奖励 | 未成年人和家庭场景风险高 |

正确收费对象：

| 可以收费 | 原因 |
| --- | --- |
| 基础内容包 | 买一个清晰的家庭游戏主题包 |
| 后续主题包 | 是明确内容扩展 |
| 节日活动包 | 是运营内容 |
| Game Pass | 是持续活动和更新服务 |

## 4. 买断内容包

买断内容包是首发核心商业模型，覆盖独立 APK 和商店版本。首发建议只重点销售一个 `时光体感馆基础包`，不要一开始把三个主题馆拆成多个小包并列售卖。

| 内容包 | 内容方向 | 阶段 |
| --- | --- | --- |
| 时光体感馆基础包 | 童年操场、客厅街机、家庭电视健身三个样板 | 首发 |
| 童年操场包 | 木头人、跳房子、丢手绢、跑停挑战 | 首发 / 第二批 |
| 客厅街机包 | 投篮机、拳击机、反应挑战、排行榜短局 | 首发 / 第二批 |
| 家庭电视健身包 | 复古健美操、拳击操、亲子拉伸 | 首发 / 第二批 |
| 节日游园包 | 套圈、扔沙包、庙会挑战、节日活动 | 节日版本 |
| 西游童年神话包 | 火焰山、蟠桃园、筋斗云、白骨精挑战 | 第二批 / 节假日 |

对用户表达：

| 场景 | 推荐文案方向 |
| --- | --- |
| 基础包 | 买一个家庭游戏主题包 |
| 主题包 | 买几个孩子能一起玩的家庭短局 |
| 节日包 | 买一个周末或节日亲子活动内容 |

## 5. 订阅 / Game Pass

Game Pass 是成长期运营工具，不是首发变现工具。它销售的是持续家庭活动，而不是把基础内容锁进会员墙。

订阅承载内容：

| 订阅内容 | 价值 |
| --- | --- |
| 每周家庭挑战 | 给家庭一个再次打开的理由 |
| 每月主题活动 | 形成持续新鲜感 |
| 节日限定活动 | 春节、暑假、开学季、周末家庭赛 |
| 家庭排行榜 | 支撑复玩和围观 |
| 新主题皮肤 | 低成本更新视觉新鲜感 |
| 新奖励卡片合集 | 增加轻收集目标 |
| 新短局玩法 | 内容能力成熟后再加入 |

订阅上线条件：

1. 每月至少能稳定交付一个可感知更新。
2. 每周有轻量挑战或活动目标。
3. 首局完成率、再来一局比例和 7 日留存有基础数据支撑。
4. 用户已经理解 `时光体感馆` 的家庭价值。
5. 订阅内容不影响已买断用户的基础体验。

## 6. 买断后再订阅

买断和订阅是两类不同权益：买断获得永久内容使用权，订阅获得持续运营服务权。

核心规则：

1. 已买断内容不进入订阅墙。
2. 订阅到期后，用户仍然保留已买断内容。
3. 订阅可以包含新活动、新主题、新挑战和临时可玩的扩展内容。
4. 订阅不能回收用户已经买断的基础包。
5. 已解锁奖励保留，不随订阅到期消失。

权益拆分：

| 权益类型 | 购买方式 | 到期规则 | 示例 |
| --- | --- | --- | --- |
| 基础包永久权益 | 买断 | 永久保留 | `时光体感馆基础包`、已购买主题包 |
| 订阅服务权益 | Game Pass | 订阅到期后停止 | 每周家庭挑战、每月主题活动、节日运营入口 |
| 订阅期间可玩内容 | Game Pass | 订阅到期后停止，除非单独买断 | 当月新增短局、限时主题皮肤、活动路线 |
| 游玩解锁奖励 | 游玩获得 | 已解锁则保留 | 贴纸、徽章、称号、奖励卡片 |

买断用户再订阅：

```text
已买断基础包
-> 继续永久拥有基础内容
-> 看到 Game Pass 入口
-> 订阅后获得每周 / 每月活动、新主题挑战、限时内容和运营服务
-> 订阅到期后回到已买断内容，不丢失基础包和已解锁奖励
```

未买断用户订阅：

```text
未买断基础包
-> 可订阅 Game Pass 体验订阅期内开放内容
-> 订阅到期后仅保留免费内容和已解锁的非付费奖励
-> 若单独买断基础包，则基础包永久保留
```

用户表达边界：

| 场景 | 正确表达 | 禁止表达 |
| --- | --- | --- |
| 已买断用户看到订阅入口 | “你已拥有基础包，订阅可获得每周家庭挑战和每月主题活动。” | “升级会员才能继续玩基础包。” |
| 订阅到期 | “订阅活动已结束，你仍可继续游玩已购买内容。” | “会员到期，基础包不可用。” |
| 新内容上线 | “本月 Game Pass 开放新挑战；也可后续作为主题包购买。” | “已买断用户也必须订阅才能继续获得基础体验。” |
| 儿童界面 | “需要家长查看订阅内容。” | “马上续费，不然奖励消失。” |

内容权益归属：

| 内容类型 | 是否可买断 | 是否可进订阅 | 规则 |
| --- | --- | --- | --- |
| 首发基础内容 | 是 | 不作为订阅墙 | 买断用户永久拥有，订阅不重复收费 |
| 后续主题包 | 是 | 可在订阅期内开放体验 | 买断后永久拥有；未买断则随订阅到期停止 |
| 每周 / 每月挑战 | 否 | 是 | 属于持续运营服务，不单独永久售卖 |
| 节日活动包 | 可以 | 可以 | 可作为订阅活动，也可在活动后沉淀成买断包 |
| 奖励卡片 / 徽章 / 称号 | 否 | 否 | 只能通过游玩解锁，不收费 |

实现建议：

```text
owned_packs: 用户永久拥有的内容包
game_pass_status: 当前订阅状态
```

访问判断：

```text
如果内容属于 owned_packs -> 可玩
否则如果内容属于 active_game_pass 且订阅有效 -> 可玩
否则展示购买内容包或订阅入口
```

商业建议：

1. 首发先只卖 `时光体感馆基础包`，不要同时强推订阅。
2. Game Pass 上线时，对已买断用户强调“增加活动和持续更新”，不要强调“补会员”。
3. 可给早期买断用户首月优惠或家庭挑战体验券，但不做复杂补差价系统。
4. 所有付费页必须面向家长解释权益，不面向儿童制造压力。

## 7. 奖励与付费边界

| 项目 | 是否收费 | 原因 |
| --- | --- | --- |
| 小卖部汽水贴纸 | 否 | 游玩奖励，不能破坏成就感 |
| 木头人高手徽章 | 否 | 表现奖励，必须靠玩法获得 |
| 课间冲刺王称号 | 否 | 本局反馈，不能买 |
| 新主题馆 | 可以 | 是内容扩展 |
| 节日活动包 | 可以 | 是运营内容 |
| Game Pass 每月主题 | 可以 | 是持续服务 |

## 8. 首版付费方案

### 8.1 MVP / 体验验证

- 3 个样板免费或内部验证。
- 不开放付费。
- 验证首局完成率、再来一局比例、家庭参与度和奖励理解度。

### 8.2 首发 / 基础包

- 推出 `时光体感馆基础包`。
- 可在独立 APK 中买断。
- 包含 6-10 个核心短局和基础奖励体系。
- 不把首发基础内容拆进订阅会员墙。
- 不同时推出多个小额主题内购。

### 8.3 成长期 / 订阅

- Game Pass 每周家庭挑战。
- 每月主题活动。
- 节日活动包。
- 新贴纸、徽章、称号和主题皮肤合集。
- 订阅只在内容更新节奏、家庭复玩数据和活动运营能力成立后上线。

## 9. 风险控制

| 风险 | 表现 | 处理方式 |
| --- | --- | --- |
| 订阅过早 | 内容更新跟不上，用户觉得不值 | 先买断，后订阅 |
| 重复收费感 | 用户买断后发现基础内容又进订阅墙 | 买断内容永久保留，订阅只卖持续活动和新增服务 |
| 内购过碎 | 家长反感，孩子被付费打断 | 不卖奖励、不卖复活、不卖体力 |
| 内容包过贵 | 父母第一次决策压力大 | 基础包小而清楚，后续扩主题 |
| 订阅承诺过高 | 承诺每周新玩法，制作压力失控 | 区分挑战、皮肤、活动和新玩法 |

## 10. 当前方案

当前阶段优先做：

1. 免费 MVP 验证。
2. 一个可买断的 `时光体感馆基础包`。
3. Game Pass 的每周挑战和每月主题框架，但只做规则预埋，不作为首发核心付费点。

暂不做：

1. 儿童内购。
2. 奖励付费。
3. 抽卡或随机奖励。
4. 体力、复活、加分等付费点。
5. 高强度订阅承诺。
6. 首发即强推订阅。
7. 把基础游戏内容锁进会员墙。
