# MotionX Retro Pack / 飞蓬小剑客游戏 GDD

> 本文是 `MotionX Retro Pack / 时光体感馆` 中「飞蓬小剑客」玩法的单独 GDD。它把小时候放学路边捡根小树枝、把飞蓬草当作练剑木桩的记忆，改编成适合家庭客厅的短局体感游戏：核心动作是上下挥臂刷叶、横向挥臂斩杆、左右站位选择目标；单局目标是让家庭用户在 60-90 秒内看懂“刷掉叶子，再横扫收尾”，并愿意再挑战一棵更高的飞蓬。

## 游戏概述

「飞蓬小剑客」是一款以放学路边童年记忆为主题的短局体感游戏。玩家不需要真实道具，只需要站在屏幕前的路边练剑区，用空手动作模拟一根“空气小木棍”，把画面中的飞蓬草当作练剑木桩。

游戏的核心过程是“先刷叶，再横扫”：玩家根据屏幕提示做上挥或下挥动作，把飞蓬草不同高度的叶片一层层刷掉；当清叶进度达到阈值后，系统提示“横扫”，玩家再用横向挥臂完成收尾。每一株飞蓬都会根据清叶完整度、连击、横扫命中和动作时机给出分数反馈。

单人模式强调个人挑战，目标是在 60-90 秒内完成尽可能多株飞蓬，刷得更干净、连击更稳定、横扫更漂亮，最终获得更高分数、评级和称号。分屏模式强调同屏对比，两名玩家在左右分区内各自挑战飞蓬，通过总分、完成株数、完美横扫和最高连击判定胜利。

整体体验要轻松、明亮、可围观：失败只断连击或降低评级，不做生命惩罚；画面重点放在叶片脱落、草杆变干净、横扫折断和飞絮散开的爽感上，避免把玩法表达成割草、除草或真实刀剑对抗。

| 5 秒内看懂 | 屏幕前出现一株高高的飞蓬，叶片层层分布，提示玩家“上下刷叶” |

## 4. 核心玩法概述

| 核心环节 | 规格 |
| --- | --- |
| 玩家位置 | 站在路边练剑区，正面面向摄像头和屏幕中的飞蓬草 |
| 系统预告 | 当前目标草杆高亮，叶片按上 / 中 / 下层分布 |
| 玩家刷叶 | 根据亮起的叶片层，做上挥或下挥动作 |
| 玩家横扫 | 草杆清叶达到阈值后，进入短暂“横扫”窗口 |
| 判定输入 | 手腕关键点垂直速度、水平速度、挥臂幅度、方向匹配度、时机窗口 |
| 结果表现 | 叶片啪地飞掉、连击数字跳动、草杆折断、飞絮散开 |

核心循环：

```text
目标飞蓬出现
→ 左右站位锁定目标
→ 上下挥臂刷叶
→ 清叶进度达到阈值
→ 横向挥臂斩杆
→ 结算本株表现
→ 下一株飞蓬 / 终结挑战
```

### 4.1 场地关系

飞蓬小剑客的场地应按正面舞台理解：玩家站在屏幕前的路边练剑区，飞蓬草出现在画面中前景，后方是放学路、小学校门、小卖部或土路远景。玩家不需要真实走到草前，也不需要向前后移动。

```text
+----------------------------------------------------------------------------+
|  远景：校门 / 小卖部 / 电线杆 / 暖日光                                      |
|                                                                            |
|            飞蓬 A              飞蓬 B              飞蓬 C                  |
|              |                   |                   |                      |
|            \ | /               \ | /               \ | /                    |
|             \|/                 \|/                 \|/                     |
|              |                   |                   |                      |
|                                                                            |
|----------------------------------------------------------------------------|
|  路边练剑区                                                                |
|                         ←        玩家站位        →                         |
|                              上下刷叶 / 横向挥砍                            |
+----------------------------------------------------------------------------+
```

| 场地规则 | 说明 |
| --- | --- |
| 站位 | 玩家始终站在练剑区内，左右侧移只用于选择目标或切换草杆 |
| 朝向 | 玩家正面朝向摄像头，允许自然转肩，但不把侧身作为必要动作 |
| 目标 | 同一时间只高亮 1 株主目标，避免儿童不知道打哪一棵 |
| 结果反馈 | 叶片和草杆在屏幕中被虚拟小木棍击中，不要求玩家拿真实道具 |
| 多人边界 | 首发优先做单人模式；分屏模式优先做左右区域同屏计分，不做互相遮挡或抢目标玩法 |

## 6. 操作与动作判定

| 动作 | 玩家行为 | 游戏含义 | 2D 姿势识别判定原则 |
| --- | --- | --- | --- |
| 左右站位 | 身体中心向左 / 右移动 | 选择目标飞蓬或切换草杆 | 粗粒度区域判断，不追求精确厘米级位移 |
| 上挥刷叶 | 手腕从低位快速上移 | 从下往上挑掉一层叶片 | 判断手腕垂直速度峰值、位移幅度和目标层匹配 |
| 下挥刷叶 | 手腕从高位快速下移 | 从上往下扫掉一层叶片 | 判断手腕垂直速度峰值、位移方向和目标层匹配 |
| 横向挥砍 | 手腕从身体一侧快速扫向另一侧 | 清叶后斩断草杆 | 以水平速度峰值、水平位移和时机窗口为主，不计算真实刀剑角度 |
| 短暂停顿蓄力 | 手停在身体一侧 0.3-0.6 秒 | 横扫前准备 | 只作为加分项，不作为必须条件 |
| 双手横扫 | 双手同时做同向横向移动 | 终结轮大招或亲子高光 | P1/P2 使用，首发可只做表现加分 |

动作设计边界：

| 边界项 | 设计要求 |
| --- | --- |
| 真实道具 | 默认空手识别，不提示用户拿棍子、拖把、雨伞等硬物 |
| 手部细节 | 不做手指抓握、手腕旋转、手掌朝向识别 |
| 真实空间 | 不做真实击中距离、真实草杆高度或前后纵深移动 |
| 动作幅度 | 允许中等幅度挥臂，不奖励过大甩臂，避免客厅空间风险 |
| 身体朝向 | 不要求侧身或转体，角色动画可以承担“练剑”表现 |
| 遮挡动作 | 不把手臂从身体背后绕出、双手交叉、贴近脸部挥动作为核心动作 |
| 移动端 | 可降低挥臂幅度，重点保留方向、节奏和命中反馈 |

## 7. 飞蓬与叶片类型

| 类型 | 表现 | 玩家应对 | 作用 |
| --- | --- | --- | --- |
| 普通飞蓬 | 标准高度，叶片稀疏 | 上下刷叶后横扫 | 建立基础规则 |
| 高飞蓬 | 草杆更高，上层叶片更多 | 抬高手臂完成上层刷叶 | 引导玩家拉开动作幅度 |
| 矮飞蓬 | 叶片集中在低处 | 手臂下压或轻微下蹲刷叶 | 引入高度变化 |
| 风中飞蓬 | 草杆轻轻左右摆动 | 等它回正再刷叶或横扫 | 引入时机判断 |
| 双杆飞蓬 | 两根草杆靠得近 | 左右切换目标连续刷叶 | 中后段变化 |
| 飞絮飞蓬 | 斩断后飞出绒毛 | 挥手收集飞絮加分 | P1/P2 高光反馈 |
| 金叶飞蓬 | 少量叶片带金色边 | 打中获得加时或加分 | P1/P2 惊喜目标 |

首发版本只需要普通飞蓬、高飞蓬、风中飞蓬三类。矮飞蓬、双杆飞蓬、飞絮飞蓬和金叶飞蓬可作为 P1/P2 扩展。

## 8. 规则与评分

### 8.1 基础规则

| 规则项 | 说明 |
| --- | --- |
| 单局目标 | 限定时间内完成尽可能多株飞蓬的清叶和横扫 |
| 清叶进度 | 每株飞蓬有若干叶片层，命中正确方向和高度后清掉对应叶片 |
| 可斩断状态 | 清叶达到 70%-100% 后进入横扫窗口 |
| 横扫结果 | 在窗口内横向挥臂可折断草杆，清叶越完整终结分越高 |
| 失败条件 | 挥错方向、时机过慢或目标层偏差时，本次叶片不脱落或只掉少量分 |
| 失败处理 | 不扣生命，只断连击或降低本株评级 |
| 高光机会 | 连续清叶、完整清叶和漂亮横扫触发慢动作与飞絮表现 |
| 结算依据 | 总分、完成株数、最高连击、完美横扫次数和本局最佳飞蓬 |

### 8.2 评分建议

| 行为 | 分数 |
| --- | --- |
| 正确方向刷掉 1 层叶片 | +10 |
| 高度匹配良好 | +5 |
| 连续 5 次清叶 | +25 |
| 完整清叶达到 90% 以上 | +40 |
| 横扫斩断 | +50 |
| 蓄力后横扫命中 | +20 |
| 风中飞蓬回正时命中 | +30 |
| 挥错方向 | 不扣分，断连击 |
| 横扫过早 | 不扣分，提示“叶子还没清干净” |

| 评分原则 | 说明 |
| --- | --- |
| 鼓励方向 | 鼓励“刷得准、连得顺、最后一下收得漂亮” |
| 失败处理 | 不做负分惩罚，避免儿童把挥臂动作和挫败绑定 |
| 终结权重 | 横扫是高光，但不能压过刷叶过程；刷叶爽感才是核心 |

### 8.3 评级

| 评级 | 条件示例 |
| --- | --- |
| S | 总分高，至少 3 次完整清叶，横扫命中率高 |
| A | 完成整局，有稳定连击和至少 1 次漂亮横扫 |
| B | 完成整局，多数飞蓬能进入可斩断状态 |
| C | 能完成基础上下挥臂，但命中方向或节奏不稳定 |

评级文案保持鼓励，不使用“手太慢”“打得差”等挫败表达。

### 8.4 分屏模式胜利规则

| 判定顺序 | 胜利条件 |
| --- | --- |
| 第一优先级 | 总分更高的一方获胜 |
| 第二优先级 | 总分相同时，完成株数更多的一方获胜 |
| 第三优先级 | 完成株数也相同时，完美横扫次数更多的一方获胜 |
| 第四优先级 | 完美横扫也相同时，最高连击更高的一方获胜 |
| 并列处理 | 以上全部相同时，判定为并列胜利，结算文案强调“都刷得很干净” |

分屏模式的胜利表达要轻对抗，不使用“失败”“淘汰”“打败你”等强竞技词。落后一方也要展示个人亮点，例如最高连击、最佳飞蓬或一次漂亮横扫。

## 9. 难度曲线

### 9.1 单局节奏

| 阶段 | 时间 | 内容 |
| --- | --- | --- |
| 新手段 | 0-20 秒 | 普通飞蓬为主，叶片层提示明显，挥臂窗口宽 |

| 参数 | 低难度 | 中难度 | 高难度 |
| --- | --- | --- | --- |
| 叶片数量 | 少，层级清楚 | 标准 | 更多，间距更密 |
| 挥臂窗口 | 宽，提示长 | 标准 | 更短，但仍可读 |
| 高度要求 | 宽松 | 标准 | 稍严格 |
| 风摆幅度 | 无或很小 | 轻微 | 稍大 |
| 横扫窗口 | 长 | 标准 | 稍短 |
| 失败惩罚 | 只断连击 | 断连击 | 断连击，不建议扣分 |

| 游戏模式 | 默认难度 | 使用边界 |
| --- | --- | --- |
| 单人模式 | 低-中难度 | 首发主模式，适合首次体验、常规练习和个人挑战 |
| 分屏模式 | 中难度 | P1 扩展，适合两名玩家左右分区挑战、分数对比和家庭围观 |

## 10. 模式设计

### 10.1 P0 单人模式：路边练剑

| 项目 | 内容 |
| --- | --- |
| 目标 | 单名玩家在限定时间内刷掉叶片、横扫斩断尽可能多株飞蓬 |
| 首版原因 1 | 规则最简单 |
| 首版原因 2 | 对人数要求低 |
| 首版原因 3 | 上下挥臂和横向挥臂都可由 2D 姿势识别稳定判断 |
| 首版原因 4 | 反馈天然强：叶片减少、草杆变干净、最后折断 |
| 首版原因 5 | 大屏围观能一眼看懂哪一下打中了 |

### 10.2 P1 分屏模式：飞蓬对决

| 项目 | 内容 |
| --- | --- |
| 规则 | 两名玩家在左右分屏区域内各自挑战一组飞蓬，分别完成刷叶、横扫和结算 |
| 分屏方式 | 左侧玩家对应左侧飞蓬区，右侧玩家对应右侧飞蓬区，双方使用相同时间或相同飞蓬数量 |
| 胜利判定 | 先比总分，再比完成株数、完美横扫次数和最高连击；全部相同则并列胜利 |
| 体验重点 | 同屏对比、围观起哄和“再比一局” |
| 边界 | 不做身体碰撞，不做抢目标玩法；同屏挥臂必须保持左右安全距离和识别区域隔离 |

### 10.3 P2 模式：放学路挑战

| 项目 | 内容 |
| --- | --- |
| 规则 | 连续解锁校门口、低矮围墙、小卖部门口、田埂边等路边场景 |
| 变化项 | 每个场景改变飞蓬密度、风摆节奏和远景物件 |
| 适合场景 | 周末活动、家庭路线挑战和轻运营 |

## 12. 反馈设计

| 事件 | 画面反馈 | 音效反馈 | 文案方向 |
| --- | --- | --- | --- |
| 成功刷叶 | 对应叶片啪地弹飞，草杆露出一截 | 唰、啪、沙沙 | “刷掉了” |
| 连续清叶 | 叶片逐层脱落，连击数字跳动 | 连续轻快击打音 | “连着来” |
| 高度命中好 | 目标层亮一下，叶片飞得更远 | 清亮叮声 | “这一层很准” |
| 挥错方向 | 叶片晃动但没有脱落 | 轻微擦过声 | “换个方向再来” |
| 横扫就绪 | 草杆变亮，屏幕出现大字“横扫！” | 短暂停顿 + 风声 | “最后一招” |
| 横扫斩断 | 草杆咔地折断，顶部飞出，飞絮散开 | 咔、呼、掌声 | “收尾漂亮” |
| 风中命中 | 飞蓬回正瞬间被刷掉叶片 | 风声切入命中音 | “等得刚刚好” |

| 反馈原则 | 说明 |
| --- | --- |
| 核心爽点 | 叶片层层减少必须比单次加分更明显 |
| 失败语气 | 轻松纠偏，不羞辱玩家 |
| 表现边界 | 不做危险刀剑、真实砍伐或暴力破坏表现 |
| 记忆点 | 最后一刀横扫可以做轻慢动作，但不能拖长单局节奏 |

## 13. 美术方向

| 分类 | 设计要求 |
| --- | --- |
| 场景元素 | 小学校门远景、低矮围墙、水泥路、土路边、草丛、小卖部门口、电线杆 |
| 道具元素 | 书包、虚拟小木棍、粉笔白线、搪瓷杯、路边小石子 |
| 飞蓬表现 | 高、细、直，叶片层层分布，轮廓要比背景更清楚 |
| 光线氛围 | 明亮暖日光，可以是放学后的金色光，但不能昏暗 |
| 围观氛围 | 远景可有同学剪影、校门口人影或书包摆放，增强童年场景 |
| 反馈层级 | 叶片、草杆、挥臂轨迹、清叶进度必须比远景更清楚 |
| 主色建议 | 草绿、浅黄、粉笔白、校门红砖、天空浅蓝形成对比 |
| 色彩边界 | 不做单一土黄、脏绿、旧照片滤镜，不把场景做成荒地除草 |

视觉重点：

- 飞蓬草是主角，怀旧元素只做背景和边角锚点。
- 草杆和叶片必须有清晰的可交互层级，不能像普通背景草。
- 虚拟小木棍可以表现为玩家手边的光影树枝，不要求真实角色持棍。
- 横扫终结时可以出现飞絮飘散，但不要遮挡结算信息。

## 14. 音频方向

| 分类 | 设计要求 |
| --- | --- |
| 环境声 | 夏天风声、远处放学铃、路边树叶声 |
| 操作音效 | 上下刷叶的唰声、叶片脱落啪声、草杆轻微咔声 |
| 社交音效 | 远处同学起哄、轻口哨、掌声 |
| 开场音乐 | 温暖轻快，带一点放学路上的自由感 |
| 游戏中音乐 | 使用短循环节拍，配合上下挥臂形成刷刷节奏 |
| 高光音乐 | 横扫就绪时短暂停顿，命中后给上扬音效和飞絮风声 |
| 版权边界 | 所有音乐和音效必须原创或抽象化，不使用真实老歌、影视配乐或可识别 IP 声音 |

## 18. 风险与处理

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 用户真的拿棍子挥 | 客厅安全问题 | 所有用户文案使用“空气小木棍”，准备页增加空手提示，不做真实道具识别奖励 |
| 玩法被理解成割草 | 童年情绪变弱，可能产生劳动或破坏感 | 包装为“练剑木桩”和“刷叶收尾”，避免“除草”“砍草” |
| 上下挥臂重复导致疲劳 | 儿童或家长不愿连续玩 | 单局 60-90 秒，叶片数量控制，穿插横扫高光和目标切换 |
| 叶片层看不清 | 用户不知道打哪一层 | 高亮当前目标层，减少同屏叶片噪声，低难度配置放大叶片提示 |
| 横扫窗口不明显 | 终结动作触发率低 | 清叶进度、草杆高亮和“横扫！”提示三者同步 |
| 风中飞蓬像随机 | 玩家不信服 | 风摆规律可读，回正窗口有明显视觉提示 |
| 体感识别误判方向 | 连击体验受损 | 方向判定给宽容窗口，允许一定斜向动作，错误只断连击不扣分 |
| 场景滑向荒地杂草 | MotionX 风格不统一 | 保持明亮放学路、校门远景和干净路边，不做荒地、脏墙、暗角 |

## 19. 验证标准

| 验证项 | 通过标准 |
| --- | --- |
| 新手理解 | 新用户不看长说明，也能在第一株飞蓬上做出上下挥臂 |
| 动作识别 | 玩家正面站立时，上挥、下挥、横扫能稳定区分 |
| 安全表达 | 用户不会被引导去拿真实硬物挥舞 |
| 清叶反馈 | 围观者能看懂叶片正在一层层减少 |
| 横扫理解 | 玩家能理解“清叶后才能横扫收尾” |
| 低难度配置 | 大多数新玩家能完成至少 2-3 株飞蓬 |
| 失败体验 | 挥错方向反馈轻松，不产生明显挫败 |
| 结算可读 | 结算页能让玩家明确看到完成株数、称号和再来一局入口 |
| 再玩意愿 | 单局后存在明显“再来一局，换一棵更高的试试”的意愿 |

## 20. 与产品主循环的关系

| 关系项 | 说明 |
| --- | --- |
| 所属主题 | 建议放在「童年户外 / 放学路边」主题下 |
| 编排位置 | 可进入 `童年的一天` 的“下午·放学路上”或“周末·户外小挑战”时段 |
| 用户价值 | 提供一个很有记忆点、动作简单、爽感清楚的童年路边体感体验 |
| 产品价值 | 验证上下挥臂、横向挥臂、目标层反馈和终结高光能否支撑完整短局 |
| 成立指标 | 首局完成率、横扫就绪触发率、再来一局率 |
| 复用方向 | 打竹节、拍纸片、挥拍打落物、节奏刷目标等玩法 |
| 复用模板 | 「方向挥臂 / 目标层清理 / 终结动作」这一类内容的基础模板 |

飞蓬小剑客可以作为 `打水漂` 之外的第二个童年户外轻运动样板：打水漂验证“横向挥臂 + 飞行结果演出”，飞蓬小剑客验证“连续方向挥臂 + 可视化清理进度 + 终结高光”。如果它的清叶反馈和横扫触发成立，后续可以扩展出更多“路边小玩法”，丰富 `童年户外` 的内容池。
