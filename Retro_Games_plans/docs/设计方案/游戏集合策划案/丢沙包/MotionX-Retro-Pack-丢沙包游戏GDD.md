# MotionX Retro Pack / 丢沙包游戏 GDD

> 本文是 `MotionX Retro Pack / 时光体感馆` 中「丢沙包」玩法的单独 GDD。它基于《线下童年游戏体感改编清单》中对丢沙包的首批优先级判断展开：核心动作是左右闪避、下蹲、抬手接球、挥臂投掷；单局目标是让家庭用户在 60-90 秒内看懂、动起来、愿意再玩一局。

## 游戏概述

「丢沙包」是一款以童年操场课间游戏为主题的短局体感玩法。玩家站在屏幕前的躲避区，面对从上方或下方虚拟投手飞来的沙包，通过左右闪避、下蹲和抬手接球来完成一轮轮动作判断。

游戏的核心过程是“躲开普通球，抓住慢球，接住后反击”：沙包飞来前会有清晰预告，玩家根据轨迹选择躲避、下蹲或接球；成功接住可接沙包后，会进入短暂反击窗口，玩家挥臂把沙包打回投手或目标牌，获得更高分数和高光反馈。

单人首发模式强调操场生存和反击爽感，目标是在 60-90 秒内尽量少被击中，并通过接球反击、连续闪避和稳定参与获得更高分数、评级和称号。后续双人守线模式可以让两名玩家并排负责左右半区，重点是横向补位、互相让位和同屏围观。

整体体验要秒懂、轻运动、可围观：被击中不应立即出局，而是以扣生命、断连击或“最后一球”保护来降低挫败；画面重点放在飞行轨迹、擦身闪避、抬手接住、反击命中和粉笔计分牌反馈上，让家庭用户一眼看懂“刚才躲得好不好、接得漂不漂亮”。

## 1. 游戏定位

| 项目 | 定义 |
| --- | --- |
| 游戏名 | 丢沙包 |
| 内容线 | 童年操场 / 上午课间 |
| 推荐端 | 大屏端优先，移动端可做竖屏适配 |
| 推荐人数 | 1-2 人首发；长期可扩展 1-4 人轮流或组队 |
| 单局时长 | 60-90 秒 |
| 核心体验 | 躲开飞来的沙包，抓住慢球反击，获得生存分、接球分和反击分 |
| 目标用户 | 亲子家庭、儿童、想快速热身的轻运动用户 |
| 设计关键词 | 秒懂规则、轻运动、可围观、命中反馈强、失败不挫败 |

丢沙包是首批玩法中最适合作为操场动作样板的游戏之一：用户不用理解复杂规则，只要看到沙包飞来就会自然闪避；接住和反击能形成清晰的高光瞬间，适合在客厅大屏上被家人围观。

## 2. 设计目标

- 5 秒内看懂：沙包飞来，身体躲开或抬手接住。
- 30 秒内学会：普通球躲避，慢速发光球可接，接住后挥臂反击。
- 失败可接受：被击中不立即出局，只扣生命或连击，保证儿童不会很快离场。
- 动作原语收敛：只使用左右闪避、下蹲、举手接球、挥臂投掷，不做精细手指和真实前后纵深判断。
- 围观可读：飞行轨迹、命中区、擦身、接住、反击都要远距离可见。
- 复古感不靠直白文案：用操场白线、沙包布料、下课铃、广播、粉笔计分牌、围观同学剪影表达年代气质。

## 3. 核心玩法概述

玩家站在操场中线附近的躲避区，上下两侧各有一名虚拟投手。沙包主要沿垂直于中线的方向来回飞向躲避者，躲避者不能越过中线，只能在中线附近左右横移、下蹲或抬手接球。玩家接住可接沙包后，进入短暂反击窗口，把沙包打回上方或下方投手区域。

核心循环：

```text
沙包预告
→ 沙包飞来
→ 玩家躲避 / 下蹲 / 接球
→ 结算本次动作反馈
→ 若接住则进入短反击窗口
→ 玩家挥臂投掷反击
→ 加分、连击、难度微升
```

### 3.1 顶视图场地关系

丢沙包的场地应按顶视图理解：中线横向贯穿场地，躲避者在中线附近活动；两个投手分别站在中线上方和下方，向中间躲避者投沙包。游戏镜头可以做成略带透视的 2.5D 操场画面，但规则和判定必须先服从这个顶视图结构。

```text
+----------------------------------------------------------------------------+
|                                                                            |
|                              上方投手                                      |
|                                ○                                           |
|                                ↓                                           |
|                                                                            |
|                                                                            |
|                                                                            |
|  ------------------------------------------------------------------------  |
|                              中线                                          |
|                                                                            |
|                         躲避者活动区                                       |
|                         ←   ●   →                                         |
|                                                                            |
|                                                                            |
|                                ↑                                           |
|                                ○                                           |
|                              下方投手                                      |
|                                                                            |
+----------------------------------------------------------------------------+
```

场地规则：

- 中线是躲避者的主要活动参照，躲避者在中线附近横向躲闪。
- 上下投手负责来回打中间躲避者，不是左右两侧夹击。
- 玩家可以左右横移、下蹲、抬手接球，但默认不要求真实向前后跑动。
- 沙包轨迹主要从上向中线、从下向中线，也可以少量斜线变化。
- 反击时，玩家把接住的沙包打回上方或下方投手区域，不做自由瞄准打靶。

## 4. 单局流程

```text
回忆开场 10-15 秒
→ 入戏式识别 5-10 秒
→ 操场站位确认
→ 基础教学 10 秒内
→ 游戏中 60-90 秒
→ 结算界面 10-20 秒
→ 奖励卡片 / 再来一局
```

### 4.1 回忆开场

画面从操场广播和下课铃开始，粉笔线、教学楼影子和几名围观同学剪影出现。沙包从画面边缘滚到白线旁，计分牌亮起。

可用短句：

- “下课铃响了，操场上已经开局。”
- “站到白线里，沙包要来了。”
- “这一局，看谁能躲到最后。”

避免使用“复古”“怀旧”“八零九零”等直白年代词。

### 4.2 入戏式识别

识别阶段包装成操场站位，不使用“校准”“骨骼识别”等技术词。

推荐话术：

- “站到白线中间。”
- “举手让同学看到你。”
- “左右挪一步，试试活动范围。”
- “准备好了，第一只沙包马上来。”

识别确认条件：

- 玩家身体中心在安全站位框内。
- 头肩和双手可稳定识别。
- 左右活动空间足够。
- 多人模式下每名玩家有独立颜色区。

## 5. 操作与动作判定

| 动作 | 玩家行为 | 游戏含义 | 判定原则 |
| --- | --- | --- | --- |
| 左右闪避 | 身体中心向左 / 右移动 | 躲开中线或斜线来球 | 只判断粗粒度区域，不追求精确厘米级位移 |
| 下蹲 | 身体高度明显降低 | 躲开高位横飞球 | 判断头肩高度下降，不要求标准深蹲 |
| 抬手接球 | 一只或双手进入接球区并保持短瞬间 | 接住慢速可接沙包 | 只允许对发光慢球生效，避免所有球都可接导致规则混乱 |
| 挥臂投掷 | 接球后手臂向前 / 侧前方快速摆动 | 反击投手或目标牌 | 在短反击窗口内触发，不计算真实出手角度 |
| 站稳恢复 | 被击中或反击后回到站位框 | 进入下一轮 | 给 1-2 秒缓冲，避免连续判罚 |

动作设计边界：

- 不做真实手掌抓取。
- 不做前后纵深闪避作为核心判定。
- 不做高速连续球导致儿童无法恢复。
- 不把身体转身角度作为必需动作。
- 移动端可降低左右位移要求，重点保留躲避和接球。

## 6. 沙包类型

| 类型 | 表现 | 玩家应对 | 作用 |
| --- | --- | --- | --- |
| 普通沙包 | 标准布沙包，轨迹清楚 | 左右闪避 | 建立基础节奏 |
| 高位沙包 | 带高位提示线，从肩上方横飞 | 下蹲 | 引入动作变化 |
| 慢速可接沙包 | 速度较慢，带轻微亮边或布标飘动 | 抬手接球 | 制造高光和反击机会 |
| 连续沙包 | 两只间隔出现，方向不同 | 连续闪避 | 提升中后段紧张感 |
| 假动作沙包 | 投手预备动作明显，但实际晚半拍出手 | 等待后再躲 | 中高难度使用，不放入新手前 20 秒 |
| 奖励沙包 | 带贴纸或铃铛小挂件 | 躲开或接住均给额外分 | 活跃节奏，降低挫败感 |

首发版本只需要普通沙包、高位沙包、慢速可接沙包三类。连续沙包、假动作沙包和奖励沙包可作为 P1/P2 扩展。

## 7. 规则与评分

### 7.1 基础规则

- 玩家初始有 3 点活力。
- 普通沙包命中扣 1 点活力并打断连击。
- 躲开沙包加基础分。
- 擦身躲过加额外分，但只作为表现反馈，不要求玩家刻意追求。
- 慢速可接沙包接住后进入 3 秒反击窗口。
- 反击命中投手或目标牌获得高分，并短暂降低下一轮压力。
- 活力归零不立即黑屏失败，进入“最后一球”保护：再被命中才结束，或时间到正常结算。

### 7.2 评分建议

| 行为 | 分数 |
| --- | --- |
| 成功躲避普通沙包 | +10 |
| 成功下蹲躲避高位沙包 | +15 |
| 擦身躲过 | +20 |
| 接住可接沙包 | +30 |
| 反击命中 | +50 |
| 连击每 5 次 | +25 |
| 被击中 | -10，断连击 |
| 最后一球保护成功撑到结束 | +40 |

评分不应过度惩罚儿童。被击中主要打断连击和制造轻松反馈，分数扣减保持克制。

### 7.3 评级

| 评级 | 条件示例 |
| --- | --- |
| S | 分数高、命中少、至少 2 次接球反击 |
| A | 完成整局，躲避稳定，有 1 次接球或高连击 |
| B | 完成整局，被击中较多但持续参与 |
| C | 中途结束或识别不稳定，但完成基础体验 |

评级文案保持鼓励，不使用羞辱性表达。

## 8. 难度曲线

### 8.1 单局节奏

| 阶段 | 时间 | 内容 |
| --- | --- | --- |
| 新手段 | 0-20 秒 | 普通沙包为主，方向预告明显，速度慢 |
| 变化段 | 20-50 秒 | 加入高位沙包和可接沙包，鼓励下蹲与接球 |
| 高潮段 | 50-90 秒 | 提高出球频率，加入少量连续沙包或左右交替 |

### 8.2 难度参数

| 参数 | 低难度 | 中难度 | 高难度 |
| --- | --- | --- | --- |
| 沙包速度 | 慢，预告长 | 标准 | 更快，预告短 |
| 出球间隔 | 2.5-3 秒 | 1.8-2.4 秒 | 1.2-1.8 秒 |
| 轨迹数量 | 左 / 右 / 中 | 增加高位 | 增加连续和假动作 |
| 可接球比例 | 高 | 中 | 低 |
| 被击中惩罚 | 轻 | 标准 | 标准，不建议更重 |

儿童模式默认低难度，家庭挑战默认中难度。高难度只用于排行榜或活动挑战，不作为首次体验。

## 9. 模式设计

### 9.1 首发模式：操场生存赛

目标是在限定时间内尽量少被击中，并通过接球反击获得高分。

适合首版原因：

- 规则最简单。
- 对人数要求低。
- 动作原语完整覆盖。
- 失败保护好做。
- 大屏围观容易看懂。

### 9.2 P1 模式：接住反击

更多出现可接沙包，强调“接住再打回去”。适合亲子轮流挑战，突出高光动作。

### 9.3 P1 模式：双人守线

两名玩家并排站在中线附近，分别负责中线活动区的左半区和右半区。沙包仍由上方和下方投手向中间打来，双人重点是横向补位和互相让位，不改成左右两侧投手夹击。

### 9.4 P2 模式：班级挑战

虚拟同学队伍轮流登场，玩家代表一个班级累计分数。适合活动运营和周末家庭挑战。

## 11. 反馈设计

| 事件 | 画面反馈 | 音效反馈 | 文案方向 |
| --- | --- | --- | --- |
| 成功躲避 | 沙包擦身飞过，粉笔线轻闪 | 呼啸声、同学叫好 | “躲得漂亮” |
| 下蹲成功 | 高位沙包从头顶飞过 | 风声从上方掠过 | “这一蹲很及时” |
| 被击中 | 沙包弹开，活力少一点 | 软布撞击声 | “没事，下一球躲回来” |
| 接住沙包 | 手边出现抓住特效，时间短暂停顿 | 布料啪声、掌声 | “接住了，打回去” |
| 反击命中 | 投手身后目标牌翻动 | 计分牌叮声 | “反击成功” |
| 连击提升 | 连击数字跳动，围观同学挥手 | 连续加分音 | “连着躲开了” |

反馈要轻松，不把命中表现成真实疼痛或攻击伤害。沙包材质表现为软布、棉花、贴布，不做危险投掷感。

## 12. 美术方向

场景元素：

- 操场白线、粉笔计分牌、教学楼窗户、广播喇叭。
- 沙包使用布料拼色、针脚、旧标签、小铃铛等细节。
- 投手可以是半写实剪影或卡通同学，不做强敌人感。
- 地面可有粉笔箭头、跑道线、落叶、课间小旗。
- 远景保留围观同学和操场边树影，增强家庭围观氛围。

色彩建议：

- 主色用操场红、粉笔白、校服蓝、树荫绿形成对比。
- 不做单一棕黄旧照片色调。
- 沙包轨迹和交互提示要比背景更亮，保证可玩性优先。

## 13. 音频方向

基础音频：

- 下课铃。
- 操场广播底噪。
- 沙包飞行呼啸。
- 软布命中声。
- 粉笔计分牌跳分声。
- 同学起哄和掌声。

音乐节奏：

- 开场轻快，进入游戏后保持短循环鼓点。
- 沙包加速时增加节拍密度。
- 接球反击时给短暂停顿和上扬音效，突出高光。

## 14. 奖励卡片

首发奖励只做轻收集，不做装备和数值成长。

可解锁卡片：

| 卡片 | 触发条件 |
| --- | --- |
| 沙包王 | 单局达到 A 级以上 |
| 接住了 | 单局完成 1 次接球反击 |
| 白线守护者 | 活力未归零完成整局 |
| 擦身飞过 | 单局触发 3 次擦身躲避 |
| 课间小队 | 双人模式完成一局 |

卡片用于结算后的收藏和分享，不影响下一局能力。

- 平均被击中次数。
- 接球触发率。
- 反击成功率。
- 再来一局率。
- 儿童模式 / 标准模式选择比例。
- 大屏端与移动端完成率差异。

判断玩法是否成立的关键不是最高分，而是首局完成率、接球反击触发率和再来一局率。

## 16. MVP 范围

### 16.1 P0 必须有

- 回忆开场。
- 入戏式识别与站位框。
- 60-90 秒操场生存赛。
- 普通沙包、高位沙包、慢速可接沙包。
- 左右闪避、下蹲、抬手接球、挥臂反击。
- 分数、活力、连击、时间 HUD。
- 被击中、躲避、接住、反击四类核心反馈。
- 结算页和本局称号。
- 至少 1 张奖励卡片。

### 16.2 P0 可不做

- 多地图。
- 真实多人对抗。
- 精确投掷角度。
- 复杂排行榜。
- 照片合成。
- 角色换装。
- 运营活动和任务链。
- 高难度假动作球。

### 16.3 P1 / P2 再做

- 双人守线。
- 接住反击专项模式。
- 班级挑战活动。
- 更多沙包皮肤。
- 家庭周挑战。
- 纪念照片或课间合影卡片。

## 17. 风险与处理

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 玩家左右位移空间不足 | 躲避失败率高 | 准备页检查活动范围，移动端降低位移要求 |
| 儿童下蹲不标准 | 高位球误判 | 判定头肩高度变化，不要求标准深蹲 |
| 接球动作不稳定 | 高光体验缺失 | 可接球速度放慢，接球区做大，允许单手或双手 |
| 连续命中造成挫败 | 用户不愿再玩 | 被击中后给恢复窗口，活力归零进入最后一球保护 |
| 沙包轨迹看不清 | 围观和操作都受影响 | 轨迹线、预告方向和沙包颜色优先保证可读 |
| 规则像打靶而不是丢沙包 | 童年场景弱 | 保留躲避为主、接住反击为高光，不把投掷反击变成唯一核心 |

## 18. 验证标准

一版可演示版本完成后，应至少验证以下现象：

- 新用户不看说明也能在第一轮沙包后做出躲避。
- 儿童模式中，大多数玩家能完成一整局而不是快速失败。
- 玩家能理解发光慢球可以接住。
- 接住后挥臂反击能稳定触发，并且围观者能看懂发生了什么。
- 被击中反馈轻松，不产生疼痛或暴力感。
- 结算页能让玩家明确看到分数、称号和再来一局入口。
- 单局后存在明显“再来一局”意愿。

## 19. 与产品主循环的关系

丢沙包在 `时光体感馆` 中建议放在「童年操场 / 上午课间」主题下，作为首批可玩的高优先级项目。它承担两个作用：

- 对用户：提供最直观的童年操场体感体验。
- 对产品：验证左右闪避、下蹲、接球、投掷四个动作原语能否支撑一个完整短局。

如果丢沙包的首局完成率、接球反击触发率和再来一局率成立，后续可以把同一套动作原语复用到砸罐子、投沙包打靶、套圈等玩法中，形成「投掷 / 躲避 / 命中反馈」这一类内容的基础模板。
