# MotionX Retro Pack / 打水漂音效需求

> 本文是 `MotionX Retro Pack / 时光体感馆` 中「打水漂」玩法的单游戏音效需求表。目标是把“夏日河边、找扁石子、啪嗒连跳、家人围观”的记忆做成原创、安全、明亮、可重复听的游戏音频资产。

## 1. 音频目标

| 目标 | 设计要求 |
| --- | --- |
| 建立场景 | 用户进入游戏前 3 秒内听出夏日河边、柳树、浅水和孩子围玩的感觉 |
| 帮助动作 | 用水纹提示、蓄力提示、出手反馈帮助玩家理解什么时候挥臂 |
| 强化结果 | 每一次水漂弹跳都要有清楚、轻快、可数的反馈 |
| 保持轻松 | 沉水失败不能刺耳、不能羞辱，像“换一颗再试试” |
| 适合家庭 | 电视外放不吵，儿童和家长都能接受 |
| 版权安全 | 所有音乐、音效、口令均原创或抽象化，不使用真实老歌、影视配乐、真实品牌音源或可识别 IP 声音 |

## 2. 音频分层

| Bus | 内容 | 音量优先级 | 设计规则 |
| --- | --- | ---: | --- |
| `BGM` | 夏日河边轻音乐、游戏中节奏底 | 2 | 不能盖过水纹提示、跳点、水花和倒计时 |
| `AMB` | 蝉声、轻风、柳叶、水面环境 | 1 | 低音量循环，提供空间感，不喧宾夺主 |
| `UI` | 按钮、卡片、计分、跳数牌 | 4 | 短、圆润、清楚，避免高频刺耳 |
| `SFX` | 石子、蓄力、挥臂、水花、沉水、连击 | 5 | 游戏核心反馈优先，单个音效尽量 0.1-0.8 秒 |
| `VOICE` | 入戏口令、轻广播、同伴喊声 | 6 | 不说技术词，出现时压低 `BGM` / `AMB` |
| `COUNTDOWN` | 3、2、1、开始、时间临近 | 7 | 最高优先级，必须清楚可听 |

## 6. 状态触发矩阵

| 游戏状态 | 主要音频 | 辅助音频 | 混音规则 |
| --- | --- | --- | --- |
| 入戏开场 | `amb_river_summer_loop`、`vo_open_river_ready` | `sfx_stone_pick` | `VOICE` 出现时 `BGM` 不进或保持极低 |
| 站位识别 | `vo_stand_line`、`vo_hold_stone` | `sfx_water_ripple_ready` 轻版 | 不使用技术提示音，不说“识别”“校准” |
| 倒计时 | `sfx_countdown_tick`、`sfx_start_go` | `amb_river_summer_loop` | `COUNTDOWN` 优先级最高，压低 `BGM` 4-8 dB |
| 水纹提示 | `sfx_water_ripple_ready` | `vo_throw_on_ripple` 首次出现 | 首次教学播语音，后续只播提示音 |
| 出手瞬间 | `sfx_throw_swing`、`sfx_good_timing` | `sfx_score_tick` | 出手音不能盖住第一跳水花 |
| 连续弹跳 | `sfx_skip_hit_01`、`sfx_skip_hit_mid`、`sfx_skip_hit_far` | `sfx_skip_combo_rise` | 每跳按空间远近和音高变化，不能全部同响度 |
| 沉水失败 | `sfx_stone_sink_soft` | `vo_sink_soft` 偶发 | 失败音比成功音短、轻，不扣分感 |
| 新纪录 | `sfx_best_jump_new` | `vo_new_record` | 可短暂压低 `BGM`，突出高光 |
| 时间临近 | `sfx_time_warning` | BGM 节拍轻微加密 | 不使用刺耳警报 |
| 结算 | `sfx_result_stamp`、`sfx_reward_card` | 同伴轻掌声 | 先出分数，再出称号 / 奖励音 |

## 7. 跳点音效规则

| 跳数 | 音色 | 音高 / 空间 | 设计目的 |
| ---: | --- | --- | --- |
| 1 | 饱满水花，近景清楚 | 原始音高，近景居中 | 让玩家确认“漂起来了” |
| 2 | 清脆水花 | 略升 1-2 个半音，稍远 | 建立连续感 |
| 3 | 更轻的啪嗒 | 再略升，轻微立体声偏移 | 让跳数可听出来 |
| 4 | 细一点的水花 | 高频略多，空间更远 | 表现纵深 |
| 5 | 远处亮水花 | 加一层轻上扬点缀 | 进入高光 |
| 6+ | 小而亮的水花 + 星光感 | 音量略小，尾音更亮 | 奖励玩家，避免吵 |

## 8. 混音与技术规格

| 项目 | 要求 |
| --- | --- |
| 文件格式 | 交付 `wav` 无损源文件；游戏内可转 `ogg` / `aac` |
| 采样率 | 48 kHz |
| 位深 | 24-bit 源文件，运行时可按平台压缩 |
| 声道 | `UI` / 高频 `SFX` 可 mono；`AMB` / `BGM` 建议 stereo |
| 响度 | 同类音效响度统一；沉水和警示类音效不得刺耳 |
| 变体 | 高频音效至少 3 个变体，跳水花类至少 4-6 个变体 |
| 限频 | 语音类同一条 10 秒内最多触发 1 次；失败语音 15 秒内最多触发 1 次 |
| Ducking | `VOICE` / `COUNTDOWN` 出现时，`BGM` / `AMB` 降低 4-8 dB |
| 空间感 | 跳点越远，音量略低、混响略多、瞬态略软 |
| 平台 | 大屏电视优先，手机端保留同一套资产但可降低环境声比例 |

## 10. 版权与风格红线

| 禁止项 | 原因 | 替代方向 |
| --- | --- | --- |
| 真实老歌旋律 | 版权风险，且会破坏原创安全 | 原创轻拨弦、木质打击和明亮上扬动机 |
| 真实影视 / 综艺音效 | 可识别 IP 风险 | 抽象化节目感、广播感 |
| 真实学校广播录音 | 版权和隐私风险 | 原创广播质感短口令 |
| 刺耳警报 | 不适合亲子，容易造成压力 | 木块敲击、水纹加速、轻节拍 |
| 恐怖 / 深水危险音效 | 会让河边场景变紧张 | 木牌提示保持视觉存在，声音仍轻松 |
| 过重 VHS / 旧磁带噪声 | 影响清晰度和现代 UI 质感 | 干净怀旧、轻微生活质感 |

## 11. 验收清单

| 检查项 | 通过标准 |
| --- | --- |
| 场景识别 | 不看画面也能听出夏日河边和水面游戏 |
| 动作帮助 | 玩家能通过水纹提示和出手音理解什么时候挥臂 |
| 跳数可听 | 连续跳点有节奏、远近和轻微音高变化 |
| 失败友好 | 沉水音轻松，不像惩罚或危险警告 |
| 大屏可用 | 电视外放下水花、倒计时、语音都清楚 |
| 不抢画面 | 高频水花和 UI 音不刺耳、不盖住语音 |
| 版权安全 | 没有真实老歌、影视、品牌、街机或可识别采样 |
| 风格统一 | 和 MotionX Retro Pack 的明亮家庭体感、轻怀旧、原创安全一致 |
