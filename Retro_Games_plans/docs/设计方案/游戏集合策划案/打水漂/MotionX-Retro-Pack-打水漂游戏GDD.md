# MotionX Retro Pack / 打水漂游戏 GDD

> 本文是 `MotionX Retro Pack / 时光体感馆` 中「打水漂」玩法的单独 GDD。它把小时候在河边、池塘边找扁石子、比谁跳得远的记忆，改编成适合家庭客厅的短局体感游戏：核心动作是正面可识别的横向挥臂、节奏出手、身体重心稳定和连跳反馈；单局目标是让家庭用户在 60-90 秒内看懂“扔出去、跳起来、连着漂”，并愿意再试一次。

## 游戏概述

「打水漂」是一款以夏日河边童年记忆为主题的短局体感玩法。玩家站在屏幕前的河岸投掷区，不需要真实石子，只用空手动作模拟拿起扁石子、蓄力、横向甩出，让画面中的石子沿水面连续弹跳。

游戏的核心过程是“看水纹，稳住身体，找准节奏横向出手”：每轮系统给出一颗石子和一条水面节奏提示线，玩家先把投掷手停在身体一侧形成蓄力姿态，再在提示窗口内做横向挥臂。系统根据出手时机、水平速度、挥臂幅度和身体稳定度，生成石子的跳数、距离和连击反馈。

首发模式强调个人跳数赛，目标是在 60-90 秒内连续投掷多颗石子，尽量打出更多跳数、更远距离和更稳定连击，最终获得更高分数、评级和称号。后续双人轮流赛可以让两名玩家轮流出手，对比最佳跳数和总分，形成轻松的家庭围观挑战。

整体体验要轻松、清爽、可期待：石子沉水也不做强惩罚，只断连击或换一颗继续；画面重点放在第一跳成功、连续跳点亮起、水花反馈、跳数牌翻动和远处距离牌上，让玩家自然产生“再换一颗试试”的短循环。

## 2. 设计目标

| 目标 | 设计要求 |
| --- | --- |
| 5 秒内看懂 | 站到河岸边，挥手把石子甩出去 |
| 30 秒内学会 | 看风向和水纹提示，手放到身体一侧蓄力，水纹亮起时横向挥臂 |
| 失败可接受 | 石子沉水也不惩罚，换一颗继续扔 |
| 动作原语收敛 | 只使用正面横向挥臂、左右重心调整、短暂停顿蓄力、可选轻下蹲，不做侧身轮廓、精细手腕和真实出手角度判断 |
| 2D 姿势识别优先 | 所有核心动作必须能由肩、肘、腕、髋等屏幕平面关键点稳定判断，不能依赖深度、手掌朝向或身体背面信息 |
| 围观可读 | 石子轨迹、水花、跳数、距离牌和同伴欢呼必须远距离清楚 |
| 复古感不靠旧滤镜 | 用河岸台阶、柳树影子、搪瓷杯、草帽、手绘跳数牌、夏日蝉声表达年代气质 |

## 4. 核心玩法概述

| 核心环节 | 规格 |
| --- | --- |
| 玩家位置 | 站在河岸投掷区，正面面向摄像头和屏幕中的河面 |
| 系统预告 | 每一轮给出一颗石子和一条可读的水面节奏提示线 |
| 玩家蓄力 | 投掷手停在身体一侧，形成“攥着石子”的蓄力姿态 |
| 玩家出手 | 在提示窗口内做一次横向挥臂投掷 |
| 判定输入 | 手腕关键点水平速度、手臂摆动幅度、出手时机、身体中心稳定度 |
| 结果表现 | 连续跳点、距离和连击 |

核心循环：

```text
水面预告
→ 选择 / 获得石子
→ 正面蓄力
→ 挥臂投掷
→ 石子连续弹跳
→ 跳数、距离、连击结算
→ 捡下一颗石子 / 进入下一轮
```

### 4.1 场地关系

| 场地项 | 规格 |
| --- | --- |
| 空间理解 | 按横向河面理解：玩家在近景岸边投掷，石子从近景向远处水面弹跳 |
| 镜头表现 | 可以做成 2.5D 河岸舞台 |
| 判定边界 | 只依赖玩家屏幕平面内的 2D 姿势关键点 |
| 不要求 | 不要求真实向前扔出距离，也不要求玩家真的侧身到只剩半身轮廓 |

```text

|  远处芦苇 / 小桥 / 夕阳云影                                                 |
|                                                                            |
|             跳点 5          跳点 6             距离牌                       |
|          ~~~~~~~~~~      ~~~~~~~~~~          [ 18m ]                        |
|                                                                            |

|                                                                            |
|  跳点 1          跳点 2                                                      |

|                                                                            |
|----------------------------------------------------------------------------|
|  河岸投掷区                 玩家站位框                                      |
|                             ←  ●  →                                         |
+----------------------------------------------------------------------------+
```

| 场地规则 | 说明 |
| --- | --- |
| 站位 | 玩家始终站在岸边站位框内，不要求真实前后移动 |
| 朝向 | 玩家正面朝向摄像头，允许轻微转肩营造“侧身感”，但不把真实侧身作为核心判定 |
| 结果反馈 | 石子从近景向远景水面弹跳，跳点和水花负责反馈成绩 |
| 节奏提示 | 水纹提示线只表示推荐出手节奏，不做复杂物理模拟展示 |
| 变量权重 | 风向、涟漪和障碍物作为轻变量，不能压过基础挥臂规则 |
| 多人边界 | 双人模式默认轮流出手，不做同时投掷，避免人体重叠、遮挡和画面反馈混乱 |

## 6. 操作与动作判定

| 动作 | 玩家行为 | 游戏含义 | 2D 姿势识别判定原则 |
| --- | --- | --- | --- |
| 正面蓄力 | 投掷手停在身体左 / 右侧，另一只手自然放松 | 进入出手预备 | 判断投掷手腕相对同侧肩 / 髋的水平偏移和短暂停留，不判断身体真实侧转 |
| 横向挥臂投掷 | 手腕关键点从身体一侧快速扫向另一侧或前中线 | 把石子甩向水面 | 以手腕水平速度峰值、水平位移、肘腕协同和提示窗口匹配度为主，不计算 3D 出手角 |
| 重心稳定 | 出手前后身体中心保持在站位框内 | 让石子更平稳 | 用肩中心 / 髋中心的屏幕平面位移判断稳定度，不鼓励大幅转身、后仰或跨步 |
| 轻下蹲捡石子 | 两轮之间轻微降低身体高度或伸手 | 换下一颗石子 | 可选入戏动作，只判断头肩高度小幅下降，不要求深蹲，不作为失败条件 |
| 节奏跟随 | 在水纹亮起时完成挥臂速度峰值 | 命中更好的水面节奏 | 判断速度峰值落在宽容窗口内，不要求毫秒级准确 |

动作设计边界：

| 边界项 | 设计要求 |
| --- | --- |
| 手部细节 | 不做真实手腕旋转、手指捏石子、手掌朝向识别 |
| 真实空间 | 不做真实投掷距离、真实地面落点或前后纵深移动 |
| 动作幅度 | 不要求大幅甩臂，避免儿童和客厅空间风险 |
| 身体朝向 | 不把身体转身角度、肩膀朝向或侧身轮廓作为必需成绩来源 |
| 遮挡动作 | 不把手臂从身体背后甩出、手穿过躯干前方造成遮挡、双手交叉等姿势作为核心动作 |
| 移动端 | 可降低挥臂幅度，重点保留时机和节奏反馈 |

## 7. 石子与水面类型

| 类型 | 表现 | 玩家应对 | 作用 |
| --- | --- | --- | --- |
| 普通扁石 | 圆扁石子，水花清楚 | 正常挥臂 | 建立基础规则 |
| 轻薄石 | 颜色更浅，飞得快但容易飘 | 出手要稳 | 制造高跳数机会 |
| 厚石子 | 更沉，第一跳水花大 | 需要更大挥臂幅度 | 让力量感更明显 |
| 幸运石 | 带小贴纸或星形纹路 | 命中节奏给额外跳数 | 制造惊喜 |
| 顺风水面 | 水纹向远处流动 | 在亮线时出手 | 提供加成段 |
| 小浪水面 | 局部水纹起伏 | 避开浪点或稳住出手 | 中后段变化 |

首发版本只需要普通扁石、轻薄石、厚石子三类。幸运石、顺风水面和小浪水面可作为 P1/P2 扩展。

## 8. 规则与评分

### 8.1 基础规则

| 规则项 | 说明 |
| --- | --- |
| 单局目标 | 限定时间内连续投掷多颗石子 |
| 出手结果 | 每次出手根据时机、幅度和稳定度生成 1-8 次基础弹跳 |
| 跳点计分 | 每个跳点给基础分，连续跳点越多加成越高 |
| 失败条件 | 出手过早、过晚或身体晃动过大时，石子会较早沉水 |
| 失败处理 | 沉水不扣生命，只断当前连击并给轻松反馈 |
| 高光机会 | 每隔数轮出现一颗“好石子”，鼓励玩家把握高光机会 |
| 结算依据 | 时间结束后按最佳跳数、总距离、连续成功次数和高光出手结算 |

### 8.2 评分建议

| 行为 | 分数 |
| --- | --- |
| 每次成功弹跳 | +10 |
| 第 3 跳以后每跳追加 | +5 |
| 命中出手节奏 | +20 |
| 稳定出手 | +15 |
| 单颗石子达到 5 跳 | +40 |
| 单颗石子达到 8 跳 | +80 |
| 连续 3 颗石子成功漂起 | +50 |
| 石子第一跳沉水 | 不扣分，断连击 |

| 评分原则 | 说明 |
| --- | --- |
| 鼓励方向 | 鼓励“多试、多扔、多漂几下” |
| 失败处理 | 不对失败投掷做负分惩罚 |

### 8.3 评级

| 评级 | 条件示例 |
| --- | --- |
| S | 总分高，至少 1 次 8 跳，连续成功稳定 |
| A | 完成整局，至少 1 次 5 跳，节奏命中较多 |
| B | 完成整局，多数石子能漂起 |
| C | 能完成基础投掷，但跳数较少或识别不稳定 |

| 评级文案原则 | 说明 |
| --- | --- |
| 语气 | 保持轻松 |
| 禁用表达 | 不使用“投得太差”等挫败表达 |

## 12. 反馈设计

| 事件 | 画面反馈 | 音效反馈 | 文案方向 |
| --- | --- | --- | --- |
| 成功第一跳 | 石子贴水弹起，圆形波纹扩散 | 啪的一声水花 | “漂起来了” |
| 连续弹跳 | 跳点逐个亮起，跳数牌翻页 | 连续清脆水花 | “再跳一下” |
| 高跳数 | 水面拉出亮线，同伴剪影挥手 | 掌声、口哨、跳分声 | “这颗真会飞” |
| 沉水 | 石子咕咚入水，小水泡冒起 | 轻柔咕咚声 | “这颗沉得有点急，换一颗” |
| 命中节奏 | 水纹和出手动作同步闪亮 | 清亮叮声 | “水纹刚刚好” |
| 连击提升 | 连击数字跳动，岸边跳数牌翻动 | 连续加分音 | “手感来了” |

| 反馈原则 | 说明 |
| --- | --- |
| 失败语气 | 反馈要轻松，不把失败做成严肃扣分或尴尬惩罚 |
| 表现边界 | 石子和水花表现为夏日游戏感，不做危险投掷或砸击感 |

## 13. 美术方向

| 分类 | 设计要求 |
| --- | --- |
| 场景元素 | 河岸石阶、柳树影子、芦苇、小桥、晚霞云影 |
| 道具元素 | 扁石子、搪瓷杯、草帽、旧书包、手绘跳数牌 |
| 水面质感 | 使用明亮蓝绿和暖日光，不做暗脏河水 |
| 围观氛围 | 岸边可以有围观同学剪影和小旗，增强可围观氛围 |
| 反馈层级 | 跳点波纹、石子轨迹和加分数字必须比背景更清楚 |
| 主色建议 | 河水蓝绿、夏日浅黄、柳树绿、粉笔白形成对比 |
| 色彩边界 | 不做单一棕黄旧照片色调 |
| 反馈点缀 | 水面反馈可以使用亮白、浅青、橙黄点缀，保证电视端可读 |

## 14. 音频方向

| 分类 | 设计要求 |
| --- | --- |
| 环境声 | 夏日蝉声、轻风吹过柳树 |
| 操作音效 | 石子入手的轻碰声、水花连续弹跳声、手绘跳数牌翻动声 |
| 社交音效 | 同伴掌声和口哨 |
| 开场音乐 | 温暖轻快，带一点夏日户外感 |
| 游戏中音乐 | 保持轻鼓点或拨弦节奏，帮助玩家抓出手窗口 |
| 高跳数音乐 | 增加上扬音阶，突出“还在跳”的期待感 |
| 版权边界 | 所有音乐和音效必须原创或抽象化，不使用真实老歌、影视配乐或可识别 IP 声音 |

## 16. 数据与埋点

| 埋点 | 用途 |
| --- | --- |
| 进入准备页人数 | 判断主题入口吸引力 |
| 识别成功率 | 判断站位和动作识别是否顺畅 |
| 首局开始率 | 判断准备页到正式开局的转化 |
| 首局完成率 | 判断新用户是否能完成短局 |
| 平均出手次数 | 判断单局节奏是否足够 |
| 平均单颗跳数 | 判断基础成功体验 |
| 5 跳以上触发率 | 判断高光反馈是否足够出现 |
| 节奏命中率 | 判断水纹提示是否可理解 |
| 沉水率 | 判断难度和挫败感 |

| 儿童模式 / 标准模式选择比例 | 判断难度入口是否匹配家庭使用 |
| 大屏端与移动端完成率差异 | 判断端侧适配风险 |

| 成立判断 | 说明 |
| --- | --- |

### 17.2 P0 可不做

| 暂不做项 | 原因 |
| --- | --- |
| 多地图 | 首版先验证单一河岸场景 |
| 真实水面物理模拟 | 首版以可读跳点反馈为主 |
| 精确腕部旋转识别 | 2D 姿势识别不稳定 |
| 真实投掷距离计算 | 不依赖真实前后纵深 |
| 同时多人对抗 | 避免人体重叠和识别混乱 |
| 复杂排行榜 | 首版先验证单局完成和再来一局 |
| 照片合成 | 非核心玩法 |
| 石子养成或装备数值 | 避免把轻收集变成数值成长 |
| 高难度浪点系统 | 放到后续挑战内容 |

## 18. 风险与处理

| 风险 | 影响 | 处理 |
| --- | --- | --- |
| 玩家大幅甩臂导致空间风险 | 客厅安全问题 | 准备页提示挥臂范围，判定允许中等幅度，不奖励过大动作 |
| 玩家自然做成完全侧身 | 肩、肘、腕关键点被遮挡，识别不稳定 | 教学和站位框明确要求正面站立，用角色动画承担真实打水漂的侧身表现 |
| 精细腕部动作识别不稳定 | 成绩不可控 | 不识别手腕旋转，以挥臂时机、幅度和稳定度替代 |
| 石子跳数像随机 | 玩家不信服 | 出手节奏、水纹命中、稳定度三项反馈要明确可见 |
| 沉水过多造成挫败 | 用户不愿再玩 | 儿童模式提高第一跳成功率，沉水不扣分，只断连击 |
| 水面提示不清楚 | 用户不知道何时出手 | 水纹亮线、倒计时节拍和文案只聚焦一个动作 |
| 规则变成纯投掷打靶 | 童年记忆弱 | 强化跳点、水花、找扁石子和河岸围观，不做命中靶心为主 |

## 19. 验证标准

| 验证项 | 通过标准 |
| --- | --- |
| 新手理解 | 新用户不看说明也能在第一轮后做出挥臂投掷 |
| 姿势识别 | 玩家保持正面站立时，肩、肘、腕、髋关键点能稳定输出 |
| 站位纠偏 | 完全侧身或遮挡时，准备页能给出回到站位的提示 |
| 儿童模式 | 大多数玩家能让石子至少漂起 1-3 下 |
| 节奏理解 | 玩家能理解水纹亮起时出手会更好 |
| 围观反馈 | 高跳数反馈能让围观者看懂“这次很厉害” |
| 失败体验 | 沉水反馈轻松，不产生明显挫败 |
| 结算可读 | 结算页能让玩家明确看到最佳跳数、称号和再来一局入口 |
| 再玩意愿 | 单局后存在明显“再来一局，换颗石子试试”的意愿 |

## 20. 与产品主循环的关系

| 关系项 | 说明 |
| --- | --- |
| 所属主题 | 建议放在「童年户外 / 夏日河边」主题下 |
