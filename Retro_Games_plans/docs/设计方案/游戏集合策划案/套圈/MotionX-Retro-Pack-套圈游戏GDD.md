# MotionX Retro Pack / 套圈游戏 GDD

> 本文是 `MotionX Retro Pack / 时光体感馆` 中「套圈」玩法的单独 GDD。它把周末游园会、庙会小摊、奖券和小玩具奖品的记忆，改编成适合家庭客厅的短局体感游戏：核心动作是左右选目标、抬臂瞄准、短暂停稳、挥臂出圈；单局目标是让家庭用户在 60-90 秒内看懂“站在线后、看准三排奖品、把圈套出去”，并愿意再来一局。

## 游戏概述

「套圈」是一款以童年游园摊位为主题的短局体感玩法。玩家站在屏幕前的投掷线后，不需要真实塑料圈，只用空手动作模拟拿圈、瞄准和投掷，让画面中的彩色套圈飞向三排奖品目标。

游戏核心过程是“选目标、稳住、出圈”：玩家通过左右侧移选择目标列，用抬臂和短暂停顿完成瞄准，再用一次清晰挥臂触发出圈。系统根据目标选择、出手时机、挥臂速度、稳定度和目标排位，生成套中、擦边、落空和奖券反馈。

首发模式强调个人挑战和家庭围观，目标是在 60-90 秒内用有限数量的圈尽量套中更多奖品。三排目标形成距离层次：近排大目标低分，中排标准目标中分，远排小目标高分或奖励卡。失败不做惩罚，落空只断连击或换下一个圈。

整体体验要轻松、明亮、可围观：玩家不用真的向前投掷，也不用理解复杂物理；画面重点放在三排奖品、当前目标光圈、彩色圈飞行、奖券弹出和摊位欢呼上，让玩家自然产生“再套一次”的短循环。

## 2. 设计目标

| 目标 | 设计要求 |
| --- | --- |
| 5 秒内看懂 | 看见投掷线、彩色圈、三排奖品，知道要把圈套过去 |
| 30 秒内学会 | 左右挪选目标，手臂停一下瞄准，提示亮起时挥臂出圈 |
| 失败可接受 | 没套中不扣生命，只断连击并给轻松反馈 |
| 动作原语收敛 | 只使用左右侧移、抬臂瞄准、短暂停稳、挥臂投掷，不做真实落点和手指抓握 |
| 2D 姿势识别优先 | 所有核心动作必须能由肩、肘、腕、髋等屏幕平面关键点稳定判断 |
| 远距离可读 | 三排目标、当前目标、剩余圈数、力度条、奖券反馈必须 3 米外清楚 |
| 风格边界 | 怀旧来自奖券、粉笔线、搪瓷杯、贴纸、小玩具，不靠脏旧滤镜 |

## 4. 核心玩法概述

| 核心环节 | 规格 |
| --- | --- |
| 玩家位置 | 站在投掷线后，正面朝向摄像头 |
| 目标结构 | 奖品按近 / 中 / 远三排摆放，每排 3 个目标 |
| 玩家选目标 | 左右侧移选择目标列，也可由当前高亮目标自动轮换 |
| 玩家瞄准 | 抬起投掷手并保持 0.3-0.6 秒，锁定目标 |
| 玩家出圈 | 在提示窗口内做一次向前挥臂 |
| 判定输入 | 身体所在列、手腕高度、手腕速度峰值、挥臂幅度、稳定度、提示窗口匹配度 |
| 结果表现 | 圈飞出、落到目标区域、套中 / 擦边 / 落空、奖券弹出 |

核心循环：

```text
目标预告
→ 左右选列
→ 抬臂瞄准
→ 稳住等待亮圈
→ 挥臂出圈
→ 套中 / 擦边 / 落空反馈
→ 奖券与连击结算
→ 下一只圈
```

### 4.1 三排场地关系

```text
+----------------------------------------------------------------------------+
|  远排：高分小目标          [大奖]       [稀有贴纸]      [灯笼奖]            |
|                                                                            |
|  中排：标准目标            [风车]       [搪瓷杯]        [小奖章]            |
|                                                                            |
|  近排：低分大目标          [纸盒]       [布玩偶]        [票券盒]            |
|----------------------------------------------------------------------------|
|  粉笔投掷线                         ← 玩家站位 / 左右选列 →                |
+----------------------------------------------------------------------------+
```

| 场地规则 | 说明 |
| --- | --- |
| 三排关系 | 近排目标大、容错高、分低；中排标准；远排目标小、分高、奖励强 |
| 判定边界 | 不要求真实投掷距离，目标远近由游戏内映射决定 |
| 站位 | 玩家始终在线后，不鼓励真实向前迈步 |
| 目标数量 | 首发建议 3 列 x 3 排，避免目标过密 |
| 镜头 | 横版 16:9，三排奖品要有清楚纵深，不贴脸摆放 |
| 结果反馈 | 套圈飞行动画和目标光圈负责表达成绩，不要求真实抛物线模拟 |

## 5. 单局流程

```text
回忆开场 10-15 秒
→ 入戏式识别 5-10 秒
→ 游园摊位站位确认
→ 基础教学 10 秒内
→ 游戏中 60-90 秒
→ 结算界面 10-20 秒
→ 奖励卡片 / 再来一局
```

### 5.1 回忆开场

| 项目 | 内容 |
| --- | --- |
| 画面起点 | 游园摊位灯亮起，桌布铺开，三排奖品摆上台面 |
| 摊位物件 | 彩色塑料圈、奖券、搪瓷杯、纸风车、小奖章、粉笔投掷线 |
| 入戏动作 | 一只彩色圈滚到玩家面前的投掷线 |
| 可用短句 1 | “小摊开张，轮到你出手。” |
| 可用短句 2 | “站到线后，看准想要的那个。” |
| 可用短句 3 | “第一只圈来了，稳一下再套。” |
| 文案边界 | 避免使用“怀旧”“复古”“八零九零”等直白年代词 |

### 5.2 入戏式识别

| 项目 | 内容 |
| --- | --- |
| 包装方式 | 识别阶段包装成游园摊位站位，不使用“校准”“骨骼识别”等技术词 |
| 推荐话术 1 | “站到粉笔线后。” |
| 推荐话术 2 | “举起你的圈。” |
| 推荐话术 3 | “左右挪一步，选你想套的那一列。” |
| 推荐话术 4 | “目标亮起时，轻轻把圈送出去。” |
| 确认条件 1 | 玩家身体中心在站位框内 |
| 确认条件 2 | 头、肩、肘、腕、髋关键点可稳定识别 |
| 确认条件 3 | 左右侧移和挥臂空间足够 |
| 确认条件 4 | 玩家没有拿真实硬物或大幅遮挡身体 |
| 确认条件 5 | 多人轮流模式下，当前玩家有明确颜色区 |

## 6. 操作与动作判定

| 动作 | 玩家行为 | 游戏含义 | 2D 姿势识别判定原则 |
| --- | --- | --- | --- |
| 左右侧移 | 身体中心进入左 / 中 / 右区域 | 选择目标列 | 粗粒度区域判断，不追求精确厘米级位移 |
| 抬臂瞄准 | 投掷手抬到胸口至肩部高度 | 进入瞄准状态 | 判断腕点高度、肘腕可见、手臂停留 |
| 短暂停稳 | 手臂和身体中心短时间稳定 | 提高命中稳定度 | 0.3-0.6 秒宽容窗口，只做加分或命中修正 |
| 挥臂出圈 | 手腕向前 / 斜前快速挥出 | 投掷套圈 | 以速度峰值、位移幅度、提示窗口匹配为主 |
| 轻下蹲蓄力 | 可选轻微下蹲后起身 | 增加强度感和游玩表现 | 只做加分项，不作为必需动作 |
| 回到站位 | 出圈后身体中心回到安全框 | 进入下一只圈 | 给 1-2 秒缓冲，避免连续误判 |

动作设计边界：

| 边界项 | 设计要求 |
| --- | --- |
| 手部细节 | 不做真实手腕旋转、手指抓圈、手掌朝向识别 |
| 真实空间 | 不做真实投掷距离、真实地面落点或前后纵深移动 |
| 动作幅度 | 不鼓励大甩臂，避免儿童和客厅空间风险 |
| 身体朝向 | 不要求侧身或转体，角色动画可以承担真实套圈的出手表现 |
| 遮挡动作 | 不把手臂从身体背后甩出、手穿过躯干前方造成遮挡、双手交叉等姿势作为核心动作 |
| 移动端 | 可降低挥臂幅度，重点保留选目标、瞄准、出圈反馈 |

## 7. 目标与奖品类型

| 类型 | 排位 | 表现 | 玩家应对 | 作用 |
| --- | --- | --- | --- | --- |
| 大纸盒 | 近排 | 大目标，边缘宽 | 正常出圈 | 新手建立信心 |
| 布玩偶 | 近排 | 轻轻晃动 | 等回正或稳住出手 | 低压变化 |
| 票券盒 | 近排 | 命中弹出小奖券 | 保持连击 | 奖励反馈 |
| 搪瓷杯 | 中排 | 标准圆口目标 | 瞄准后出圈 | 核心命中训练 |
| 纸风车 | 中排 | 慢速转动 | 把握提示窗口 | 引入时机 |
| 小奖章 | 中排 | 小光圈目标 | 稳定手臂 | 精准目标 |
| 稀有贴纸 | 远排 | 限时发光 | 抓住高光窗口 | 高分挑战 |
| 灯笼奖 | 远排 | 活动目标 | 节日活动使用 | 运营扩展 |
| 大奖盒 | 远排 | 小目标，高分 | 连击后开放 | 高光奖励 |

首发版本只需要大纸盒、布玩偶、搪瓷杯、纸风车、小奖章、稀有贴纸六类。活动目标和大奖盒可作为 P1/P2 扩展。

## 8. 规则与评分

### 8.1 基础规则

| 规则项 | 说明 |
| --- | --- |
| 单局目标 | 用有限套圈数或限定时间套中尽可能多目标 |
| 圈数 | 首发 6 个圈；儿童模式 8 个圈 |
| 命中等级 | 套中、擦边、落空三档 |
| 连击 | 连续套中增加奖券倍率 |
| 失败处理 | 落空不扣分，只断连击 |
| 远排奖励 | 远排命中给高分或奖励卡碎片 |
| 结算依据 | 总分、套中数、远排命中、最高连击、剩余圈数 |

### 8.2 评分建议

| 行为 | 分数 |
| --- | ---: |
| 近排套中 | +20 |
| 中排套中 | +40 |
| 远排套中 | +80 |
| 擦边 | +10，不计连击 |
| 稳定瞄准后命中 | +10 |
| 连续 3 次套中 | +50 |
| 限时大奖命中 | +100 |
| 落空 | 0，断连击 |

| 评分原则 | 说明 |
| --- | --- |
| 鼓励方向 | 鼓励“看准、稳住、套中”，而不是鼓励用力过猛 |
| 失败处理 | 不做负分惩罚，避免儿童把投掷动作和挫败绑定 |
| 远排权重 | 远排是高光，但不能让新手只盯远排导致频繁落空 |

### 8.3 评级

| 评级 | 条件示例 |
| --- | --- |
| S | 总分高，至少 1 次远排命中，连击稳定 |
| A | 完成整局，多数圈套中，有 1 次中排或远排高光 |
| B | 完成整局，近排命中稳定 |
| C | 能完成基础出圈，但命中不稳定 |

评级文案保持鼓励，不使用“手太差”“投歪了”等挫败表达。

## 9. 难度曲线

### 9.1 单局节奏

| 阶段 | 时间 | 内容 |
| --- | ---: | --- |
| 新手段 | 0-20 秒 | 近排 / 中排静态目标，提示窗口宽 |
| 变化段 | 20-50 秒 | 加入旋转风车、轻摆奖品、目标轮换 |
| 高潮段 | 50-90 秒 | 远排大奖亮起，提示窗口缩短，奖券倍率提升 |

### 9.2 难度参数

| 参数 | 低难度 | 中难度 | 高难度 |
| --- | --- | --- | --- |
| 目标排位 | 近排为主 | 近 / 中 / 远混合 | 远排比例提高 |
| 瞄准窗口 | 0.8-1.2 秒 | 0.5-0.8 秒 | 0.4-0.6 秒 |
| 目标运动 | 静态 | 轻微摆动 | 小幅移动 / 轮换 |
| 命中区 | 大 | 标准 | 略小 |
| 圈数 | 8 | 6 | 6 |
| 落空惩罚 | 只断连击 | 断连击 | 断连击，不建议扣分 |

儿童模式默认低难度，家庭挑战默认中难度。高难度只用于排行榜或活动挑战，不作为首次体验。

| 项目 | 内容 |

### 10.4 P2 模式：节日大奖摊

## 12. 反馈设计

| 事件 | 反馈 |
| --- | --- |
| 瞄准成功 | 目标光圈轻亮，圈边出现小星星 |
| 出圈 | 彩色圈带轻拖尾飞出 |
| 套中 | 奖品跳一下，奖券飞出，摊位铃响 |
| 擦边 | 圈弹一下，提示“差一点”的方向 |
| 落空 | 圈滚到桌边，轻松音效，不做失败压迫 |
| 连击 | 奖券倍率牌翻动，围观小旗晃动 |
| 远排命中 | 短慢动作 + 大奖灯亮 |
| 最后一圈 | 摊位灯光聚焦，鼓点轻微加速 |

## 13. 美术方向

| 项目 | 要求 |
| --- | --- |
| 画面基调 | 明亮、干净、暖日光、clean-film，不做暗旧庙会 |
| 主场景 | 游园摊位 + 三排奖品台 + 粉笔投掷线 |
| 怀旧锚点 | 奖券、搪瓷杯、贴纸、纸风车、塑料圈、广播喇叭 |
| UI 风格 | 大块高对比 HUD，圆角、软阴影、远距离可读 |
| 奖品风格 | 原创、玩具化、轻 3D 空间感，不出现真实商品包装 |
| 构图要求 | 横版 16:9 主舞台，三排目标有纵深，目标不能贴得太近 |
| 版权边界 | 奖品全部原创，不出现真实 IP、商标、影视角色或真实商品包装 |

## 14. 音频方向

| 类型 | 设计 |
| --- | --- |
| 入戏 | 摊位铃铛、远处广播、人群轻欢呼 |
| 瞄准 | 轻微“叮”声或光圈蓄力声 |
| 出圈 | 塑料圈划过空气的轻快音 |
| 套中 | 奖券哗啦 + 小铃铛 |
| 擦边 | 轻弹声，不刺耳 |
| 落空 | 圈滚动声 + 轻松短音 |
| 连击 | 奖券倍率翻牌声 |
| 结算 | 温暖短旋律，像游园小奖品到手 |

音频边界：

| 边界项 | 要求 |
| --- | --- |
| 原创安全 | 不使用真实庙会音乐、真实老歌或可识别节目音效 |
| 频率控制 | 出圈和命中音效短促，不盖过家庭说话声 |
| 儿童友好 | 落空音效不能刺耳或像惩罚 |

## 17. MVP 范围

### 17.1 P0 必须有

| 模块 | 要求 |
| --- | --- |
| 场地 | 三排目标、粉笔投掷线、玩家站位区 |
| 动作 | 左右选列、抬臂瞄准、挥臂出圈 |
| 目标 | 至少 6 类原创奖品 |
| 规则 | 6-8 个圈、套中 / 擦边 / 落空、近 / 中 / 远排分数 |
| HUD | 时间、剩余圈数、分数、连击、奖券、稳定条 |
| 反馈 | 出圈、套中、擦边、落空、远排高光 |
| 结算 | 分数、套中数、最佳一圈、称号、回忆标签 |

### 17.2 P0 可不做

| 模块 | 原因 |
| --- | --- |
| 真实抛物线物理 | 首版用表现动画和命中区即可验证体验 |
| 复杂力度模拟 | 容易导致动作挫败，首版只做三档稳定 / 力度反馈 |
| 多人同时出圈 | 遮挡和反馈复杂，先做轮流 |
| 活动换皮 | P1/P2 再接运营活动 |
| 实时合影 | 属于独立图像管线 |
| 精细手势 | 2D 单目不稳定，不作为核心判定 |

### 17.3 P1 / P2 再做

| 阶段 | 内容 |
| --- | --- |
| P1 | 亲子轮流赛、奖券挑战日、更多奖品类型、奖励卡收集 |
| P2 | 节日大奖摊、主题活动路线、合影分享、更多家庭围观反馈 |

## 18. 风险与处理

| 风险 | 处理 |
| --- | --- |
| 玩家以为要真实向前投 | 文案和站位明确“站在线后”，命中由屏幕内目标映射 |
| 三排目标太近、没距离感 | 画面拉远，三排分层，远排目标更小且带高分标识 |
| 动作像投篮机换皮 | 取消篮筐逻辑，强化奖品台、奖券、三排目标和有限圈数 |
| 精准投掷不稳定 | 只做宽容命中区，不追求真实落点 |
| 画面太杂 | 每轮只高亮 1 个主目标，怀旧物件放边角 |
| 儿童频繁落空 | 儿童模式增加近排目标和圈数，降低远排引导 |
| 家长觉得太幼稚 | 加入远排高分、连击和亲子轮流挑战，保留成人刷分动机 |
| 版权风险 | 奖品全部原创，不使用真实商品、品牌、影视角色或动画角色 |

## 19. 验证标准

| 检查项 | 通过标准 |
| --- | --- |
| 5 秒内知道玩法 | 用户能说出“站在线后把圈套向奖品” |
| 30 秒内完成首圈 | 用户能完成选目标、瞄准、出圈 |
| 三排距离感成立 | 近 / 中 / 远排在画面和分数上都能区分 |
| 儿童不挫败 | 落空后仍愿意继续下一圈 |
| 家庭围观可读 | 旁观者能看懂套中、擦边、远排大奖 |
| 动作安全 | 玩家不需要真实道具，不需要大幅甩臂或向前冲 |
| 风格统一 | 明亮、干净、原创，不像暗旧手游截图或真实庙会照片 |
| 奖励动机 | 奖券和奖励卡能解释为什么想再玩一局 |

## 20. 与产品主循环的关系

套圈适合作为 `周末游园包 / 节日游园会` 的代表玩法，不建议挤进首批 MVP 三样板，但很适合做 P1/P2 活动内容。它和丢沙包、打水漂共享“挥臂投掷 + 命中反馈”的动作资产，同时用三排奖品、有限圈数和奖励卡片形成自己的差异化记忆点。

| 关系项 | 说明 |
| --- | --- |
| 与丢沙包 | 共享挥臂反击和命中反馈经验，但套圈没有躲避压力 |
| 与打水漂 | 共享投掷动作和结果演出，但套圈目标更清楚、奖励更直接 |
| 与客厅街机投篮机 | 都有投掷爽感，但套圈属于游园摊位，不做篮筐、高分灯牌和街机刷分包装 |
| 与奖励系统 | 奖券、贴纸、称号卡天然适合接奖励卡片和周末活动 |
| 与云端编排 | 可挂在“周末·节日游园”路线中，作为轻奖励短局 |
