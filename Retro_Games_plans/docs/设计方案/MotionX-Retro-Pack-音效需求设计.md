# MotionX Retro Pack / 音效需求设计

> 音效是 `时光派对 / MotionX Retro Pack` 拉起回忆情绪的关键手段。它不只是按钮反馈，而是把用户从普通菜单带回到课间、街机、电视节目和家庭游戏现场的第一触发点。

## 1. 核心目标

| 目标 | 定义 |
| --- | --- |
| 拉回回忆 | 用熟悉但原创的声音锚点，让家长立刻感到“这个场景我见过” |
| 建立场景 | 在画面还没完全展开前，先让用户听出操场、街机或电视节目 |
| 帮助动作 | 用节拍、倒计时和反馈音帮助用户知道什么时候动、停、命中或失败 |
| 服务亲子 | 声音轻松、明亮、不刺耳，失败也不制造羞辱感 |
| 版权安全 | 所有音乐、旋律、音效均原创或抽象化，不使用真实老歌、影视音乐、真实街机音源或可识别 IP 音效 |

一句话：

> 音效要像小时候场景里的声音被重新做了一遍，而不是直接复刻当年的声音。

## 2. 音效分层

| 层级 | 触发位置 | 作用 | 时长 |
| --- | --- | --- | --- |
| 产品启动音 | 启动 / 登录前后 | 轻量品牌识别，不拖慢进入 | 0.5-1.5 秒 |
| 主题入场音 | 点击主题馆后 | 建立主题氛围 | 2-4 秒 |
| 单游戏入戏音 | 选择具体游戏后 | 帮用户进入这一局的身份和动作理由 | 10-20 秒内分段出现 |
| 识别 / 准备音 | 站位、就绪、倒计时 | 降低等待感，告诉用户快开始了 | 3-8 秒 |
| 游戏中反馈音 | 成功、失败、连击、暂停、时间变化 | 强化身体动作反馈 | 0.1-1 秒 |
| 结算 / 奖励音 | 结果页、奖励卡、收藏 | 形成完成感和家庭话题 | 1-4 秒 |

## 3. 全局音频风格

| 项目 | 要求 |
| --- | --- |
| 情绪 | 明亮、亲切、热闹、轻松、有家庭感 |
| 质感 | 轻复古、抽象化生活音、玩具感、广播感、节目感 |
| 节奏 | 短、清楚、可重复听，不拖慢操作 |
| 响度 | 大屏 / 手机都清楚，但不刺耳；儿童和家长都能接受 |
| 混音 | 关键提示音优先级高于背景氛围；倒计时、成功、失败必须清楚 |
| 避免 | 真实老歌、真实影视音乐、可识别街机采样、过重 VHS 噪声、恐怖音效、刺耳警报、长旁白 |

## 4. 音频总线与混音规则

| Bus | 内容 | 音量优先级 | 规则 |
| --- | --- | ---: | --- |
| `BGM` | 主题背景音乐、节目节拍底 | 2 | 不能压过口令、倒计时和动作反馈 |
| `AMB` | 操场环境、客厅房间声、街机厅底噪 | 1 | 只做空间感，默认低音量，可循环 |
| `UI` | 按钮、返回、选择、卡片翻页 | 4 | 高频触发也不能刺耳 |
| `SFX` | 成功、失败、命中、红绿灯、投币、贴纸 | 5 | 游戏核心反馈优先 |
| `VOICE` | 广播、老师、机器、节目口令 | 6 | 口令出现时自动压低 `BGM` / `AMB` |
| `COUNTDOWN` | 3、2、1、开始 | 7 | 倒计时期间最高优先级，不被其他反馈盖住 |

混音规则：

| 场景 | 规则 |
| --- | --- |
| 主题入场 | `AMB` 先起，`SFX` 做记忆钩子，最后用短 `VOICE` 或 UI 音落到主题主页 |
| 入戏准备 | `VOICE` 和 `COUNTDOWN` 优先；背景只保留轻环境 |
| 游戏中 | 动作反馈 `SFX` 不超过 0.8 秒，避免遮挡下一次动作 |
| 连击 | 同类反馈需要做音高或层级变化，但最多 3 层，避免堆叠成噪声 |
| 失败 | 失败音比成功音短 20%-40%，音色更轻，不做负面惩罚 |
| 结算 | 先播结果确认，再播奖励/称号音；不能同时全部响起 |

## 5. 页面级触发需求

| 页面 / 状态 | 触发点 | 音效内容 | 目标 |
| --- | --- | --- | --- |
| 健康游戏忠告过渡页 | 页面出现 | 极轻品牌提示音，可无 | 不制造等待负担 |
| 登录页面 | 主卡出现 | 贴纸册翻动、粉笔轻碰、短品牌音 | 让登录页不像普通账号表单 |
| 首页（记忆桌面目录版） | 主题切换 | 纸片滑动、物件轻响、目录选中 | 强化“翻到一段回忆” |
| 首页 | 点击进入主题 | 当前主题专属确认音 | 进入主题前先给情绪钩子 |
| 主题入场 | 2-4 秒过渡 | 主题环境 + 主题标志音 | 建立操场/街机/电视场景 |
| 主题主页 | 切换玩法 | 木牌/灯牌/节目单切换音 | 不像普通菜单 |
| 准备页 | 玩家就绪 | 单个玩家就绪确认音 | 降低等待焦虑 |
| 准备页 | 全员就绪 | 集合完成音 + 倒计时起音 | 推动开始 |
| 游戏中 | 成功动作 | 短成功反馈 | 让身体动作有结果 |
| 游戏中 | 失败 / 误动 | 温和提醒音 | 提示修正，不羞辱 |
| 游戏中 | 时间临近 | 轻倒计时加速 | 形成短局紧张感 |
| 结算页 | 分数出现 | 结果确认音 | 用户知道这一局结束 |
| 奖励卡片 | 奖励出现 | 贴纸/徽章/收藏音 | 形成“收下了”的记忆 |

## 8. 游戏反馈规则

| 事件 | 音效方向 | 禁止方向 |
| --- | --- | --- |
| 成功 | 上扬、清楚、短促，有“做到了”的感觉 | 过长胜利音乐 |
| 失败 | 轻松、短、可继续，不羞辱 | 嘲笑、尖锐报警、沉重失败音 |
| 连击 | 逐步增强，但不盖过节拍 | 高频噪声堆叠 |
| 倒计时 | 节拍明确，最后一秒最清楚 | 模糊环境音、听不出开始点 |
| 站位就绪 | 温和确认，像“轮到你了” | 技术检测音 |
| 奖励获得 | 纸张、贴纸、徽章、掌声 | 抽卡、赌博、付费感音效 |

## 9. 动态播放规则

| 机制 | 要求 |
| --- | --- |
| 随机变体 | 高频音效必须有 3 个以上变体，避免机械重复 |
| 音高微调 | UI 和脚步可做 ±3% pitch variation；口令和关键倒计时不做随机变调 |
| 同类限频 | 失败提醒、选择音、分数 tick 必须限频 |
| Ducking | `VOICE` / `COUNTDOWN` 出现时，`BGM` 和 `AMB` 降低 4-8 dB |
| Fade | 主题环境循环进入游戏时 0.3-0.8 秒淡出 |
| Pause | 暂停时保留低环境音或静音，不继续播放紧张倒计时 |
| Resume | 继续游戏时播放短提示，不重播完整入戏音 |

## 10. 语音与口令需求

首版可以使用短口令，但不依赖长旁白。

| 场景 | 口令方向 | 示例 |
| --- | --- | --- |
| 童年操场 | 广播 / 老师 / 同学招呼 | `下课了，站到队伍里`、`老师看过来了，别动` |
| 客厅街机 | 机器提示 / 围观喊声 | `投币成功`、`挑战启动`、`看看谁能上榜` |
| 家庭电视健身 | 节目主持 / 家庭口令 | `站到电视前`、`跟上节拍`、`全家一起` |

口令边界：

- 单句 2-6 个字优先，最长不超过 10 个字。
- 不说 `校准`、`骨骼识别`、`算法检测`。
- 不模仿真实主持人、影视台词、经典节目口号。
- 儿童失败时不用嘲讽口吻。

## 11. 交付规格

| 项目 | 要求 |
| --- | --- |
| 文件格式 | `wav` 作为母版，游戏内可转 `ogg` / `mp3` |
| 采样率 | 48kHz |
| 位深 | 24-bit 母版，运行包按平台压缩 |
| 声道 | UI / SFX 可 mono 或 stereo；环境和音乐建议 stereo |
| 命名 | `sfx_主题_事件_版本`，例如 `sfx_pg_bell_short_v01.wav` |
| 循环 | 循环音必须提供 seamless loop 版本 |
| 响度 | 同类音效响度统一；警示音不得明显刺耳 |
| 版本 | 每个关键音效至少提供 2-3 个候选版本 |

| `volume` | `0.85` | 默认音量 |
| `pitch_random` | `0.03` | 随机音高范围 |
| `cooldown_ms` | `300` | 同类限频 |
| `ducking` | `BGM:-6dB` | 是否压低其他总线 |

## 13. 验收标准

| 验收项 | 通过标准 |
| --- | --- |
| 场景识别 | 只听前 2 秒，能区分操场、街机、电视健身 |
