## 2. 文档侧保留口径

| 口径项 | 当前结论 |
| --- | --- |
| 风格主次 | 主题体验为主，轻怀旧元素为辅 |
| 推荐比例 | 主题体验约 70%，怀旧元素约 30% |
| 通用画风 | 2D 手绘插画为主，带轻 3D / 2.5D 空间感，UI 保持现代清晰 |
| 首页和主题入口 | 走大主题舞台，不做经营地图主风格 |
| 游戏中 HUD | 倒计时、分数、目标、站位、动作反馈优先，怀旧细节退到边缘 |
| 结算与奖励卡 | 先保证结果清楚，再用贴纸、奖章、票根、节目封面感做轻收藏 |

## 3. 设计红线

1. 不做纯 80/90 怀旧滤镜、旧照片 UI、VHS 噪点或脏旧破损表达。
2. 不做经营游戏式大地图、货币、等级、红点和建筑养成入口。
3. 不做重 3D 玩具广告感、夜店霓虹街机厅或低幼教育 App 感。
4. 不使用真实老歌、真实影视、真实街机 / 游戏 IP、明星教练或可识别影视引用。
5. 不让怀旧物件替代动作理由；每个页面和游戏仍必须说清场景、身份、动作理由、反馈和结算记忆。
