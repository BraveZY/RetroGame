# 复古元素清单：按市场划分

> 本文是 `MotionX Retro Pack / 复古体感包` 的复古元素引用清单。主方案见 [MotionX-Retro-Pack-产品定义.md](./项目管理计划/MotionX-Retro-Pack-产品定义.md)，区域依据见 [区域怀旧设计依据_美术音乐玩法.md](./区域怀旧设计依据_美术音乐玩法.md)。本文只回答一个问题：当前我们说的“复古元素”具体指哪些可被美术、音乐、玩法、UI 和营销引用的东西。当前制作优先查中国大陆部分，海外市场内容仅作为后续资料池。

## 0. 使用原则

- 复古元素是情绪锚点，不等于直接复刻真实 IP。
- 当前阶段先做国内市场；海外市场元素只保留为资料池，不进入 MVP、首发宣传素材和运营活动。
- 底层动作和判定尽量保持后续可复用，但当前皮肤、音乐、文案、首页排序和主题包装优先服务国内用户。
- 能做成游戏入口的元素，必须能落到 1-3 分钟短局和 2D 稳定动作原语。
- 不能直接使用真实老歌、真实影视音乐、明星/演员形象、真实街机/动画/游戏角色和受版权保护的造型。

## 1. 中国大陆

### 核心年代

- 1990s 为主。
- 80 年代末为辅。
- 面向今天 30-45 岁父母的童年/青春记忆。

### 情绪底色

- 暖的。
- 户外的。
- 集体的。
- 人挤人的。
- 清贫但热闹。
- 放学后、课间十分钟、老电视、街道叫卖。

### 场景元素

| 类型 | 元素 |
| --- | --- |
| 学校/操场 | 水泥操场、粉笔格子、红砖教学楼、绿皮黑板、老式吊扇、课间铃、操场广播 |
| 放学/街道 | 夕阳、校门口、小卖部、推车叫卖、一毛钱冰棍、街边空地 |
| 家庭/电视 | 老电视开机、客厅、复读机、MP3、电子宠物、小霸王学习机氛围 |
| 节日/游园 | 庙会、春节家庭运动会、套圈摊、投掷摊、灯笼、奖票 |
| 神话童年 | 水帘洞、火焰山、蟠桃园、筋斗云、妖怪关卡、盘丝洞 |

### 玩法元素

| 元素 | 体感化方向 |
| --- | --- |
| 木头人 / 红绿灯 / 三个字 | 跑停、静止判定、多人同屏 |
| 跳房子 | 屏幕格子飘 + 时序跳，不做真实踩格子 |
| 扔沙包 / 丢沙包 | 左右躲闪、伸手挡、轮流攻防 |
| 踢毽子 | 抬膝计数、左右脚节奏 |
| 跳皮筋 | 节奏跳跃、左右移动，第二批以后评估 |
| 滚铁环 | 原地跑停、节奏推进、上学路热身 |
| 套圈 / 投掷摊 | 摆臂、伸手到屏幕区域 |
| 广播体操 | 摆臂、抬膝、蹲起、亲子跟做 |
| 西游火焰山 | 大幅摆臂扇风、躲火球 |
| 西游蟠桃园 | 伸手摘桃、限时得分 |
| 西游筋斗云 | 左右闪避、跳跃、下蹲 |
| 西游盘丝洞 | 左右躲蛛网、挥手拍蛛丝 |

### 美术元素

- 暖黄、橙红、泛黄滤镜。
- 水泥灰、粉笔白、红砖色。
- 老照片感，但不要脏和灰。
- 大色块、远距离可读 UI。
- 童年神话主题可用原创国风、庙会、云纹、火焰、山洞、水帘等符号。

### 音乐元素

- 童谣感。
- 口风琴、手风琴、木琴。
- 广播体操节拍感。
- 锣鼓、民乐打击、庙会节奏。
- 西游主题可以借鉴神话/庙会/童年动画感，但必须原创，不使用或模仿 86 版电视剧音乐、唱腔、台词和音效。

### 不要使用

- 真实广播体操音乐。
- 真实动画和电视剧角色。
- 86 版西游电视剧音乐、演员形象、服装造型、台词口吻和镜头设计。
- 真实小霸王、马里奥、魂斗罗、数码宝贝等 IP 名称和角色。

## 2. 北美 / 欧洲

### 核心年代

- 1980s 为主。
- 90 年代初为辅。
- 面向街机黄金期、VHS 健身录像带、家庭电视娱乐记忆。

### 情绪底色

- 酷的。
- 亮的。
- 室内的。
- 竞技的。
- 霓虹、科技感、排行榜、投币挑战。

### 场景元素

| 类型 | 元素 |
| --- | --- |
| 街机厅 | 街机柜、投币口、代币、发光按钮、摇杆、排行榜、花纹地毯 |
| 电视/屏幕 | CRT 弧面屏、扫描线、VHS 录像带、磁带标签、电视雪花 |
| 健身录像 | 演播室背景、运动发带、护腕、亮色健身服、几何图案 |
| 派对/家庭 | 客厅地毯、家庭电影夜、朋友围观、短局挑战 |

### 玩法元素

| 元素 | 体感化方向 |
| --- | --- |
| 投篮机 | 伸手区域 + 摆臂，限时高分 |
| 拳击机 | 出拳、连击、力量感反馈 |
| 反应灯 | 看到哪里亮就拍哪里 |
| 打地鼠 | 伸手到屏幕区域、反应速度 |
| 街机闪避跑 | 左右躲、跳、蹲 |
| 体感打砖块 / 太空闪避 | 身体左右移动控制挡板或飞船 |
| 80s 健美操 | 踏步、抬膝、摆臂、拍手 |
| 90s 拳击操 | 出拳、摆臂、踏步、节奏连击 |

### 美术元素

- 暗底 + 荧光粉、青、绿。
- Neon、arcade、CRT、VHS、synthwave。
- 像素可点缀，但不能做成低成本像素皮。
- 高对比、粗线条、大计分牌。

### 音乐元素

- Chiptune / 8-bit。
- Synthwave。
- 80s synth-pop。
- Disco-funk。
- 投币、得分、连击、倒计时等原创街机音效。

### 不要使用

- 真实街机游戏 IP 名称和角色。
- 真实 80/90 年代歌曲、采样、名曲旋律。
- 真实明星教练形象。
- 直接复刻知名 VHS 健身课程编排、口令和镜头。

## 3. 日本

### 核心年代

- 80-90s。
- 昭和末到平成初。
- 面向放课后校庭、运动会、家庭电视游戏记忆。

### 情绪底色

- 温暖。
- 校园秩序。
- 运动会热血。
- 分队、应援、仪式感。

### 场景元素

| 类型 | 元素 |
| --- | --- |
| 学校 | 放课后校庭、校门、樱花/银杏路、教室走廊 |
| 运动会 | 赤白帽、应援团、分队旗、玉入れ、接力 |
| 家庭/街边 | 卓袱台、家庭电视游戏氛围、駄菓子屋 |

### 玩法元素

| 元素 | 体感化方向 |
| --- | --- |
| 校园运动会热身 | 摆臂、抬膝、蹲起 |
| 接力 / 分队挑战 | 轮流上场、同屏竞速 |
| 玉入れ投球 | 摆臂、伸手区域 |
| 木头人 | 跑停、静止 |
| 应援节奏 | 拍手、举手、同步感三档 |

### 美术元素

- 昭和/平成初暖调。
- 校园干净秩序感。
- 赤白对抗色。
- 运动会旗帜、手绘应援牌。

### 音乐元素

- 运动会进行曲感。
- 应援节奏。
- 昭和歌谣感点缀。
- 原创校园热血短循环。

### 不要使用

- 真实动漫角色。
- 真实游戏主机品牌和角色。
- 真实歌曲和学校运动会曲目。

## 4. 韩国

### 核心年代

- 1990s。
- 电子游戏厅、学校运动会、户外童年游戏。

### 情绪底色

- 学校。
- 街边电子游戏厅。
- 户外儿童游戏。
- 与中国童年运动会高度同构。

### 场景元素

| 类型 | 元素 |
| --- | --- |
| 电子游戏厅 | 오락실、街边小型游戏厅、短局挑战 |
| 学校 | 运动会、操场、分队 |
| 户外游戏 | 跳橡皮筋、抛石子、丢沙包变体 |

### 玩法元素

| 元素 | 体感化方向 |
| --- | --- |
| 跳橡皮筋 | 节奏跳跃、左右移动 |
| 抛石子类 | 伸手区域、反应判断 |
| 丢沙包变体 | 左右躲闪、轮流攻防 |
| 电子游戏厅挑战 | 拳击机、反应灯、排行榜 |

### 美术和音乐元素

- 可复用中国童年运动会底层，但换韩文字体、学校/街机厅皮肤和本地化音效。
- 音乐可偏 90s 电子厅、校园运动会、轻快家庭派对。

### 不要使用

- 真实韩流歌曲或艺人形象。
- 真实动画、游戏、街机 IP。

## 5. 东南亚 / 拉美

### 核心年代

- 不强压具体年代。
- 比“怀旧年代”更重要的是家庭派对、户外童年、多人热闹。

### 情绪底色

- 热闹。
- 低门槛。
- 家庭派对。
- 户外游戏。
- 多人轮流。

### 场景元素

| 类型 | 元素 |
| --- | --- |
| 家庭派对 | 客厅、院子、亲友围观、节日装饰 |
| 户外童年 | 空地、学校、社区活动 |
| 嘉年华 | carnival、游园、投掷摊、奖票、灯串 |

### 玩法元素

| 元素 | 体感化方向 |
| --- | --- |
| 木头人类规则 | 跑停、静止，换本地名称 |
| 丢手绢类规则 | 轮流上场、追逐、反应 |
| 投掷摊 | 摆臂、伸手区域、限时得分 |
| 套圈 | 伸手区域、摆臂 |
| 街机挑战 | 投篮机、拳击机、反应灯 |
| 家庭接力 | 轮流完成动作、分队对抗 |

### 美术元素

- 明亮、热闹、户外。
- 节日灯串、摊位、奖票、家庭聚会。
- 可以比中国更派对化，比欧美少一点冷霓虹科技感。

### 音乐元素

- 家庭派对节奏。
- 打击乐。
- 简单重复、容易跟动的短循环。
- 地区版本可换本地化节奏包，但底层曲式保持轻量。

### 不要使用

- 真实民族音乐采样。
- 真实明星、球队、动画、游戏 IP。
- 过度地域刻板印象。
